# 第4章 見出しとリード文、入り口の表現を磨く

> 第3章からの接続：導管（論理の骨格）は設計できた。しかし、入口が暗ければ、自分はタブを閉じ、記事を忘れる。第1章の手紙が「玄関」に、第3章の関所が「ゲート」になる。開いた瞬間に「自分向けだ」と思わせる設計を、敬意と誠実さで行う章です。

> この章で学ぶこと
> - 見出しを「スクリーニングゲート」として設計する。検索結果を見てクリックする前に「この関所を通る価値があるか」を判断する最初の関門
> - リード文を「最初にして最大の防波堤」として設計する。離脱（タブを閉じる）を防ぎ、問い（ボール）を引き取る技術
> - title・meta を「正当性を証明する配送ラベル」として設計する（第5章へ続く）
> - 読者が「開いてすぐ戻る」「読み続ける」行動は、問いに合っているかを映す鏡であり、その結果として検索・AIの適合度にも反映されることを踏まえ、入口を設計する
> - 第3章の導管に、読者がワクワクしながら飛び込める「玄関（入り口）」を作る

本章の核となるメッセージ

> 導管が整っても、入口が閉じていれば、自分はタブを閉じ、記事を忘れる。見出しとリードは、タブを閉じる判断と競争する「開いた瞬間の判断」の設計である。テクニックではなく、時間を預かった設計士の責任です。

寿司職人がお客様が座る前に板を拭き、包丁を研ぐように。あなたが書いたあなたの物語も、読者が最初の一行を目にする前に、玄関と防波堤を整えておく必要があります。
