# 2-7 章末まとめ・チェックリスト・演習

第2章を読み終えたあなたへ。ここまでで「宛名」と「返球の方向」は決まりました。第3章以降は、その答えが「詰まらず流れる導管」として設計されていきます。一度、本章の地図を確認しましょう。

## 第2章のメッセージ（再確認）

> この節の要点：検索は日常の問いを解消する行為であり、Webライティングはその問いに正確に返球し、情報の通り道を設計する対話である。第3章では導管の設計へ進む。

第1章で、Webライティングは「敬意ある手紙」であると述べました。第2章では、その手紙の「宛名と返信の内容」を決める作業を扱いました。

> 検索とは、日常のあらゆる「問い（ボール）」を解消する行為である。  
> Webライティングとは、その問いを正確にキャッチし、読者がストレスなく答えに辿り着ける「情報の通り道」を設計する対話である。

キーワードは表面。検索意図は裏側。ペルソナは投げた人の像。プラットフォームは投球フォーム。読み方・デバイス・メディアは受け取り方。ジャーニーは対話の連続。これらを執筆前に揃えれば、第3章の「導管」、第4章の「玄関」、第5章の「Web最適化（検索を入口に）」が、「読者に届く方向」を向きます。

第3章では、問いと出口が決まったあと。「答えまで流れる導管」を設計します。手紙の型から工場ラインの比喩へ、比喩は一段深まりますが、「離脱＝タブを閉じた瞬間の消滅」という緊張感は変わりません。

## 第2章の章末まとめ

> この節の要点：第2章の核心は、検索の定義拡張・四型＋SNS/AI型・ペルソナ・スキャン/ジャンプ/離脱・スマホ前提・メディア別設計・ジャーニーの九つである。

1. 「検索」は検索エンジンに限らない。SNS・AI・アプリ内探索を含む、「日常の問いを解消する行為」である。
2. 「Know / Do / Go / Buy」に加え、SNSの「共感・体験型」、AIの「対話型」を意識して返球を設計する。
3. プラットフォームが変わっても「問いの本質は同じ」。情報の設計士は「情報の通り道」を設計する。
4. 「ペルソナは1記事1人」。5ステップ（キーワード → 意図 → シート → 境界線 → 読み返し）で具体化する。
5. 「スキャン・ジャンプ・離脱（タブを閉じる）」が基本。斜め読みでも答えが届く構造を目指す。
6. 自分が「開いてすぐ戻る」「読み続ける」を選ぶことは、問いに答えられたかを映す鏡。発見の入口（検索を含む）にその結果が伝わりうる。
7. 「スマホ前提」で段落長・ファーストビューを確認する。
8. 「メディア」（ブログ・コーポレート・EC・SNS）ごとに、期待される返球の深さとトーンが異なる。
9. 「ジャーニー」上の位置を意識し、前後の問いにも返球できるよう内部リンクでつなぐ。

## 第2章の執筆前・公開前チェックリスト

> この節の要点：執筆前は返球の設計（キーワード・プラットフォーム・意図・ペルソナ・ジャーニー段階）、公開前は届け方（見出し・ペルソナ視点・スマホ・内部リンク・トーン）を確認する。

記事を書き始める前、および公開前に、次の項目を確認してください。

### 執筆前（返球の設計）

- [ ] ターゲット「キーワード／問い」を1行で書いた
- [ ] 「流入プラットフォーム」（検索エンジン / SNS / AI / アプリ等）を想定した
- [ ] 「検索意図の型」（Know/Do/Go/Buy、＋SNS共感型・AI対話型）を特定した
- [ ] 「6つの問い」（何が欲しい／なぜ今／知識量／答えの後／含まれないもの／プラットフォーム）に答えた
- [ ] 「ペルソナシート」を1人分埋めた（状況・不安・検索後のゴールを含む）
- [ ] 「Must / Must Not」（書くこと・書かないこと）を決めた
- [ ] 「ジャーニー」上、どの段階（認知・検討・決定・継続）の読者かを確認した

### 公開前（返球の届け方）

- [ ] 「見出しだけ」読んで、検索意図に答えているか確認した
- [ ] 「ペルソナの声」で読み返し、トーンと難易度が合っているか確認した
- [ ] 「スマホ」でプレビューし、段落長・ファーストビューを確認した
- [ ] 「次に来そうな疑問」への内部リンクがある
- [ ] メディアの種類（ブログ/コーポレート/EC等）に合った「トーンと長さ」になっている

## 第2章の演習

> この節の要点：テーマ1つについて、ペルソナシート・検索意図メモ・ジャーニーマップ・Must/Must Notを作成する。実在する問いをプラットフォームごとに調べ、具体性を高める。

課題：テーマを1つ選び、「ペルソナシート」と「簡易ジャーニーマップ」を作成してください。

### 推奨テーマ（いずれか1つ）

- 自分の業界・興味に近いキーワード（例：「在宅ワーク 始め方 主婦」）
- 自社・身近なサービスに関連するキーワード
- 第2-1の例「副業 始め方 初心者」を自分なりにアレンジ

### 提出物

1. 「ペルソナシート」（2-2のテンプレート全項目）
2. 「検索意図メモ」（6つの問いへの回答）
3. 「ジャーニーマップ」（最低3段階×3キーワード以上）
4. 「1記事分の Must / Must Not」（各3項目以上）

ヒント：最初は「実在する問い」を、想定プラットフォーム（検索エンジン、SNSのハッシュタグ、AIへのプロンプトなど）で調べ、意図の読み解きを具体化してください。ペルソナは「統計の平均」ではなく、「同僚の健太さんが昨日、通勤電車で投げた問い」くらいの具体性を目指してください。
