# 2-2 ペルソナと読者像の設定

「誰にでも当てはまる記事」を書こうとして、結局誰にも刺さらなかった経験はありませんか。キーワードだけを見て執筆を始めると、宛名のない手紙を量産している可能性があります。ペルソナは空想の人物像ではなく、検索意図を読み解くための実務ツールです。

## 宛名のない手紙を書かない理由

> この節の要点：「誰にでも当てはまる記事」は誰にも届かない。ペルソナとは「この検索をした人は、具体的に誰か」を言葉にしたものである。

第1章で、手紙の第一歩は「宛名」だと述べました。Web文章でも同じです。

「誰にでも当てはまる記事」を書こうとすると、結果的に「誰にも届かない記事」になります。読者が投げたボール（検索エンジン、SNS、AI、アプリのいずれかから）を、特定の相手の手元まで正確に返すには、「投げた人の像」を具体化する必要があります。

それが「ペルソナ（Persona）」。想定読者の人物像です。

ペルソナを「マーケティング用のお役立ちシート」とだけ捉えると、年齢・性別・職業を埋める作業に見えがちです。本書では、もっと実務的に定義します。

> ペルソナとは、「この検索をした人は、具体的に誰か」を言葉にしたものである。

ボールを投げた相手の「立場」「状況」「知識」「不安」を想像する。それがペルソナ設定の本質です。

## ペルソナが検索意図とセットである理由

> この節の要点：「なぜ今？」「どれくらい知っているか？」に答えるには「誰」を想定するかが不可欠である。同じキーワードでもペルソナが違えば返球は変わる。

前節の6つの問い。特に②「なぜ今？」と③「どれくらい知っているか？」に答えるには、「誰」を想定するかが不可欠です。

| キーワード | ペルソナA | ペルソナB | 求める答えの違い |
|---|---|---|---|
| Excel 関数 | 事務職・毎日使う・VLOOKUPは知っている | 経営者・年1回触る・基本操作に不安 | Aには応用例、Bには画面付きの初歩 |
| 育児 休職 | 妊娠中の会社員・制度を調べ始めた | 復帰直前・職場との調整に悩む | Aには制度説明、Bには復帰のコツ |

同じキーワード、同じ検索意図の型（Know）でも、「ペルソナが違えば返球は変わります」。

「万人向け」に書いた記事は、AにもBにも「中途半端な返球」になります。

## ペルソナ設定の五つのステップ

> この節の要点：1記事につき30〜45分で、キーワード→意図の読み解き→シート記入→境界線→声で読み返しの五ステップを執筆前に完了させる。

実務でそのまま使える手順を示します。1記事につき30〜45分を目安に、執筆前に完了させてください。

### ステップ1：記事のテーマとキーワードを1行で書く

```
例：「副業 始め方 初心者」で記事を書く
```

まず、ボールの「表面」。キーワード。を固定します。

---

### ステップ2：検索意図の型と6つの問いに答える

前節のワークを実施し、メモを残します。

```
① Know（知りたい）＋ Do（やってみたい）の混合
② 本業の収入に不安を感じ始めた
③ 副業の種類・確定申告など用語は曖昧
④ 「自分にもできそう」と思い、1つ試したい
⑤ 成功談だけでは不十分。リスクも知りたい
```

---

### ステップ3：ペルソナシートを埋める

次の項目を、「一人の具体的な人物」として書きます。架空でも構いませんが、「統計の平均値」ではなく、「一人のストーリー」にしてください。

#### ペルソナシート（テンプレート）

| 項目 | 記入例 |
|---|---|
| 名前（仮） | 田中 健太（32歳） |
| 職業・立場 | 中堅メーカーの営業職。管理職候補 |
| 検索に至った状況 | 同僚が副業を始めた話を聞き、自分も検索した |
| 流入プラットフォーム・デバイス | 通勤中にスマホでGoogle検索（SNSやAI経由の場合は入口が異なる） |
| 知識レベル | PCは日常使う。確定申告は会社に任せている |
| 本当の不安 | 会社にバレるか、時間が足りるか、何から始めればいいか |
| 記事を読んだ後に | 今週末に試せる具体的な一歩が欲しい |
| 使わないとよい言葉 | フリーランス、複業、MVP（説明なしでは伝わらない） |
| 使うとよい言葉 | 在宅でできる、週末だけ、初期費用0円 |

「ポイント」：「32歳男性」だけではペルソナではありません。「同僚の話を聞いて、初めて検索した」という「状況」まで書くと、書き出しの温度感が決まります。

---

### ステップ4：「この人に返すなら、何を書く／書かないか」を決める

ペルソナシートを見ながら、記事の「境界線」を引きます。

「書くこと（Must）」

- 初心者向けの副業の種類（3〜5個に絞る）
- 始める前の確認事項（就業規則、確定申告の概要）
- 今週末に試せる最初の一歩

「書かないこと（Must Not）」

- 法人設立の詳細（ペルソナの段階では早い）
- 特定ツールの上級テクニック
- 「誰でも月10万」など、根拠の薄い煽り

この境界線は、執筆中の「迷いを減らすガードレール」になります。「書きたいこと」と「返すべきこと」が違うとき、ペルソナが正しい返球を教えてくれます。

---

### ステップ5：ペルソナの「声」で読み返す

下書きができたら、ペルソナになりきって読みます。

```
「健太さん、今の段落は用語が難しすぎない？」
「この結論、『今週末何をすればいいか』まで届いている？」
「不安（会社にバレる件）に触れていないのでは？」
```

一人の編集者が隣に座っているつもりで、「声に出して」読むのが効果的です。第1章の「公開前チェック」に、ペルソナ視点の読み返しを加えるイメージです。

## ペルソナは1記事1人に絞る

> この節の要点：原則は1記事1ペルソナ。「初心者にも上級者にも」は宛名を「各位」にした手紙と同じである。

原則、「1記事＝1ペルソナ」に絞ります。

「初心者にも上級者にも」は、宛名を「各位」にした手紙と同じです。どうしても複数層に届けたい場合は、次のいずれかを選びます。

1. 「記事を分ける」（初心者向け／経験者向け）
2. 「主ペルソナを1人決め、他は副次読者として見出しで拾う」
3. 「ハブ記事＋詳細記事」のクラスター構成（第12章で扱う）

実務では②が最も多いです。「主に健太さん向け。経験者は○○の章を読んでください」と、導線で誠実に伝えます。

## データがなくてもペルソナは作れる

> この節の要点：ペルソナは完璧な顧客データの結晶ではなく、執筆中に読者を想像するための仮説である。検索キーワード・問い合わせ・自分の体験から十分に立てられる。

「アクセス解析やアンケートがないから、ペルソナが作れない」。よく聞く悩みです。

初期段階では、次の情報源で十分です。

| 情報源 | 得られる手がかり |
|---|---|
| 検索キーワード | 何を知りたいか |
| 検索結果上位記事のコメント・口コミ | 読者の不満・追加の疑問 |
| 社内の問い合わせ・営業の声 | 実在する顧客の言葉 |
| 競合のFAQ | よくある不安 |
| 自分の過去の体験 | 「以前の自分なら何が欲しかったか」 |

ペルソナは「完璧な顧客データの結晶」ではありません。「執筆中に読者を想像するための仮説」です。公開後の数字やフィードバックで更新していけばよいのです（第14章）。

## 手紙の比喩でペルソナを再確認する

> この節の要点：ペルソナ設定は、宛名・便箋の選び方・書く分量・書かないこと。敬意ある手紙を書くための最初の具体的な行為である。

| 手紙 | ペルソナ設定 |
|---|---|
| 宛名 | 誰に向けた手紙か（名前・関係性） |
| 便箋の選び方 | 相手に合った語彙・トーン |
| 書く分量 | 相手の知識量に合わせた詳しさ |
| 書かないこと | 相手の段階では早い話題を避ける |

ペルソナは、「敬意ある手紙」を書くための、最初の具体的な行為です。

---

### ペルソナ設定のポイント

- ペルソナは「空想」ではなく、「検索意図を具体化する実務ツール」
- 1記事1ペルソナ。万人向けは、誰にも届かない返球になりやすい
- 5ステップ：キーワード → 意図の読み解き → シート記入 → 境界線 → 声で読み返し
- データがなくても、検索結果・問い合わせ・自分の体験から仮説を立てられる
- ペルソナは固定ではなく、公開後に更新していく

### ペルソナ設定でよくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 年齢・性別だけ埋める | 状況と不安が見えず、トーンが決まらない | 「検索に至った状況」「本当の不安」を必ず書く |
| 理想の顧客像だけ描く | 今検索している人とズレる | 検索キーワードとセットで設定する |
| ペルソナを作って使わない | 執筆中に忘れ、自分向けの文章になる | Must/Must Not を執筆机に貼る |
| ペルソナが多すぎる | 記事の焦点がぼやける | 主ペルソナ1人に絞り、他は別記事へ |
