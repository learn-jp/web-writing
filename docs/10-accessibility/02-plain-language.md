# 10-2 平易な言葉への置き換え（プレーンランゲージ）

整備士が客の問いに届く言葉で説明するように、Expertiseを失わずに全員に返球する技術です。正式な文体のまま載せた長文は、自分がスキャンした段階で「自分向けではない」と感じて戻りますが、平易な言葉へ整えれば、検索・SNS・AI引用のどの入口から来ても、核心に辿り着けます。

## プレーンランゲージとは

> この節の要点：プレーンランゲージは、読者が一度読んで理解でき、必要な行動を取れるように書く原則。読者中心・短い文・能動態・具体性・用語の定義。

プレーンランゲージ（plain language）とは、読者が一度読んで理解でき、必要な行動を取れるように書く原則です。

| 原則 | 意味 |
|---|---|
| 読者中心 | 書き手の都合ではなく、読者の問いに答える |
| 短い文 | 1文1メッセージ。修飾を削ぎ落とす |
| 能動態 | 「〜される」より「あなたが〜する」 |
| 具体性 | 抽象語より、手順・数字・固有名詞 |
| 用語の定義 | 専門語は初出で説明、または平易語に置換 |

第7章で、整備士は専門用語で客を黙らせないと述べました。プレーンランゲージは、その実践そのものです。

```
✗ 「キャリパーのピストンシール劣化により制動力が不均一化」
✓ 「左前のブレーキパッドが薄くなっています。このままだと、
    左右で止まり方が違い、危ない状態です」
```

寿司職人が「中トロは脂がのっています」と言い、化学式で説明しないのと同じです。Expertiseは、相手に届く言葉で示します。

---

## 平易語は「誰にでも」への入口

> この節の要点：平易語は認知負荷を下げ、読字障害・外国語話者・高齢・疲労など、多様な状況の読者への入口になる。専門家も移動中は平易なほうが読みやすい。

アクセシビリティの文脈でプレーンランゲージが重要な理由は、認知負荷を下げることです。

| 読者の状況 | 平易語の効果 |
|---|---|
| 読字障害・発達障害 | 文が短いほど処理しやすい |
| 外国語話者 | 漢字多用・長文が壁になる |
| 高齢読者 | 一度に得られる情報量が限られる |
| 疲労・マルチタスク | スキャンで核心に辿り着ける |

もしあなたが「ターゲットは専門家だから」長文・専門語を正当化していたなら、専門家も疲れたとき・移動中は平易なほうが読みやすい、と考え直してください。工房の入口は、職人だけでなく初来店の客も通れる幅が必要です。

## 置き換えの4ステップ

> この節の要点：問いを1文で書く→長い文を分割→名詞連鎖を動詞に→専門語に説明を添える。四ステップで置き換えを固定する。

### ステップ1：読者の問いを1文で書く

```
問い：「副業を始める前に、会社に何をすればいい？」
```

### ステップ2：長い文を2文に割る

```
✗ 「副業を始める場合は就業規則を確認し、
    必要であれば届け出を行い、承認を得てから開始してください。」

✓ 「副業を始める前に、就業規則を確認してください。
    届け出が必要な会社では、人事部に提出してから始めます。」
```

### ステップ3：名詞の連鎖を動詞に変える

```
✗ 「就業規則上の副業届出義務の履行」
✓ 「副業の届け出をする」
```

### ステップ4：専門語は残すか、説明を添える

完全に削る必要はありません。初出で括弧説明を添えます。

```
✓ 「就業規則（会社のルールブック）に、副業の可否が書いてあります。」
```

第7章の「問いへの応答」と矛盾しません。専門語は、読者の問いに直結するときだけ使い、それ以外は平易語にします。

## 平易語とWeb最適化・構造のバランス

> この節の要点：平易語に置き換えるとき、問いの核心語を消しすぎない。見出しは平易語であり、標識として機能する文言である必要がある。

検索を入り口にする読者は、問いの言葉（キーワード）でページを選びます。平易語に置き換えるとき、核心語を消しすぎないことが重要です（第5章 Web最適化（検索・SNS・AI引用））。加えて、次の読者にも同じ標識が効きます。

- **検索**：title・見出しとクエリの対応
- **SNS**：シェア文・OGPで一目で内容が伝わるか
- **AI引用**：Gemini・ChatGPTが要約・引用するとき、見出しと冒頭だけで意味が取れるか

| 問いの言葉 | 平易語の例 | 注意 |
|---|---|---|
| 副業 始め方 | 副業の始め方 | 核心語は残す |
| 就業規則 確認 | 会社のルールを確認 | 同義語を併記 |
| 確定申告 初めて | はじめての確定申告 | 検索語と自然に一致 |

見出し（第3章）は、平易語であり、標識として機能する文言である必要があります。

```html
<h2>始める前に：就業規則で副業が許されているか確認する</h2>
<p>多くの会社では、副業の届け出が必要です。
   社内ポータルの「就業規則」を開くか、総務に問い合わせてください。</p>
```

「ブラウザでの表示結果（見た目）」：

- H2が目次の関所として表示され、スキャンで「何をすべきか」が一目でわかる
- 段落が短く、スマホでも1画面に収まりやすい
- スクリーンリーダーは見出し→段落の順で読み上げ、構造が音声でも追える

## 平易語のチェックリスト（執筆中）

> この節の要点：公開前に声に出して読み、1文60字・主述の距離・冗長表現・見出しだけでの骨格・専門語の橋渡しを確認する。

公開前に、次を声に出して読んでください。

1. 1文が60字を大幅に超えていないか
2. 主語と述語が離れすぎていないか
3. 「〜において」「〜に関して」が3回以上続いていないか
4. 見出しだけ読んで、記事の骨格がわかるか（第3章）
5. 専門語の初出に、読者の問いへの橋渡しがあるか

自動車整備士が説明を終えたあと、客が「だから、今日何をすればいい？」と聞かない状態。それが平易語の合格ラインです。

## 平易語＝子ども向けではない

> この節の要点：プレーンランゲージは政府・医療・金融でも採用される標準。平易な言葉は内容を下げるのではなく、正しい情報をより多くの人の出口まで届ける導管を広げる。

よくある誤解です。「平易＝幼稚」「専門サイトでは使えない」と。

プレーンランゲージは、政府・医療・金融でも採用される標準です。YMYL（第7章）ほど、誤解が命や財産に関わる分野ほど、平易語と正確さの両立が求められます。

> 平易な言葉は、内容を下げるのではなく、正しい情報を、より多くの人の出口まで届ける導管を広げる行為である。

---

### ポイント

- プレーンランゲージ＝読者の問いに届くExpertise（第7章）
- 短い文・能動態・具体性・用語の定義
- 核心キーワードは残し、名詞連鎖と冗長表現を削る
- 見出しと段落の構造（第3章）とセットで設計

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| すべてカタカナ語 | 別の壁になる | 日常語＋必要な専門語 |
| キーワードまで削除 | 問いとの対応が弱まる | 核心語は見出しに残す |
| 1文に情報を詰め込む | 認知負荷が上がる | 1文1メッセージで分割 |
| 丁寧すぎる敬語の重ね | 読み上げが長くなる | 簡潔な敬体で統一 |
