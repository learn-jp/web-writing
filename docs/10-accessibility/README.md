# 第10章 アクセシビリティ

> 第9章からの接続：モバイルファーストで、短い画面でも答えを届ける設計を学びました。しかし、画面の大きさだけが、読みやすさの条件ではありません。視覚・聴覚・認知・操作のどこかに制約がある読者も、同じ問い（ボール）を投げてきます。第10章は、その全員が出口に辿り着ける「工房」を設計する章です。

> この章で学ぶこと
> - Webアクセシビリティを「善意の配慮」ではなく、設計士の責務として位置づける
> - 平易な言葉（プレーンランゲージ）で、専門性を失わずに届ける
> - 代替テキスト（alt）を、画像の意味を伝える文章として書く
> - 色やコントラストだけに頼らない情報設計
> - 読み上げソフト（スクリーンリーダー）を意識した見出し・段落・リンクの構造

本章の核となるメッセージ

> アクセシビリティは、入口の横に置いたおまけのスロープではない。工房全体にスロープと明確な標識を組み込む、設計の責任である。誰にでも読みやすい文章は、あなたの物語を消滅させないための、本編第1章から続く敬意の延長線上にある。
