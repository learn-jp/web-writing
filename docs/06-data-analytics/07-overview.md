# 6-7 章末まとめ・チェックリスト・演習

第6章を読んだあと、第2の返球をどう読み解くか、実務の型として言えないことはありませんか。章末では、自分が検索したときの体験を振り返る精密検査の要点を、チェックリストと演習で第7章の証明書へつなげます。

---

## 第6章のメッセージ（再確認）

> この節の要点：公開後のデータ＝第2の返球。分析＝故障診断・精密検査である。

第1章から第5章で、第1の返球（手紙、問い、導管、玄関、物流）を設計しました。第6章では、出荷後の対話を扱いました。

> 公開後のデータは、あなた自身が読者として検索した体験を振り返るための第2の返球である。  
> 分析は、故障診断・精密検査である。

整備士の予兆検知（異音、メーター、走行報告）を、選ばれにくさ、即去り、Search Consoleのクエリにマッピングしました。どの問いに、どの答えを、いつ改善するか。それが、自分が検索したときの体験を振り返り、問いと答えのズレを直す段取りです。

## 章末まとめ

> この節の要点：第6章8項目の要点。第2の返球から月次ルーティンまで。

1. 公開後のデータ＝第2の返球。対話は公開後も続く
2. 分析＝故障診断。責めず、原因レイヤーを特定
3. 整備士の予兆検知 → 選ばれにくくなる、即去りの増加、クエリズレ
4. 指標は束ねて読む。表示→選ばれ方→去り方→読み続け→クエリ
5. ヒートマップ＝自分がどこで止まったかを振り返る補助工具。関所の詰まりを可視化する
6. Search Consoleで想定の問いと実際の問いを照合
7. Impact × Urgency ÷ Effort で改善優先度を決める
8. 月次60分の精密検査ルーティンを習慣化

## チェックリスト

> この節の要点：月次精密検査と診断の質を章末チェックリストで固定する。

### 月次精密検査

- [ ] Search Consoleで表示・クリック率・クリック数の前月比を確認
- [ ] 異常記事を第6-2節の予兆パターンに当てはめた
- [ ] 重点3記事についてクエリ分類（想定内/外）を実施
- [ ] 問い×答えマトリクスを更新した
- [ ] 今月のリライト3本とアクションを決めた
- [ ] 先月改善記事の前後比較（再試運転）を実施

### 診断の質

- [ ] 症状（即去り等）と原因（レイヤー）を分離した
- [ ] ペルソナ（第2章）で最終判断を確認した
- [ ] 工数大の全面リライトより、レイヤー限定修正を優先した

## 演習

> この節の要点：記事1本の第2の返球精密検査レポートを作成する演習。

課題：自社または他社の記事1本を選び、第2の返球の精密検査レポートを作成してください（Search Console・Analyticsがなくても、公開情報と想定データで可）。

### 提出物

1. 対象記事URL（またはタイトル）
2. 執筆時の想定（問い・ペルソナ・Must。第2章形式）
3. 第2の返球メモ（表示・選ばれ方・去り方・主要クエリ。実データ or 想定）
4. 予兆パターン（第6-2節のどれに該当するか）
5. 原因レイヤー（外門 / 防波堤 / 関所 / 物流）
6. 問い×答えマトリクス（3クエリ以上）
7. 今月のアクション1つ（title修正、H2追加等）と理由
8. 優先度スコア（Impact / Urgency / Effort を1〜3で）

ヒント：Search Consoleが使えない場合、想定されるクエリを3つ書き、記事本文と照合してください。自動車整備士が診断機なしで異音から原因を絞るように、比喩の階段（第1〜5章）に沿って疑う訓練になります。
