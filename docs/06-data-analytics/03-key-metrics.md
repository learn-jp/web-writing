# 6-3 設計士のダッシュボード、主要指標の読み方

一つの計器だけを見て判断していませんか。あなた自身が検索結果を眺め、クリックする前に判断した経験を思い出してください。Search ConsoleとAnalyticsの指標は、その体験を振り返るための計器です。一つだけでは、原因レイヤー（外門・防波堤・関所・物流）を特定できません。

---

## 計器を束ねて読む

> この節の要点：一つの計器だけで判断しない。複数指標を束ねて原因レイヤーを絞り込む。

自動車整備士は、エンジン音だけ、または油温だけでは車の状態を判断しません。複数の計器を束ねて、故障の手がかりを絞り込みます。

Web記事も同じです。第2章で触れた行動信号を、計器として整理します。以下で計器名を一度定義し、以降は自分が検索したときの体験として読みます。

| 指標 | 第2の返球として | 主な計器 | 疑うレイヤー |
|---|---|---|---|
| 表示回数 | 検索結果に載った回数 | Search Console | 物流（第5章） |
| CTR | 外門を通過した率 | Search Console | 玄関・ラベル（第4・5章） |
| クリック数 | 実際に来た読者数 | Search Console / Analytics | 物流×外門 |
| 直帰率 | 問いに合わなかった信号 | Analytics | 防波堤・意図（第2・4章） |
| 平均滞在時間 | 答えとして有用だったかも | Analytics | 導管全体（第3章） |
| エンゲージメント | 対話が続いたか | GA4 | 導管・関所 |
| スクロール深度 | どこまで読んだか | Analytics / ヒートマップ | H2・段落（第3章） |

一つの計器が赤でも、原因は別のレイヤーにあることが多いです（第6-2節の予兆表）。

---

## 指標ごとの読み方

> この節の要点：各指標が示す第2の返球と疑うレイヤー。計器名を定義したあとは、自分が検索したときの体験として読む。

### 表示回数（インプレッション）

何を見るか：記事が物流ルートに載っているか。

表示がゼロに近い → インデックス、クロール、順位の問題（第5-2節）。  
表示がある → 物流は部分的に機能。次は選ばれ方とクエリを見る。

### CTR（クリック率）

何を見るか：配送ラベル（title・meta）と外門（H1）の吸引力。

```
表示 10,000 / クリック 100 → CTR 1%
```

同じ順位帯で選ばれにくい → 競合と比べ、ラベルが弱い、または釣りで信頼を失った（第4章）。  
改善の方向：title・metaのリライト（第5-3節、第11章）。

### 直帰率（Analytics：単一ページで終了した割合）

何を見るか：防波堤以降の適合度（第2章・第4章）。

開いてすぐタブを閉じる → リードが問いを引き取っていない、H1と中身が不一致、スマホで読みにくい（第2章デバイス）。  
補足：1ページだけ見てタブを閉じるサイトでは、即去り＝悪とは限らない。Go型（公式へ誘導）など、意図の型（第2章）とセットで判断。

### 平均滞在時間（Analytics：ページに留まった時間）

何を見るか：導管を通過できたか。

読み続けが短い → スキャン段階で自分向けではない、結論が遅い、段落が長い。  
読み続けが長いがCVに至らない → 情報は届いたが、行動目的（第1章）の設計不足。

GA4のエンゲージメントも同じ視点で、自分が導管を通過できたかの補助計器として読みます。

### 検索クエリ（Search Console）

何を見るか：実際に来ている問い（第6-4節で詳述）。

執筆時に想定したキーワードと、Search Consoleのクエリが違う → 第2の返球が想定と違う問いで来ていると教えてくれている。

### スクロール深度とヒートマップ

何を見るか：自分がどの関所（H2）まで読んだか。

ヒートマップは、自分がページ上で目を止め、クリックし、どこまでスクロールしたかを色の濃淡で可視化するツールです。H2の直前で色が急に薄くなるなら、自分がそこでタブを閉じた、という体験と照らして関所の詰まりを疑います。詳細な読み方とツール選定は[6-6 精密検査の実務フロー](./06-inspection-workflow.md)を参照してください。

Analyticsのスクロールレポートだけでも、おおまかな関所の詰まりは把握できます。

## ベンチマークより自分の過去と比較

> この節の要点：業界平均より改善前後の比較。整備士がこの車の先月比を見るように読む。

業界平均の即去り率は参考程度に留めます。

自動車整備士が見るのは、この車の先月比です。

```
改善前 選ばれ方 1.2% → 改善後 2.1%   ← 外門改善の効果
改善前 即去り 78% → 改善後 62%    ← 防波堤・導管改善の効果
```

自分の記事の改善前後を比較する。それが、精密検査の基本です。寿司職人が昨日の握りの反応を見て、今日の塩加減を微調整するように、過去の自分との比較が次の一手を決めます。

### ポイント

- 指標＝第2の返球の計器。自分が検索した体験を振り返る道具として束ねて読む
- 表示→選ばれ方→去り方→読み続け→クエリの順で疑うレイヤーが変わる
- ヒートマップ＝関所の詰まりを可視化する（詳細は6-6節）
- ベンチマークより改善前後の比較
- 意図の型（Go型等）で即去りの意味は変わる

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| PVだけ見る | 適合度不明 | 選ばれ方・去り方・クエリを追加 |
| 即去りだけで記事を否定 | 意図・Go型を無視 | 第2章の型とセット |
| 計器が多すぎて混乱 | 優先が決まらない | 第6-5節の優先順位へ |
| 一度見て終わり | 予兆を逃す | 月次で推移を記録 |
