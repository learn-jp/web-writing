# 第13章 実践ワークフロー

> 比喩の階段における位置：応用編（第8章〜）。本編第1章〜第7章で学んだ設計・物流・検査・証明を、第8章〜第12章の運用知見と接続し、「企画から公開まで」を標準手順として固定する章です。

> 第12章からの接続：コンテンツ戦略で「何を・いつ・誰が」書くかを決めた。第13章は、その1本を工房の段取り表に落とし込み、企画→リサーチ→構成→執筆→校正→公開→運用まで同じ順序で回す章です。

> この章で学ぶこと
> - 企画・リサーチ・構成・執筆・校正の5ステップと、各工程の成果物
> - 編集者・ライター・ディレクターの役割分担と、一人チームでの回し方
> - 工程ごとに使うツールの選び方（過剰導入を避ける）
> - レビューとフィードバックの受け方（差し戻しを減らす設計）
> - 公開後の運用フロー（第6章・第11章・第12章との接続）

本章の核となるメッセージ

> 腕前は章ごとに積み上がる。しかし現場では、段取りがなければ品質は再現できない。第1章の手紙の型から第7章の証明書までを、1本の記事で漏れなく通す。それが、実践ワークフローの設計です。
