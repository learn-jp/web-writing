# 第5章 Web最適化と発見性（検索を入口に）

> 第4章からの接続：玄関（H1・リード）は磨いた。次は、読者を玄関の前まで連れてくる発見の設計をする。SNS・生成AI・検索を含むWeb最適化の一翼として、第1章の手紙が配送ラベルと通信規格として完成する。道具と段取りと構造化の規格が、一本の設計として収束する章です。

> この章で学ぶこと
> - 検索エンジン（Web上の情報を収集・整理し、問いに対する答えを選び出す仕組み）を、郵便局ではなく問いをインデックスする知性として理解する
> - Web最適化を構造化の通信規格として設計し、読者・SNS・生成AIへの価値提供と両立させる
> - タイトル・メタを配送ラベルとして整え、問いに届く物流ルートを構築する

本章の核となるメッセージ

> Web最適化はキーワードの羅列ではない。読者・SNS・生成AIに届く構造を先に設計し、その結果として検索インフラにも正しく伝わる発見のための物流設計である。自動車整備士が工具を手入れし段取りを整えるように、通信規格を守ることは、読者の時間を預かる責任の延長線上にある。
