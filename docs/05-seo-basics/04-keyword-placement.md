# 5-4 キーワードを自然に配置する。問いの型番を段取りに刻む

キーワードを増やせば順位が上がる、とまだ信じていませんか。読者がスキャンし、SNSで要約され、AIが引用する本文に、問いの型番を正しい位置に刻む。それが通信規格であり、開いてすぐ去ることを防ぐ設計です。

---

## 配送ラベルの内側に、問いの型番を本体へ刻む

> この節の要点：キーワードはラベルの飾りではなく、H1・リード・H2の正しい位置に刻む問いの型番である。

配送ラベル（title・meta）を貼ったあと、次は荷物の中身です。キーワードは、ラベルの外側だけの飾りではありません。問い（ボール）の言葉を、導管（第3章）の正しい位置。H1、リード、H2。に刻み込む作業です。

自動車整備士が工具箱の引き出しに部品番号を貼るのは、見栄のためではありません。次の作業者が迷わないためです。キーワード配置も同じ。読者がスキャンしたときに「このページは、この問いへの答えだ」と一瞬で伝わる段取りを整える行為です。その結果として、インデクサーと生成AIにも主題が明確に伝わります。

配置がずれれば、玄関（第4章）で約束した問いと、本文の答えがミスマッチになる。自分が期待外れでタブを閉じ、消滅する（第1章・第2章）。型番の羅列は、通信規格違反であると同時に、読者の時間を預かった設計士の失敗でもあります。

---

## キーワード羅列は通信規格違反である

> この節の要点：キーワード羅列は偽ラベルであり通信規格違反。問いの言葉を構造の正しい位置に置く。

検索エンジンへの最適化の古い手法。キーワードを何度も繰り返す、見出しに詰め込む、白文字で隠す。は、偽のラベルです。

インデクサー（検索エンジンの知性）は、長年それを見抜いてきました。現代では、過剰なキーワード詰め込みは、自分が不自然さを感じてタブを閉じてしまう原因になる。その結果、品質評価でも不利になり得ます。

> キーワード配置＝、問い（ボール）の言葉を、構造の正しい位置に置くこと。  
> 羅列＝、ラベルだけ貼って中身が空の荷物。

第2章で、キーワードは答えではなく問いの断片だと述べました。配置の目的は、読者にこのページはこの問いに答えていると伝えることです。その結果として、インデクサーと生成AIにも主題が明確に伝わります。

---

## 配置の優先順位は、工場ラベルと本体の対応表で整理する

> この節の要点：title→H1→リード→H2→本文→meta→alt→URLの優先順位で自然に配置する。

| 優先度 | 位置 | 役割 |
|---|---|---|
| 1 | title | 主ラベル（第5-3節） |
| 2 | H1 | ページ内の正式名称（第4章） |
| 3 | リード文（最初の100字） | 防波堤での宣言 |
| 4 | H2（主要見出し） | 関所の標識 |
| 5 | 本文 | 自然な文脈 |
| 6 | meta description | 補足ラベル |
| 7 | 画像 alt | 視覚情報の代替（第1章） |
| 8 | URL（スラッグ） | 通路の名前 `/side-job-start/` |

上位ほど重い。title と H1 にメインキーワード（問いの核心）を含める。本文は無理に回数を増やさない。

## 見出しへのキーワード配置。HTMLと表示結果

> この節の要点：見出しへの配置は自然か羅列か。HTMLと読み味をセットで良い例・悪い例から確認する。

### 自然な配置（通信規格を満たす）

```html
<h1>副業の始め方｜初心者が今週末に登録まで進む3ステップ</h1>
<p>副業の始め方を探している初心者向けに、在宅で始められる方法を解説します。</p>
<h2>初心者向け｜在宅で週末だけ試せる副業3選</h2>
<h2>今週末に登録まで進む4ステップ</h2>
```

ブラウザでの表示結果（見た目）：

- H1 に「副業の始め方」、H2 に「副業」「始める」が自然に分散
- スキャン読みで主題と各関所が一目でわかる
- インデクサーが見出し階層から意味地図を組み立てやすい

### 羅列配置（通信規格違反）

```html
<h1>副業 始め方 副業 初心者 副業 在宅</h1>
<p>副業 始め方 副業 初心者 副業 在宅 副業 おすすめ</p>
```

ブラウザでの表示結果（見た目）：

- 不自然な繰り返しで、自分がタブを閉じやすくなる
- キーワードのために文が歪んでいる
- 開いてすぐ戻る体験が続けば、品質評価でも不利になり得る

## 自然な配置の5ルール

> この節の要点：1記事1主KW、文として読める、見出しはKW＋約束、語形バリエーション、詰め込み自己チェック。

### 1. 主キーワードは1記事1つ（中心）

第2章の1記事1ペルソナ、第3章の1記事1出口と同様、1記事1主キーワード（問い）を中心に置く。

関連語・共起語は、公開後の第2の返球。Search Consoleのクエリデータ（第6章）。からも見えてきます。執筆前は第2章の問い設計を中心に、自然に本文に含まれる程度でよい。

### 2. 文として読める

```
✗ 「副業 始め方 副業 初心者 副業 在宅」
✓ 「副業の始め方を探している初心者向けに、在宅で始められる方法を解説します。」
```

### 3. 見出しはキーワード＋約束

第4章のゲート設計と一致。

```
✓ 「副業の始め方｜初心者が今週末に登録まで進む3ステップ」
✗ 「副業 始め方 初心者 在宅 おすすめ」（羅列）
```

### 4. 語形のバリエーション

副業 始め方、副業の始め方、副業を始める。同じ意図の自然な言い換えは、読者にもインデクサーにも健全。

### 5. 詰め込みの自己チェック

```
□ 同一段落に同じキーワードが3回以上ないか
□ 読み上げて不自然でないか
□ キーワードのために文が歪んでいないか
```

## 意図の型ごとに、キーワードの置き方を変える

> この節の要点：Know・Do・Go・Buyの意図型ごとに、キーワード配置の型を使い分ける。

| 意図 | キーワードの特徴 | 配置のコツ |
|---|---|---|
| Know | とは、意味、方法 | 定義・整理のH2に |
| Do | やり方、手順、始め方 | 番号リストの前後 |
| Go | ブランド名＋サービス名 | title・H1・冒頭に公式導線 |
| Buy | おすすめ、比較、選び方 | 比較表・H2に |

## アウトライン段階で、キーワードと構造を一体設計する

> この節の要点：構造が先、キーワードは構造に沿って乗る。H2の段取り段階で一体設計する。

第3章のアウトライン段階で、主キーワードをH2に分散させると、自然な配置になります。

```
主KW：副業 始め方 初心者

H2：初心者向け｜在宅で週末だけ試せる副業3選     ← 「副業」「初心者」
H2：始める前に確認：就業規則…                 ← 「始める」
H2：今週末に登録まで進む4ステップ             ← 「始め方」
```

構造が先、キーワードは構造に沿って乗る。第5-1節の原則1です。寿司職人がネタの順番を決めてから握るように、H2の段取りが決まってから、問いの言葉を嵌めます。

### ポイント

- キーワード＝問いの言葉。羅列は通信規格違反。読者の消滅にもつながる
- 配置は段取り：整備士が型番を正しい位置に嵌めるように、構造に沿って置く
- 優先：title → H1 → リード → H2 → 本文 → meta → alt → URL
- 1記事1主キーワード、文として自然、語形バリエーション可
- アウトラインのH2に分散させると自然

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 密度2%など数字だけ追う | 羅列・不自然 | 構造と文脈で配置 |
| 本文にKWだけ増やす | タブを閉じる | title/H2で十分なことも |
| URLを意味不明に | 通路が読めない | 英語またはローマ字で意味のあるスラッグ |
| 関連語を無理に全部入れる | 焦点がぼやける | 第6章の精密検査で優先順位を決める |

## 第5章から第6章へ。出荷後の精密検査

> この節の要点：物流を整え公開したあと、第2の返球の精密検査は第6章。改善の段取りを決め続ける。

物流を整え、あなたの物語を出荷したあと。Search ConsoleやAnalyticsから第2の返球（見られたか、選ばれたか、自分がタブを閉じたか、どんな問いで来たか）が返ってきます。第5章までが第1の返球の設計なら、第6章はその精密検査です。自動車整備士が走行後の異音を無視しないように、公開後も改善の段取りを決め続けます（第6-1節〜）。
