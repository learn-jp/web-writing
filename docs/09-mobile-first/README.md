# 第9章 モバイルファーストの文章

> 比喩の階段における位置：応用編（第8章〜）。本編で身につけた設計思想を、自分が実際に手にする画面に落とし込む章です。

> 第8章からの接続：トーンと声が整った。次は、届け先の封筒サイズを前提に返球を設計する。第2章で触れた「スマホでボールを受け取る自分自身」を、執筆の起点に据えます。

> この章で学ぶこと
> - モバイルファーストを「最小の整備ピットで設計する」発想として理解する
> - 短い画面で伝わる構成（第3章の導管を、狭い画面向けに再調整する）
> - ファーストビューの設計（第4章の玄関を、スクロール前の一瞬に圧縮する）
> - タップしやすいCTAの文言設計
> - 読み込み速度と文章量のバランス（整備士の軽量化と、寿司職人の「必要な分だけ」）

本章の核となるメッセージ

> スマホで読める返球を書けば、どの画面でも読める。最小の整備ピットに収まる設計をすれば、広い工場でもそのまま通用する。それが、モバイルファーストの文章設計です。
