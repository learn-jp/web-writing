# 7-6 未来の設計士へ、誠実な設計士としての生き方

第1章からここまで、あなたは多くの型を学んできました。手紙の型、問いの読み方、導管、玄関、物流、精密検査、証明書。本章の最後では、それらを超えた、設計士としての生き方を語ります。

## この本は、テクニックの本ではなかった

> この節の要点：PREPや見出し階層は、読者の問いに応え続ける設計思想の道具である。テクニック集ではない。

PREP、見出し階層、title・meta、Search Console。名前は違えど、すべて同じ骨格です。

```
読者の問いを受け取り、
  時間を預かり、
    正しい答えを、
      正しい形で、
        届け、
          届いたかを確かめ、
            正しいと宣言する。
```

これは、検索エンジン向けの小手先の技集ではありません。読者の人生や仕事に、向き合うための、設計の思想です。

---

## 整備士が教えてくれたこと

> この節の要点：見出しを適当に付ける、出典なしで書く、公開して終わりにする。それは未来の読者と未来の自分に面倒をかける行為である。

第1章のコラムで、自動車整備士の言葉を紹介しました。

「道具を汚れたままにしておくのは、次にこの道具を使う人。たいていは未来の自分。に面倒をかけますと宣言するようなものです。」

Webライティングも同じです。

- 見出しを適当に付ける → 未来の読者に面倒をかける
- 釣りタイトルでクリックを稼ぐ → 未来の自分の信頼をすり減らす
- 出典なしで書く → 未来の精密検査（第6章）で矛盾が露呈する
- 公開して終わり → 第2の返球を、無視することになる

次にこの記事を読む人。画面の向こうにいる、名前も顔も知らない誰か。のために、今日ひとつだけ整える。

自動車整備士が、それを矜持と呼ぶなら、情報の設計士も、同じ言葉を使っていい。寿司職人が次の客のために板を磨くように、設計士も次の読者のために、今日ひとつだけ整えます。

## テクニックを超えて、3つの誓い

> この節の要点：空の返球を返さない、消滅を切り捨てない、正しいと宣言し更新し続ける。未来の設計士への3つの誓いである。

未来の設計士、あなたに、3つの誓いを提案します。厳格さと、温かさの両方を込めて。

### 誓い1：問いに、空の返球を返さない

キーワードだけを拾い、PREPの形だけを真似し、証明書の欄だけを埋める。それは、返球の形だけの、空の手紙です。

読者が投げたボールを、両手で受け止める。ペルソナの問いの言葉で、リードが始まる。Mustと一致した中身がある。これが、最低限の誠実さです。

### 誓い2：消滅を、仕方ないと切り捨てない

Webでは、離脱は消滅です（第1章）。自分がタブを閉じた体験を、「読者のせい」「そもそも読まれない記事だ」と切り捨てた瞬間、設計士としての仕事は終わります。

第6章の精密検査は、責めないための技術でした。「ここを直せ」という第2の返球が、計器を通じて自分の読者体験として振り返れます。計器は、敵ではありません。

自動車整備士が走行後の異音を無視しないように。出荷して終わりにしない。月次60分の検査を、段取りとして固定する。それが、第6章で学んだ改善の継続という姿勢です。

### 誓い3：正しいと、宣言できるまで出荷する。そして、更新し続ける

第5章で物流、第6章で精密検査、第7章で証明書。出荷の前・後・宣言のすべてに責任があります。

正しいと宣言できない情報は、出荷しない。わからないことはわからないと書く。古い情報は更新する。誤りは訂正する。

そして、一度宣言したから終わりではない。第6章の精密検査で見つかったズレを直したら、証明書も更新する。自動車整備士が修理後に記録簿を書き直すように、Trustworthinessは、宣言の勇気であり、継続の誠実さです。

## 技術者の矜持、温かく、厳格に

> この節の要点：最初の記事は完璧でなくていい。次に読む人のために、今日ひとつだけ整える積み重ねが、信頼になる。

国家資格を取得した自動車整備士が、最初の1台目で完璧だった。そんな話は聞きません。工具を落とし、診断を誤り、先輩に怒られました。

しかし、道具を手入れし、段取りを整え、記録を残し、次は同じミスをしない。その積み重ねが、10年後のあの人に頼めば安心になります。

Webライティングも同じです。

最初の記事は、壊れた手紙かもしれません。開いてすぐ去られるかもしれません。証明書の欄は、半分しか埋まっていないかもしれません。

それでいい。

大事なのは、次に読む人のために、今日ひとつだけ整えること。見出しをひとつ、見出しタグとして付ける。リンクをひとつ、こちらから具体的な言葉に変える。出典をひとつ、追加する。

その小さな整備の積み重ねが。

- 読者の消滅を減らし、
- 第2の返球を味方にし、
- 証明書に誠実さを刻み、
- いつか、誰かのあの記事、助かったになる。

寿司職人が毎日板を磨き、ネタの鮮度を確かめるように、設計士も小さな整備を積み重ねます。

## 本書を貫く比喩、最後に

> この節の要点：7つの比喩は7つの誓いでもある。手紙から証明書まで、一本の設計思想として閉じる。

```
第1章  手紙       … 届け方は、礼儀である
第2章  問い       … 宛名を、間違えるな
第3章  導管       … 段取りを、整えよ
第4章  玄関       … 入口で、去らせない
第5章  物流       … 届け方を、設計せよ
第6章  精密検査   … 第2の返球を、診断せよ
第7章  証明書     … 正しいと、宣言せよ
```

7つの比喩は、7つの誓いでもあります。

## 未来の設計士へ

> この節の要点：読者が問いを投げ、誰かが誠実に答える構造は変わらない。あなたの現場と一次体験を、証明書として世界に発行せよ。

もし、あなたがこの本を第1章からここまで読み進めてくれたなら。あなたはすでに、テクニックを知っている人ではありません。

問いに応える責任を、引き受けようとしている人です。

検索エンジンのアルゴリズムは変わります。SERPの見え方は変わります。AIが検索を置き換えるかもしれません。SNSの文化も変わります。PREPに代わるフレームが生まれるかもしれません。

しかし、読者が問いを投げ、誰かが誠実に答える。その構造は、変わりません。

自動車整備士として国家資格を取得し、現場で技術を磨いてきた経験が、本書の背骨でした。それは、著者の履歴書の一行ではなく。預かったものを、正しく返すという、生き方そのものです。

あなたにも、あなたの現場があります。あなたの国家資格があります。あなたの、まだ書かれていない一次体験があります。

それを、記事に刻んでください。  
問いに、責任を持って応えてください。  
そして、正しいと、宣言できる証明書を、世界に向けて発行してください。

画面の向こうにいる誰かが、あなたの記事にたどり着く日があります。その人は、まだあなたの名前を知らないかもしれません。

それでも。

その人にとっての最初のおもてなしは、すでにあなたの手の中で始まっている。

道具と段取りを整えるように、情報の構造を設計する。  
読者の時間を預かり、問いに誠実に応える。  
正しいと、宣言できるまで、設計を続ける。

それが、誠実な設計士としての生き方です。

自動車整備士が、工場を去るときに工具を手入れするように。  
あなたが、このページを閉じるとき、次に書く記事のために、今日ひとつだけ、整えてください。
