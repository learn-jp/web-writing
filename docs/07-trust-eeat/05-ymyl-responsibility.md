# 7-5 命と財産がかかる問い、YMYLと責任

YMYL（Your Money, Your Life）は、お金と生活・健康に直結する問いの呼び名です。誤情報が読者の人生に直結する分野として、業界ではYMYLと呼ばれ、検索エンジンや生成AIも信頼要件が厳しくなります。本質は、読者の人生への責任です。

## YMYLとは何か

> この節の要点：YMYLはお金と生活・健康に直結する問い。誤情報のリスクが高く、証明書の基準が一段厳しくなる。

お金と生活・健康に直結するトピックはYMYL（ワイマル）と呼ばれます。読者への誤情報リスクが高い分野です。SNSで拡散され、ChatGPTやGeminiが引用される時代ほど、誤情報の被害は広がりやすくなります。検索エンジンも同様に、こうした分野では信頼要件を厳しく見ます。

| YMYLの例 | 読者の問い | 誤情報のリスク |
|---|---|---|
| 医療・健康 | この症状、大丈夫？ | 生命・健康被害 |
| 金融・投資 | この商品、安全？ | 資産損失 |
| 法律・税金 | これ、違法？ | 法的・金銭的損害 |
| 安全・防災 | この対策で足りる？ | 身体の安全 |
| 重大な購買 | この契約、問題ない？ | 長期的な不利益 |

自動車整備士がブレーキを預かるとき、命がかかります。説明を適当にすれば、結果が返ります。YMYLの記事も、同じ重さで書きます。

> YMYLにおけるE-E-A-Tは、検索エンジン向けの加点ではない。読者・SNS・生成AIを通じて届く、人生への責任声明である。

---

## 整備士の「預かり」とWebの「預かり」

> この節の要点：YMYLでは、読者から時間だけでなく判断を預かる。整備士が車と命を預かるのと同型の責任である。

自動車整備士は、客から車と命を預かります。情報の設計士は、読者から時間と判断を預かります。YMYLでは、その判断が人生や財産に直結します。

| 整備士 | YMYLのWebライター |
|---|---|
| 資格と経験を明示 | 著者・監修者のExpertise |
| マニュアルと測定値に基づく | 出典・公式情報 |
| このまま走行は危険と伝える | リスク・限界・専門家への相談を促す |
| 記録簿に残す | 更新日・改訂履歴 |
| わからなければ専門店へ | 医師に相談、税理士に確認 |

なんとなく大丈夫は、整備記録簿にも、Web記事にも、書けません。

## YMYL記事の設計原則

> この節の要点：監修・公式出典・限界の明示・更新・専門外は書かない。5原則で証明書の欄を一段厳しく埋める。

YMYLの記事を書くとき、次の5原則を守ってください。すべて、証明書の欄を厳しく埋めるための指針です。

### 1. 監修または専門家の関与

可能な限り、資格を持つ監修者を明示する。整備士2級の整備士がブレーキを担当するように、分野のExpertiseが、証明書を支えます。

### 2. 公式・一次情報を優先

税務なら国税庁、健康なら厚生労働省・医療機関。部品メーカーの公式と同じく、公式を根拠の中心に。

### 3. 個人の状況により異なりますを書く

一般論と、読者個人の判断を分離する。一括りの絶対は、Trustworthinessを損なう。

### 4. 古い情報の危険性

制度・医療・金融は変わる。第6章の精密検査で、YMYL記事は更新優先度を上げる（第11章）。

### 5. 自分の専門外は、書かない

自動車整備士がエンジン以外をなんとなく直さないように。Must Not（第2章）を、YMYLでは特に厳格に。

## 誤情報・古い情報への対処

> この節の要点：誤りを見つけたら即座に訂正し、記録に残す。整備士が記録簿を直すのと同じ倫理である。

第2の返球（第6章）で内容が古い、問いとズレていると判明したら。

1. 即座に誤りを訂正する（Trustworthiness）
2. 更新日と改訂内容を記載する
3. 影響が大きい場合は一時非公開を検討する
4. 読者へのお詫びと訂正（必要に応じ）

自動車整備士が誤った整備に気づいたら、記録簿を訂正し、客に連絡する。同じ倫理です。寿司職人がネタの鮮度に問題を見つけたら、客に正直に伝えるように、設計士も誤りを隠さず訂正します。

---

## YMYLでない記事にも、責任はある

> この節の要点：YMYL以外でも、読者の時間を預かる事実は変わらない。すべての問いに、整備士の矜持で応える。

すべての記事がYMYLではありません。しかし、読者の時間を預かる事実は変わりません（第1章）。

副業の始め方、エアコンの掃除、転職のマナー。命ほどではない問いでも、誤った答えは、読者の時間と機会を奪います。離脱＝消滅（第1章）は、YMYL以外でも起きます。

> YMYLは基準が厳しい。それ以外は、基準が緩い、ではない。すべての問いに、整備士の矜持で応える。

---

### ポイント

- YMYL＝Money/Life。証明書の基準が一段厳しい
- 監修、公式出典、限界の明示、更新
- 誤りは訂正し、記録に残す
- すべての記事に、預かる責任がある

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 医療を一般論だけで | 生命リスク | 監修・専門家・相談促進 |
| 制度情報が古い | 誤判断 | 更新日・公式リンク |
| 絶対儲かる | Trustworthiness崩壊 | リスク・限界を書く |
| 専門外を書く | Expertiseの侵害 | Must Not、別記事化 |
