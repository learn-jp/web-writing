# 第3章 情報設計と構成

> 第2章からの接続：問い（ボール）と宛名（ペルソナ）が決まった。次は、「答えまで流れる導管」を設計する。第1章の手紙の型を、工場ラインの比喩へ。「道具と段取り」で、タブを閉じる前に出口へ届ける。

> この章で学ぶこと
> - PREP法を「理想的な返球フォーム」。問いへの最短・最明確な答えの構造。として設計する
> - 見出し・段落・リストを「情報の導管」として組み立て、読者の脳にストレスを与えない流れを作る
> - 構造化を「情報の正当性を証明するエンジニアリング」。巨大なAIへの正確なマッピング。として位置づける
> - ノイズを削ぎ落とし、答えに心地よく辿り着ける「構造の美学」を身につける

本章の核となるメッセージ

> 構成はテンプレートではない。読者を情報の出口（納得のいく答え）へ誘導するための、論理的な導管設計である。段取りを整える整備士のように、「詰まりと逆流を許さない」。それが、読者の時間を預かる設計士の仕事です。
