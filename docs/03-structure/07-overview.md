# 3-7 章末まとめ・チェックリスト・演習

第3章を読み終えたあなたへ。ここまでで「問いと出口」に向けた導管の設計は身につきました。第4章では、この導管に「玄関」を設計します。一度、本章の地図を確認しましょう。

## 第3章のメッセージ（再確認）

> この節の要点：構成はテンプレートではなく論理的な導管設計。PREP・見出し・段落・リスト/表・アウトライン・削ぎ落としが、設計士としての技術である。

第2章で、読者の「問い」と「出口」を決めました。第3章では、その間をつなぐ「情報の導管」を設計しました。

> 「構成はテンプレートではない。」  
> 「読者を情報の出口（納得のいく答え）へ誘導するための、論理的な導管設計である。」

PREPは理想的な返球フォーム。見出しは関所と標識。段落・リスト・表は流れの単位と分岐。アウトラインは設計図。削ぎ落としは構造の美学。これらは、第1章の「構造層」、第2章の「読者理解」の上に載る、「設計士としての技術」です。正しく印を付けた導管は、検索エンジンやAIへの「情報のマッピング」であり、「正当性を証明するエンジニアリング」でもあります（第5章）。

第4章では、この導管に「玄関」を設計します。論理が正しくても、自分が入口でタブを閉じれば、導管は空回りします。「外門（H1）」と「防波堤（リード）」。タブを閉じる判断と競争する「開いた瞬間の判断」が、次の階段です。

## 第3章の章末まとめ

> この節の要点：PREP・逆ピラミッド・見出し・段落・リスト/表・アウトライン・削ぎ落としの8要点を一覧で確認する。

1. 「PREP」は暗記する型ではなく、問いへの「最短・最明確な返球フォーム」（P→R→E→P）。
2. 「逆ピラミッド」は記事全体の情報優先順位。出口（結論）を上に置く。
3. 「見出し」はタイトルではなく、情報の「関所」と「標識」。H1は1つ、階層を飛ばさない。
4. 「段落」は1論点・3〜4文。文は60字目安。余白は呼吸の設計。
5. 「リスト・表・図」は並列情報の分岐・合流。Do型は番号リスト、Buy型は表。
6. 「アウトライン」は本文前の導管設計図。問い・出口から逆算し、H2＋PREP骨格を引く。
7. 「削ぎ落とし」は構造の美学。問いに答えない情報はノイズ。Must/Should/Could/Won'tで優先順位を決める。
8. 「構造化・タグ付け」は検索を入口にした小手先の技ではなく、読者・AIへの「正確なマッピング」。「正当性を証明するエンジニアリング」。

## 第3章の執筆前・公開前チェックリスト

> この節の要点：設計段階（アウトライン）と執筆・公開前（導管の検査）の2段階で、問い・出口・PREP・削ぎ落としを確認する。

### 設計段階（アウトライン）

- [ ] 「問い」と「出口」を1行ずつ書いた
- [ ] 「Must / Must Not」を確認した
- [ ] 「H2の見出しだけ」読んで、通り道が通る
- [ ] 各H2に「PREPのP（要点）」を一行メモした
- [ ] 「逆ピラミッド」。最重要H2が上にある
- [ ] リスト・表・図の「配置」を決めた

### 執筆・公開前（導管の検査）

- [ ] 各H2が「1論点」のPREP返球になっている
- [ ] 見出しが「標識」として機能する（「背景」「まとめ」だけではない）
- [ ] 段落は「1論点・3〜4文」。スマホで5行超えがない
- [ ] 並列情報は「リスト・表」に分離している
- [ ] 「削ぎ落とし」。削除しても答えに到達できる段落がないか確認
- [ ] ペルソナの「出口」に、記事全体で到達できる

## 第3章の演習

> この節の要点：テーマを1つ選び、見出しとPREP骨格からなる「記事アウトライン（導管設計図）」を作成する。本文は書かない。

「課題」：テーマを1つ選び、「記事アウトライン（導管設計図）」を作成してください。

### 演習の推奨テーマ

- 第2章演習で使ったキーワード／問いをそのまま使う（推奨）
- 新規：「在宅ワーク 始め方」「確定申告 初めて 副業」など

### 演習の提出物

1. 「問い・出口・ペルソナ・意図の型」（各1行）
2. 「Must / Must Not」（各3項目以上）
3. 「H2見出し一覧」（3〜5個）。見出しだけ読んで骨格が通ること
4. 「各H2のPREP骨格」（P・R・E・Pを一行ずつ）
5. 「リスト・表・図」の配置メモ（どのH2に何を置くか）
6. 「削ぎ落とし候補」。書きたいが Must Not に入れた項目があれば1つ
