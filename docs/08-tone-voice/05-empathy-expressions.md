# 8-5 共感を生む表現と避けるべき表現

第1章で、Web文章の3つの目的のひとつに「共感」を挙げました。第2-6節では、ジャーニーの段階でトーンを変えると述べました。共感表現は、そのトーンを具体化する道具です。「共感＝『わかります！』『大丈夫！』と書くこと」ではなく、設計として捉え直してください。検索結果のリード、SNSの冒頭2行、AIが引用する段落。いずれも、読者の不安を先に言語化できているかが、次の行動（クリック・シェア・深読み）を決めます。共感は、証明書（第7章）と矛盾しません。むしろ、YMYL（第7-5節）では、不安を先に受け止めることが、信頼の入口になります。

## 共感の設計、先に問いを言語化する

> この節の要点：共感は、読者の状況と不安を具体的に言語化してから、返球に入ることである。

優れた共感表現は、読者の状況を具体的に言葉にしてから、返球に入ります。抽象の「お困りでは」だけでは、宛名がぼやけます（第2章）。

```
✗ 「副業に興味がある方、お困りではありませんか。」

✓ 「本業が忙しいなか、副業を始めたいが、
    会社の就業規則がわからず、検索の手が止まっている。
    そんな状態から始める方が多いです。」
```

2つ目は、第2-2節のペルソナの「検索に至った状況」をそのまま表に出しています。読者は「自分のことが書いてある」と感じ、スキャンを続けます（第2-3節）。

| 共感の段階 | 表現の型 | 例 |
|---|---|---|
| 状況の特定 | 「〜で、〜と感じている方へ」 | 時間がなく、何から手を付けるか迷っている |
| 不安の代弁 | 「〜ではないかと心配になる」 | 会社にバレるのではないか |
| 正常化（必要時） | 「多くの場合、〜です」 | 届け出が必要な会社がほとんど |
| 返球への橋 | 「まず確認すべきは、〜です」 | 就業規則（第4章の結論ファースト） |

## 整備士の共感、不安を先に名指しする

> この節の要点：客の言葉を繰り返してから説明を始める。共感段落のあと、必ず具体的な返球へつなげる。

自動車整備士が優れているのは、客の言葉を繰り返してから説明を始める点です。

```
客：「ブレーキから変な音がする。大変な故障？」
整備士：「音が気になって不安ですよね。まず今日は点検だけします。
        交換が必要かどうか、見てからお伝えします。」
```

「大変な故障かも」という不安を先に受け止め、次の一手（点検）を明示する。Web記事でも、見出しまたはリード（第4-3節）で同じ構造を使えます。

```
「副業は会社にバレるのでは、と不安になる方へ。
 多くの場合、就業規則と届け出の確認が先です。
 本章では、確認手順を順に説明します。」
```

共感段落のあと、必ず具体的な返球（手順、条件、限界）へつなげます。共感だけで終わる段落は、空の返球（第7-6節）です。

## 避けるべき表現、トーンを壊す禁則

> この節の要点：過剰な同調・不安の煽り・断定の過剰・他者贬めは、8-4節の禁則語に必ず含める。

共感の反対側に、トーンと信頼を同時に壊す表現があります。8-4節の禁則語に必ず含めてください。

| カテゴリ | 避ける表現 | 理由 |
|---|---|---|
| 過剰な同調 | 「わかります！完全にわかります！」 | 軽く、根拠がない |
| 不安の煽り | 「このままだと危険」「今すぐでないと」 | YMYLで特に有害（7-5節） |
| 断定の過剰 | 「絶対」「100%」「誰でも」 | 証明書と矛盾 |
| 他者贬め | 「〇〇は古い」「バカバカしい」 | 権威性の偽装 |
| 責める | 「〜しない人は損」 | 読者を敵にする |
| 曖昧な励まし | 「きっと大丈夫」 | 問いに答えていない |

寿司職人が「今日はお腹いっぱいですね」と客の状態を察しながらも、ネタの鮮度や産地を隠さないように、共感と誠実さは両立します。

## 共感と行動喚起、第1章の3目的との接続

> この節の要点：共感→情報→行動の順序を守る。共感段落のあと、押し売り口調に切り替えない。

共感は、行動（CTA）の前段です。第1章の3目的（情報・共感・行動）を、トーンで順序立てます。

```
1. 共感（不安・状況の言語化）
2. 情報（手順・条件・根拠）
3. 行動（次に確認すること、CTA）
```

ECやコーポレートでは、共感段落のあとに押し売り口調に切り替えると、ボイスが分裂します（8-1節）。「選び手の立場」（第2-5節）を保ったまま、行動を提案します。

```
「就業規則の確認が終わったら、副業の種類を絞り込みましょう。
 次の記事では、時間の使い方から比較しています（内部リンク）。」
```

## YMYLでの共感、一段厳しい線引き

> この節の要点：YMYLでは共感も証明書と同レベルの責任を伴う。不安を煽らず、専門家への導線を省略しない。

健康、お金、法律に関わる記事では、共感表現も証明書と同様に責任を伴います。第7-5節を参照し、次を守ります。

- 不安を煽らない。代わりに、確認すべき事項を列挙する
- 「医師に相談を」など、専門家への導線を省略しない
- 体験談の共感は、一般化しない（「私は〜だった」で止める）

```
✗ 「この方法でみんな治った！」
✓ 「著者は〇〇を試したが、効果には個人差がある。
    症状が続く場合は、医療機関への相談を検討してください。」
```

## 共感は、返球の前の「受け止め」

> この節の要点：共感段落を追加しても問いに近づいていないなら、ペルソナの「本当の不安」を第2-2節から再引用する。

### この節の整理

- 共感＝状況と不安を、先に具体的に言語化する
- 共感のあと、必ず情報と返球につなげる
- 煽り・断定・他者贬めは禁則。ガイドラインに明記
- YMYLでは共感も証明書と同レベルの責任

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 共感だけで長いリード | 結論が遅い | 第4章の結論ファーストと両立 |
| テンプレ同調 | どの記事も同じ | ペルソナの状況を毎回具体化 |
| 不安を煽ってクリック | 信頼を毀損 | 確認事項の列挙に置換 |
| 共感とCTAのトーン差 | ボイス分裂 | 8-1節のボイスに照合 |
