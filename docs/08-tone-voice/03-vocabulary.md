# 8-3 ターゲットに合わせた語彙選び

第7-3節で、Expertise（専門性）は専門用語の羅列ではないと述べました。語彙選びは、E-E-A-Tの問題でもあり、トーンの問題でもあります。ペルソナの健太さん向け記事に、マーケター同士の略語だけで書いていたら、宛名違いの返球（第2章）になり、スキャン段階で消滅します（第1章）。

## ペルソナの辞書を先に作る

> この節の要点：語彙選びは、ペルソナシートから逆算する。検索語と不安を、見出し・本文に自然に織る。

第2-2節のペルソナシートには、「検索に至った状況」「本当の不安」が書いてあります。語彙選びは、そのシートから逆算します。

| ペルソナの要素 | 語彙への反映 |
|---|---|
| 職種・立場 | 使う・避ける業界語 |
| 不安 | 共感語彙（8-5節） |
| 検索語 | 見出し・本文に自然に織る（第5-4節） |
| リテラシー | 定義の要否、比喩の種類 |

健太さん向けなら、「インデックス」より「検索結果に載る」、「クリックされる率」より「検索結果で選ばれる」と、ペルソナの言葉に近づけます。Web最適化（検索・SNS・AI引用）での自然なキーワード配置（第5章）と矛盾しません。読者の問いの言葉こそ、検索を入口にした発見でも、SNSのプレビューでも、AIの引用でも、自然に届く配置の単位です。

## 三層の語彙、表・裏・禁則

> この節の要点：語彙を表層（読者向け）・裏層（根拠）・禁則に分け、設計しやすくする。

寿司職人は、客には「脂の乗った中トロ」と言い、仕入れメモには産地と入荷日を書き、ネタの欠点は隠しません。Web文章も、語彙を三層に分けると設計しやすくなります。

| 層 | 役割 | 例 |
|---|---|---|
| 表層（読者向け） | 問いに届く言葉 | 「副業の届け出」「就業規則」 |
| 裏層（専門・根拠） | 証明書の根拠 | 法令名、調査名、著者の経験 |
| 禁則 | 使わない語 | 誇大、断定的な収益保証、他者贬め |

表層で専門用語を使う必要があるときは、第7-3節の整備士の説明のように、一文で定義してから使います。

```
「検索エンジン（Web上の情報を検索する仕組み）が
 ページを読み取る工程を、インデックス（検索用の目録に載せること）と呼びます。」
```

初出で定義し、以降は略語可。これは礼儀であり、ボイスの一貫性でもあります。

## 同じ概念、読者層で言い換える

> この節の要点：同じ事実でも、記事の目的とペルソナで言い換え表を持つと、トーンが安定する。

自動車整備士は、オーナーには「ブレーキを踏むと音がする」と言い、同業者には「ローターとの接触音」と言い換えます。同じ事実、語彙だけ変える。Webでも、記事の目的とペルソナで言い換え表を持つと、トーンが安定します。

| 概念 | 初心者向け | 上級者向け |
|---|---|---|
| 検索順位 | 「検索結果の上の方に出る」 | 「特定クエリでの表示順位」 |
| 即去り | 「ページを開いてすぐ閉じる」 | 「Analyticsの単一ページ終了（計器上は直帰率）」 |
| E-E-A-T | 「誰が書いたか、根拠はあるか」（第7章） | 「Experience〜Trustworthinessの4要素」 |

言い換え表は、8-4節のブランドガイドラインに「推奨語彙／避ける語彙」として載せます。チーム執筆のばらつきを防ぐ、カウンター裏の共通メモです。

## カタカナ語・外来語・和語のバランス

> この節の要点：カタカナ語の連続使用は認知負荷を上げる。和語または具体的な動詞への置き換えを検討する。

Web文章はカタカナ語が増えがちです。

| 傾向 | 使いどころ | 注意 |
|---|---|---|
| カタカナ語 | 業界標準語、固有名詞 | 初出定義、連続使用を避ける |
| 和語 | 動作・関係の説明 | 曖昧すぎる抽象語は避ける |
| 漢語 | 公式・契約・YMYL | 読みの難度に注意 |

「最適化」「エンゲージメント」「リテンション」を連続させない。1段落にカタカナ語が3つ並んだら、和語または具体的な動詞に置き換えられないか見直します。

## 検索クエリと語彙、第5章との接続

> この節の要点：Search Consoleのクエリは、自分が検索するときに使う語彙の返球である。語彙表を更新し続ける。

Search Consoleのクエリ（第6-4節）は、自分が検索するときに使う語彙の返球です。執筆時の想定語彙とクエリがズレていたら、言い換え表を更新します。ただし、クエリに合わせてペルソナから外れた語彙を無理に入れるのは、宛名違いの別問題です。

```
想定：「副業 始め方」
実際のクエリ：「副業 会社にバレない」
→ 語彙と見出しに「届け出」「就業規則」を織る（問いに合わせる）
```

語彙選びは、一度きりの作業ではありません。第6章の第2の返球を見て、ペルソナの辞書を更新し続けます。

## 語彙は、問いへの返球の最短経路

> この節の要点：語彙表を作り、表層の言葉をペルソナの問いに届く形へ置き換える。

### この節の整理

- ペルソナシートから「読者の辞書」を逆算する
- 表層・裏層・禁則の三層で語彙を管理する
- 専門用語は初出定義、以降は読者の負荷に合わせる
- 第6章のクエリで語彙表を更新する

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 業界用語で権威性を演出 | 空の証明書（7-3節） | 問いへの応答で示す |
| キーワードの詰め込み | 不自然な語彙 | 第5-4節の自然な配置 |
| カタカナ語の連打 | スキャン困難 | 和語・具体動詞へ |
| ペルソナと無関係な流行語 | トーンの崩れ | ボイス（8-1節）に照合 |
