# 用語集

> 本書で使用する主要用語の定義です。五十音順で追加していきます。

| 用語 | 読み | 定義 |
|---|---|---|
| E-E-A-T | イーイーエーティー | Experience（経験）、Expertise（専門性）、Authoritativeness（権威性）、Trustworthiness（信頼性）。本書では「情報の正当性を世界に宣言する証明書」（第7章）。検索エンジンへの最適化のチェックリストではない |
| 検索エンジンへの最適化 | エスイーオー | 本書では、検索エンジンのAI（インデクサー）に情報の構造と価値を正しく伝える「構造化の通信規格」 |
| クローラビリティ | クローラビリティ | 検索エンジンのクローラーがサイトを迷わず巡回できる度合い。工場ラインの「通路」に相当 |
| CTA | シーティーエー | Call To Action（行動喚起）の略。読者に取ってほしい次の行動を促す要素 |
| 検索 | けんさく | 本書においては、検索エンジンの検索窓に限らず、SNSのハッシュタグ検索、AIへの質問、アプリ内の情報探索など、「日常のあらゆる問いを解消する行為」を指す |
| 検索意図 | けんさくいと | 読者が問いの入り口（検索窓、ハッシュタグ、AIプロンプト等）に文字を打った「理由」。何を知りたい・達成したいか |
| 情報の通り道 | じょうほうのとおりみち | 読者が最小のストレスで答えに辿り着けるよう、見出し・段落・リンク等で設計する情報の経路 |
| 情報のマッピング | じょうほうのマッピング | 検索エンジンがHTMLの印（見出し・title・meta等）から組み立てる、ページの「意味地図」。問いと答えの対応を正しく伝える「構造化」の成果 |
| 滞在時間 | たいざいじかん | ページに留まった時間。本書では、「答えとして有用だったかもしれない」という適合信号の一つとして理解する（Dwell Time） |
| 直帰率 | ちょっきりつ | 1ページだけ閲覧してサイトを去る割合。本書では、「問いに対する答えとして不適合かもしれない」という信号としても理解する |
| 離脱 | りだつ | 本書では単なる途中離脱ではなく、「タブを閉じた瞬間にあなたの物語が読者の世界から消滅すること」を指す。離脱を防ぐことは、情報の設計士にとって読者への最大の敬意であり、設計の最終目的。検索エンジン検索経由の場合、「直帰・短い滞在」として検索エンジンに不適合信号になり得る |
| スクリーニングゲート | すくりーにングゲート | 見出しの機能。読者が「この関所を通る価値があるか」を0.5秒で判断する最初の関門 |
| 第2の返球 | だい2のへんきゅう | 記事公開後、読者の行動データやSearch Consoleのクエリなど、読者・システムが設計士に送り返す信号。「精密検査(6)の対象」。第2章の「返球」の継続 |
| 精密検査 | せいみつけんさ | 比喩の階段における「第6章」の位置づけ。第2の返球を、整備士の故障診断のように読み解き、改善の段取りを決める工程 |
| PREP法 | プレップほう | Point（結論）→ Reason（理由）→ Example（具体例）→ Point（結論）の論理展開フレーム。手紙の型（第1章）の基本 |
| 逆ピラミッド | ぎゃくピラミッド | 重要な情報を先頭に置き、詳細を後半に流す構成。情報の「出口を上に置く」導管設計 |
| 予兆検知 | よちょうけんち | 整備士が走行中の異音・メーター異常から故障を察知する技術。本書ではCTR低下・直帰上昇・クエリズレなど「第2の返球」の読み取りにマッピングする（第6章） |
| リライト | りらいと | 既存のあなたの物語を改善・更新する作業。第6章の精密検査後の「修理」に相当 |
