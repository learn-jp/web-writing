## 発展課題（任意）

第6章・第7章・第11章・第14章の演習を同じ記事で提出し、本書全体の接続図を1枚描いてください。

```
本編：問い → 導管 → 玄関 → 物流 → 精密検査 → 証明書
応用編：声 → 媒体 → 修理 → 戦略 → ワークフロー → 測定
```

どの章の改善が、どの指標に効くかを線で結んでください。
