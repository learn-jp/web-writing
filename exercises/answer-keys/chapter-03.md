## 演習 2. Must / Must Not

「Must」

1. 初心者向け副業を3つに絞って紹介
2. 就業規則・確定申告の確認ポイント
3. 今週末に登録まで進む手順

「Must Not」

1. 法人設立・税務の詳細
2. 「誰でも月10万」などの煽り
3. 特定ツールの上級テクニック

## 演習 4. PREP骨格（H2-1の例）

### H2-1：初心者向け｜在宅で週末だけ試せる副業3選

| 要素 | 一行メモ |
|---|---|
| P | 初心者は、ライティング・データ入力・ハンドメイドの3つから1つ選ぶのが現実的 |
| R | いずれも初期費用0〜低く、週末2〜5時間から始められるため |
| E | 比較表（種類・費用・時間・在宅可否）＋各1行の説明 |
| P | まず1つに絞り、次のH2で就業規則を確認してから登録へ |
| リスト/表/図 | 「比較表」 |

### H2-3：今週末に登録まで進む4ステップ

| 要素 | 一行メモ |
|---|---|
| P | 就業規則確認→1つ選ぶ→アカウント登録→プロフィール入力の4ステップ |
| R | 順番を守ると、後戻りと不安が減るため |
| E | 「番号付きリスト」＋登録画面のスクリーンショット |
| P | 今週末中にステップ2まで完了を目標に |
| リスト/表/図 | 「番号リスト＋図」 |

## 発展課題の例（H2-1のP・第1段落）

> 副業を始めるなら、まず在宅で週末だけ試せる種類を1つ選びましょう。初心者向けには、クラウドソーシングのライティング、データ入力、ハンドメイド販売の3つが現実的です。いずれも初期費用を抑えられ、本業の合間に始めやすい選択肢です。
