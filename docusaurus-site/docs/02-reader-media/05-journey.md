# 2-5　あなたの物語が読者に届くまでの道のり

最後に、第2章を締めくくる話をします。

あなたが文章を書く。  
それが読者に届く。  
その間には、実はいくつかの「道のり」があります。

まず、あなたの文章は、検索エンジンやSNSのアルゴリズム、AIといった「機械の目」に読まれます。

機械は、あなたの文章を見て、こう判断します。

「これは誰のどんな問いに答える文章か」  
「この文章は信頼できるか」  
「この文章を誰に届けるべきか」

機械の目が「届けるべき相手」と判断した読者の元に、あなたの文章は運ばれます。

次に、読者がスマホやPCの画面で、あなたの文章に出会います。

ここで読者は、ほんの数秒で判断します。

「これは自分のための文章か」  
「読む価値はあるか」

「ある」と感じれば、読み始めます。  
「ない」と感じれば、タブを閉じます。

そして、読み始めた読者は、スキャンしながら自分の問いに合う部分を探します。

見つかれば、じっくり読み込みます。  
心が動けば、シェアします。  
さらに深く知りたいと感じれば、あなたの他の記事も読みに来ます。

そうやって、あなたという書き手のファンが、一人ずつ生まれていきます。

---

この道のりを、もう一度見てください。

機械の目に理解されること。  
読者の関心を掴むこと。  
読者の心を動かすこと。  
読者をファンにすること。

これら全てに、Webライティングの技術が関わっています。

「文章を書くだけ」ではなく、「届くまでの全体を設計すること」。

これが、新時代のWebライティングです。

第3章からは、この道のりを成立させるための、具体的な技術に入っていきます。
