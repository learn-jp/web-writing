# 2-5 メディアの種類別の書き方（ブログ・コーポレート・EC・SNS）

同じWeb上でも、ブログ、企業サイト、商品ページ、SNSでは「読者が期待する返球」がまったく違います。SNS用の短いトーンでコーポレートサイトを書いていたら、読者は「公式情報として信頼できるか」と迷うかもしれません。手紙にも便種があり、届け先（メディア）によって返球の型が変わります。

## 同じWebでも、便の種類は違う

> この節の要点：ブログ・コーポレート・EC・SNSはいずれもWeb上の文章だが、読者が期待するトーン・長さ・行動は異なる。第1章の三つの目的と組み合わせて設計する。

読者が「問い（ボール）」を投げてくる場所は、必ずしも「ブログ記事」ではありません。

- 企業の「コーポレートサイト」のコラム
- 「ECサイト」の商品説明
- 「SNS」の投稿やリンク先
- 個人・メディアの「ブログ」

いずれもWeb上の文章ですが、読者が期待する「トーン」「長さ」「行動」は異なります。第1章の「3つの目的（情報・共感・行動）」と組み合わせて、メディアごとの設計を押さえましょう。

## ブログ（オウンドメディア）での書き方

> この節の要点：ブログは特定テーマについて深く継続的に学べる場所。検索意図に直接応える返球が中心で、内部リンクと更新・リライトを意識する。

「読者の期待」：特定テーマについて、「深く・継続的に」学べる場所。

「発見との関係」：検索を入口にした流入が多いが、SNSからのリンクやAI引用経由も増えている。いずれの入口でも「検索意図に直接応える」返球が中心。

「書き方の要点」：

| 項目 | 方針 |
|---|---|
| 検索意図 | 記事ごとに明確に。Know/Do/Buyを1記事1意図に近づける |
| 構成 | 見出し階層、内部リンクで関連記事へつなぐ |
| トーン | 著者・メディアの声を保ちつつ、ペルソナに合わせる |
| 更新 | 情報が古くなりやすいテーマは更新日・リライトを意識（第11章） |

「手紙の比喩」：定期便の手紙。同じ差出人から、テーマ別に届く。「続きが読める」信頼関係を築く。

---

## コーポレートサイト（企業サイト・サービスページ）での書き方

> この節の要点：コーポレートサイトでは信頼と公式情報が期待される。結論ファースト、ブランドガイドラインに沿った敬体、実績・出典・監修情報で信頼性を示す。

「読者の期待」：「信頼」と「公式情報」。誇大表現より正確さ。

「発見との関係」：ブランド名＋サービス名（Go型）や、BtoBの比較検討（Buy型）が多い。検索を入口に、SNSや口コミからの流入も想定する。

「書き方の要点」：

| 項目 | 方針 |
|---|---|
| 検索意図 | Go型なら迷わない導線。Buy型なら比較材料とFAQ |
| 構成 | 結論ファースト。忙しい決裁者もスキャンで要点を掴める |
| トーン | ブランドガイドラインに沿う（第8章）。敬体が基本 |
| 信頼性 | 実績、導入事例、出典、著者・監修情報（第7章） |

「手紙の比喩」：会社からの「公式文書」。格式と正確さが、返球の信頼性になる。

---

## EC（商品ページ・カテゴリ説明）での書き方

> この節の要点：ECでは「買うかどうか」の判断材料が期待される。比較・不安解消・具体的メリットを示し、CTAまでの迷いを減らす。

「読者の期待」：「買うかどうか」の判断材料。スペック、使い方、レビュー相当の情報。

「発見との関係」：Buy型が中心。「○○ おすすめ」「○○ 口コミ」からの検索流入に加え、SNSのレビュー投稿からの導線も多い。

「書き方の要点」：

| 項目 | 方針 |
|---|---|
| 検索意図 | 比較・不安解消・具体的メリット |
| 構成 | ファーストビューに核心。スペック表、FAQ、レビューへの導線 |
| トーン | 押し売りより「選び手の立場」で。デメリットも誠実に |
| 行動 | CTA（カートに入れる、購入）までの迷いを減らす |

「手紙の比喩」：商品カタログ付きの「案内状」。「これが欲しかった」と思わせる返球。

---

## SNS（投稿文・リンク先の記事）での書き方

> この節の要点：SNSでは短い刺激と興味があれば深掘り。共感・体験型の問いが多く、投稿は短いフック、リンク先で本返球につなぐ。

「読者の期待」：「短い刺激」と、興味があれば深掘り。タイムライン上では一瞬で判断。

「発見との関係」：ハッシュタグ検索やフィード内探索では、「共感・体験型」の問い（第2-1参照）が多い。SNSが第一の入口となり、リンク先記事で Know/Do 型の本返球につなぐ構図が基本。

「書き方の要点」：

| 項目 | 方針 |
|---|---|
| 投稿文 | 1投稿1メッセージ。リンク先で詳細 |
| リンク先 | SNSから来た読者は「文脈が薄い」 → リードで「何の記事か」を明示 |
| トーン | プラットフォームの文化に合わせる（X、Instagram、LinkedIn等） |
| 長さ | 投稿は短く。長文はnoteやブログへ |
| 意図 | 「共感・体験型」。体験談・感情から入り、本編へつなぐ |

「手紙の比喩」：便箋に書いた「短いメモ」。「詳しくは添付の手紙を」と本編へつなぐ。寿司職人がカウンター越しに一言で心を掴み、本編の握りへ導くイメージです。

## メディアを跨いだ一貫性の設計

> この節の要点：同じ企業が複数メディアを運営する場合、返球のトーンは揃えつつ深さと長さはメディアに合わせる。SNS→ブログ→サービスページの連続性がジャーニーになる。

同じ企業がブログ・コーポレート・SNSを運営する場合、「返球のトーン」は揃えつつ、「深さと長さ」はメディアに合わせて変えます。

```
SNS投稿     →  フック（共感・疑問）
     ↓
ブログ記事  →  検索意図への本返球（Know/Do）
     ↓
サービスページ →  行動（Do/Buy）への後押し
```

ボールは一度きりではありません。「同じ読者が、別の場所で再度ボールを投げてくる」。その連続性が、次節の「読者ジャーニー」です。

---

### メディア別の書き方のポイント

- メディアごとに読者の「期待する返球の型」が異なる
- ブログ：検索意図への深い返球。コーポレート：信頼と公式性
- EC：Buy型の判断材料。SNS：短いフックとリンク先の本返球
- トーンは統一、「深さと長さ」はメディアで調整。発見の入口はメディアごとに異なる

### メディア別の書き方でよくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| コーポレートにブログ並みのカジュアルさ | 信頼を損なう | ブランドガイドに沿った文体 |
| ECページがスペックだけ | Buy型の不安に答えていない | FAQ、使い方、比較ポイントを追加 |
| SNSから来た読者向けの文脈なし | リンク先で「何の話？」 | リードで流入元を意識した書き出し |
| 全媒体で同じ長さ | 読まれない・読まれにくい | メディアごとに情報量を設計 |
