# 2-3　読者の読み方

ペルソナを思い描けたら、次は「その人がどう読むか」を知ります。

実は、Webの読者は、文章を「読んで」いません。

正確に言うと、最初から最後まで丁寧に読むことは、まずありません。

ではどうしているか。

まず、ページをパッと開いて、上から下へ視線を走らせます。

これを「スキャン」と呼びます。

太字、見出し、画像、リストといった、目立つ要素だけを拾い読みする。  
そこで「自分の問いに答えてくれそうか」を一瞬で判断します。

次に、関心のある部分だけを「ジャンプ」して読みます。

たとえば「在宅勤務の始め方」の記事を読む人が、「机の選び方」という見出しに惹かれたら、その章だけを読む。  
冒頭から順に読むことはあまりありません。

そして、つまらないと感じた瞬間、「離脱」します。

タブを閉じる。  
別の記事を開く。  
スマホをスクロールして次の投稿に行く。

これが、Webの読者の現実です。

冷たく感じるかもしれません。  
しかし、これを責めることはできません。

なぜなら、私たち自身も、他の人の記事を読むときに同じことをしているからです。

この現実を受け入れた上で、書き手ができることは何でしょうか。

答えは、こうです。

スキャンに耐える文章を書く。

見出しだけで内容がわかる。  
太字だけ追えば要点が掴める。  
最初の3行で「ここに自分の求める答えがある」と確信できる。

そんな文章を書ければ、読者は「ちゃんと読んでみよう」と腰を据えてくれます。

逆に、ダラダラと長い段落が続く文章は、スキャンの段階で離脱されます。

Webの文章は、まず「見られる」ものであり、その次に「読まれる」もの。

この順番を、絶対に間違えないでください。
