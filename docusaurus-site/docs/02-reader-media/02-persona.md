# 2-2　ペルソナと読者像の設定

「読者の問いに応える」と言われても、読者は無数にいます。

その全員に応えるのは不可能です。

だから、書き手は「たった一人の読者」を頭に思い浮かべて書きます。

これを「ペルソナ」と呼びます。

ペルソナとは、あなたの文章を読む「具体的な一人の人物像」のことです。

たとえば、こんな具合に。

- 名前：山田さん（仮名）
- 年齢：32歳
- 仕事：都内のIT企業勤務、エンジニア4年目
- 状況：来月から完全在宅勤務になることが決まった
- 不安：家で集中できるか、運動不足にならないか、孤独にならないか

ここまで具体的に思い描けると、文章の書き方が変わります。

「在宅勤務には自己管理が大切です」という抽象的な一文ではなく、  
「山田さんのように、これまでオフィスでメリハリをつけて働いてきた方ほど、家での切り替えが難しく感じるはずです」という具体的な語りかけになる。

読者は、自分のことを書かれていると感じた瞬間、文章に引き込まれます。

ペルソナを設定する時のコツは1つだけ。

実在する誰かを思い浮かべることです。

架空の人物を一から考えようとすると、なぜか平均的でつまらない人物像になりがちです。  
それよりも、友人、家族、過去の自分、知り合いの誰か。  
実在する人を思い浮かべて、その人に語りかけるつもりで書く。

その方が、文章に温度が宿ります。
