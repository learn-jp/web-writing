# 2-1　読者の「問い」を読み解く

文章を書く前に、まず考えたいことがあります。

それは、読者があなたの言葉に出会う「その瞬間」、何を求めているのか。

人は、暇つぶしであなたの記事を開いたわけではありません。  
何か知りたいこと、解決したい悩み、満たしたい好奇心があるから、画面の前に座っているのです。

これを「問い」と呼びます。

たとえば、誰かが「在宅勤務 始め方」と検索したとします。

この人の本当の問いは、何でしょうか。

「在宅勤務を始めるための手順を知りたい」  
これは表面的な問いです。

その奥には、もっと深い問いが隠れています。

「自分にも在宅勤務ができるだろうか」  
「会社にどう切り出せばいいだろうか」  
「在宅勤務で本当に成果を出せるだろうか」

読者は、手順だけを知りたいのではありません。  
不安を解消したい。背中を押してほしい。失敗したくない。

そういう感情を抱えて、検索窓に言葉を打ち込んでいるのです。

この「奥の問い」に応えられる文章だけが、読者の心に届きます。

そして、忘れてはいけないことがあります。

「問い」は検索エンジンだけで生まれるものではありません。

最近の若い世代は、おいしいレストランを探すときに、検索エンジンではなくInstagramを開きます。  
「カフェ 渋谷」とSNS内で検索する。  
そこで見つけた写真の雰囲気から、お店を決める。

これも立派な「問い」です。

問いの形は、時代と共に変わります。  
しかし、人が何かを求めて言葉に触れる、その本質は変わりません。

あなたが書く文章は、誰のどんな問いに答えるものなのか。

ここを見失わなければ、文章は必ず誰かに届きます。
