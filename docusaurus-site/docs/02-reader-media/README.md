# 第2章 読者とメディアを理解する

> 第1章からの接続：第1章で、Webライティングは「敬意ある手紙」であり、離脱は「タブを閉じた瞬間、記事が自分の頭から消える」ことだと学びました。手紙に宛名を書く前に、「誰が、なぜ、どんな問いを投げたのか」を読み解く。それが本章の仕事です。

> この章で学ぶこと
> - 「検索」の広い定義（検索エンジン、SNS、AI、アプリ内探索）と検索意図の読み解き方
> - ペルソナ（誰に向けた手紙か）を実務的なステップで設定する
> - プラットフォームの特性に応じた「情報の通り道」の設計。「タブを閉じる前に答えへ届ける」
> - 自分が「開いてすぐ戻る」「読み続ける」を選ぶことは、問いとの適合度を映す鏡であり、その結果として検索・AIの評価にも反映され得る理由

本章の核となるメッセージ

> 検索とは、日常のあらゆる「問い（ボール）」を解消する行為である。Webライティングとは、その問いを正確にキャッチし、「タブを閉じて忘れる前に」、答えに辿り着ける通り道を設計する対話である。問いに答えられたかという事実は、その対話の「適合度を映す鏡」でもある。「道具と段取りを整える設計士」が、問いの向こうにいる「人」を見失わないための章です。
