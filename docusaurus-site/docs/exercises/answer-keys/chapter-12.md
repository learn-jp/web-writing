```
  ↓

```

## 採点の目安

- クラスターにハブ1＋スポーク5以上。役割が明確か
- カレンダーに新規・リライト・更新が区別されているか
- リライト枠（月2〜3本）が確保されているか
- Must/Won't が定義され、根拠が1行あるか
- 第2章ジャーニー・第5章リンク・第6章データとの接続が説明できるか
- Won't を書いているか（書かないと計画が過積載になりやすい）
