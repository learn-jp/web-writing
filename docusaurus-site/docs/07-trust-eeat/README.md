# 第7章 信頼とE-E-A-T、情報の正当性を証明する

> 第6章からの接続：精密検査で「どこを直すか」は見えた。しかし、直したあとも、読者・SNS・生成AIが問い続ける。「この情報は、正しいのか？ 信頼できるのか？」 第7章は、その問いに、世界に対して宣言する章です。

> この章で学ぶこと
> - E-E-A-Tを品質チェックリストではなく、「情報の正当性を世界に宣言する証明書」として理解する
> - 自動車整備士として国家資格を取得し、現場で技術を磨いてきた経験。それ自体が最大のE-E-A-Tである
> - 専門性は専門用語の羅列ではない。問い（ボール）に、現場の知恵で責任を持って応えること
> - 根拠・著者・更新。証明書の記載事項を設計する
> - 寿司職人の誠実なもてなしと、設計士としての生き方。テクニックを超えた技術者の矜持

本章の核となるメッセージ

> E-E-A-Tは、検索エンジンへのお世辞でも、AIへの迎合でもない。「この情報は正しい」と、読者・SNS・生成AIのすべてに向けて宣言するための証明書である。
