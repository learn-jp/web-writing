# 7-4 証明書の記載事項、根拠・著者・更新

整備記録簿が空白の欄だらけなら、誰も信頼しません。Web記事も同じです。第5章（Web最適化）で触れた実務リストを、証明書の記載事項として再整理します。執筆時から設計する。それが、本章の基本姿勢です。

## 整備記録簿の記載事項

> この節の要点：著者・監修者・出典・更新日・利益開示は、整備記録簿と同型の記載事項である。後付けより、執筆時から設計する。

Web記事のE-E-A-Tは、整備記録簿と同型です。次の表で、記載事項と実務の対応を確認してください。

| 記載事項 | 対応するE-E-A-T | 実務 |
|---|---|---|
| 著者名・プロフィール | Experience, Expertise, Authoritativeness | 著者ページ、記事末尾 |
| 監修者（該当時） | Expertise, Authoritativeness | 資格・所属を明示 |
| 出典・引用 | Trustworthiness | 政府、研究、公式へのリンク |
| 更新日・改訂履歴 | Trustworthiness, Experience | 2026年6月更新 |
| 利益相反の開示 | Trustworthiness | アフィリエイト、広告、スポンサー |
| 連絡先 | Trustworthiness | 問い合わせフォーム、運営者情報 |

後付けより、執筆時から設計する。第1章の公開前に構造を確かめると同じ。証明書も、出荷前に欄を埋めます。寿司職人がネタの産地と鮮度を客に伝えるように、著者・出典・更新日は、あなたの物語への信頼のラベルです。

---

## 出典、他人の部品番号を借りる

> この節の要点：「言われている」は証明書に載せられない。誰が・いつ・何を調べたか、検証可能な形で残す。

自動車整備士が部品を交換するとき、メーカー番号を記録簿に書きます。根拠のない部品は使いません。

Web記事で他人の主張を引用するとき。

```
✓ 「総務省の調査（2025年）によると、副業者は〇〇%増加しています。
    （出典：総務省「副業・兼業に関する調査」リンク）」
✗ 「最近、副業する人が増えていると言われています。」
```

言われているは、証明書に載せられません。誰が、いつ、何を調べ、何と結論づけたか。検証可能な形で。

### 出典の優先順位

1. 一次情報（政府、公式、原著論文）
2. 権威ある二次情報（大手メディア、専門機関）
3. 自分の一次体験（第7-3節）

4以下（匿名掲示板、出典不明のまとめサイト）は、Trustworthinessを損なう。使うなら、補足に留め、主張の根拠にはしない。

## 著者情報、誰が整備したか

> この節の要点：著者不明は署名のない整備記録簿と同じ。肩書きだけでなく、具体的事実付きのプロフィールが必要である。

著者不明の記事は、整備記録簿に署名がない状態です。

最低限：

```
著者：山田 太郎
プロフィール：Webマーケティング歴8年。
              月100本規模の記事監修、Search Console運用を担当。
```

具体的事実（第7-2節）。肩書きだけの一行は、欄の半分しか埋まっていません。

組織名義の記事では、執筆者または監修者を明示する。工場の看板だけでは、誰の手で整備されたかわかりません。

---

## 更新、証明書に有効期限がある

> この節の要点：一度書けば終わりではない。更新日と改訂履歴を残し、誤りの訂正もTrustworthinessの証である。

整備記録簿に2020年整備とだけ書いて、6年間更新がなければ、その記録は参考程度です。制度、価格、ツール、法律。Webの情報は腐ります。

```
最終更新：2026年6月15日
改訂内容：インボイス制度2024年対応を反映
```

第6章の精密検査で鮮度を疑ったとき、更新日がない記事は、リライト優先度が上がります（第11章）。

誤りを訂正した事実も、Trustworthinessの証です。2026年6月：〇〇の記述を訂正しました。自動車整備士が記録簿に訂正を残すのと同じです。

---

## 利益相反、隠さない

> この節の要点：アフィリエイトやスポンサーを隠すと、証明書は偽造になる。明示された利益相反の方が、読者は信頼する。

アフィリエイトリンク、広告、スポンサー記事。隠すと、証明書は偽造になります。

```
「本記事には、アフィリエイトリンクが含まれます。
  紹介する商品は、執筆者が実際に使用したものです。」
```

読者は、隠された利益相反より、明示された利益相反の方を信頼します。寿司職人が「今日は仕入れ値が上がっています」と正直に伝える誠実さと同根です。

---

## 記載事項チェックリスト

> この節の要点：公開前に、著者・出典・更新・利益開示・監修者の欄を、チェックリストで最終点検する。

公開前に、証明書の欄を確認します。

```
□ 著者名と、Experience/Expertiseが伝わるプロフィール
□ 数値・事実に出典（または一次体験の明示）
□ 更新日（または初版日＋更新日）
□ 利益相反の開示（該当時）
□ 連絡先または運営者情報（About）
□ 引用の転載ではなく、自分の言葉での再構成
□ 監修者（YMYL・専門領域で該当時）
```

---

### ポイント

- 出典・著者・更新＝証明書の記載事項
- 言われているは載せられない。検証可能な形で
- 著者は具体的事実付き。肩書きだけは不十分
- 更新・訂正を記録に残す＝Trustworthiness
- 利益相反は隠さず開示

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 出典なしの統計 | 検証不能 | 公式リンク |
| 著者「編集部」のみ | 誰の経験か不明 | 執筆者・監修者を明示 |
| 更新日なし | 鮮度不明 | 更新日を載せ、リライト |
| アフィリエイト隠し | 信頼崩壊 | 冒頭または末尾で開示 |
