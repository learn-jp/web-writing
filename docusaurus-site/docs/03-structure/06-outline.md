# 3-6　構成案の作り方

ここまでの話を、実際の執筆プロセスに落とし込みましょう。

長い文章を書く前に、必ず作ってほしいものがあります。  
それが「構成案」です。

構成案とは、本文を書く前に作る「設計図」のことです。

たとえば「在宅勤務の始め方」という記事を書くなら、こんな構成案を作ります。

タイトル：はじめての在宅勤務、まず何から始めればいい？

この記事で伝えたいこと：在宅勤務初心者が、最初の1ヶ月をスムーズに乗り切るためのステップ

読者ペルソナ：来月から完全在宅勤務が始まる、32歳のIT企業勤務エンジニア

構成：

- 導入：在宅勤務、楽しみと不安が入り混じる気持ち
- H2：始める前に確認すること
  - 会社の制度
  - 家族との話し合い
- H2：環境を整える
  - 机と椅子
  - ネット回線
- H2：最初の1週間の過ごし方
  - 時間の使い方
  - 集中するコツ
- まとめ：在宅勤務を成功させる、たった1つのコツ

ここまで作ってから、本文を書き始めます。

なぜこれが大切か。

構成案がないまま書き始めると、書きながら考えることになります。  
「次は何を書こう」と迷う時間が増え、文章が散らかります。

逆に、構成案ができていれば、本文を書く作業は「肉付け」だけになります。  
迷いがなくなり、書くスピードも上がります。

---

構成案を作る時のコツは1つ。

読者が知りたい順番に並べることです。

書き手が伝えたい順番ではなく、読者が知りたい順番。  
ここを間違えると、構成案を作っても文章は届きません。

「読者は何を最初に知りたいか」  
「次に何を知ると安心するか」  
「最後に何を持ち帰りたいか」

この問いを自分に投げかけながら、構成案を組み立ててください。
