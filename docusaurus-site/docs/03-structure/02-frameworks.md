# 3-2　記事構成の基本フレーム

長い文章を書く時、いきなり書き始めると迷子になります。

「次に何を書こう」「ここで結論を出すべきか」「この話はどこに入れよう」。  
書きながら考えていると、文章が散らかります。

これを防ぐために、書き始める前に「型」を決めておく方法があります。

代表的な型を2つ紹介します。

## PREP法

PREP（プレップ）法は、短い文章にも長い文章にも使える、万能の型です。

- Point（結論）：まず、伝えたいことを1行で
- Reason（理由）：なぜそう言えるのか
- Example（具体例）：たとえば、こんな場面で
- Point（結論）：だから、結論はこうです

たとえば「在宅勤務には、専用の椅子を買うべきだ」という主張を書く時。

結論：在宅勤務には、専用の椅子を買うべきです。  
理由：なぜなら、1日8時間以上座る環境で、椅子の質が体調を左右するからです。  
具体例：私自身、最初の半年は普通のダイニングチェアで仕事をして、ひどい腰痛になりました。  
結論：だから、在宅勤務を始めるなら、まず椅子に投資してください。

短くまとまっていて、説得力もあります。

## 逆ピラミッド型

逆ピラミッド型は、ニュース記事でよく使われる型です。

- 冒頭：もっとも大切な結論
- 次：それを補強する重要な情報
- その次：詳細や背景

「大切なことから順に書く」のがポイントです。

なぜこの型が Webと相性がいいか。  
それは、読者が途中で離脱しても、最初の数行で「大切なこと」が伝わるからです。

逆に、結論を最後に持ってくる「起承転結」型は、Webには向きません。  
読者は、結論にたどり着く前にタブを閉じます。

---

どちらの型を使うかは、書く内容によって変わります。

「主張」を伝えたい時は、PREP。  
「情報」を伝えたい時は、逆ピラミッド。

このくらいの使い分けで十分です。
