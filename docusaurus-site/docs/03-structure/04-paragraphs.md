# 3-4　段落・文の長さと改行のルール

文章は、見出しだけでは成立しません。  
見出しの下にある「本文」も、読みやすく書く必要があります。

Webの本文で意識したいのは、3つのことです。

## 1. 一文を短く

長い一文は、Webでは嫌われます。  
スマホで読む読者にとって、長文は壁です。

目安として、一文は60文字以内。  
50文字を超えそうになったら、句点で区切ることを考えてください。

## 2. 一段落を短く

紙の本では、段落は5〜10行になることもあります。  
Webでは、それは長すぎます。

段落は、3〜4行を目安に。  
1〜2行の段落があっても、まったく問題ありません。

## 3. 改行でリズムを作る

文と文の間に改行を入れることで、読み手にリズムが生まれます。

たとえば、こう書くと、文章が詰まって読みづらい。

「在宅勤務には、専用の椅子を買うべきです。なぜなら、1日8時間以上座る環境で、椅子の質が体調を左右するからです。私自身、最初の半年は普通のダイニングチェアで仕事をして、ひどい腰痛になりました。だから、在宅勤務を始めるなら、まず椅子に投資してください」

これを改行で区切ると、読みやすくなります。

「在宅勤務には、専用の椅子を買うべきです。

なぜなら、1日8時間以上座る環境で、椅子の質が体調を左右するからです。

私自身、最初の半年は普通のダイニングチェアで仕事をして、ひどい腰痛になりました。

だから、在宅勤務を始めるなら、まず椅子に投資してください」

同じ内容なのに、後者の方がスッと頭に入ってきませんか。

Webの文章は、文章だけでなく「余白」もデザインです。  
余白を恐れず、たっぷり使ってください。
