# 3-3　見出し階層の設計

長い文章には、必ず見出しが必要です。

見出しは、読者にとっては「目次」であり、機械にとっては「文章の地図」です。

見出しには階層があります。

- H1：記事全体のタイトル（1つだけ）
- H2：大きな章（複数）
- H3：H2の中の節（複数）
- H4：H3の中の細かい項目（必要に応じて）

この階層を、正しく使うことが大切です。

たとえば、こんな構造の記事を想像してみてください。

H1：在宅勤務の始め方  
　H2：始める前に確認すること  
　　H3：会社の制度をチェック  
　　H3：家族との話し合い  
　H2：環境を整える  
　　H3：机と椅子  
　　H3：ネット回線  
　H2：実際に始めてから

この階層を見るだけで、記事全体の流れが把握できます。  
これが「読者にとっての目次」です。

一方で、機械も同じ階層を読み取って、「この記事は在宅勤務についての記事で、主に3つのトピックを扱っている」と理解します。  
これが「機械にとっての地図」です。

---

見出しを使う時の注意点を、いくつかお伝えします。

## 1. 階層をスキップしない

H1の次にいきなりH3を使ったり、H2の中にH4を使ったりしないでください。  
階層は順番に使います。

## 2. 見出しだけで内容がわかるようにする

「その他」「補足」のような曖昧な見出しは避けましょう。  
スキャンしている読者は、見出しで内容を判断します。

## 3. デザインのために見出しを使わない

「ここを目立たせたいから」という理由で見出しタグを使うのは避けてください。  
機械が混乱します。

これらを守るだけで、あなたの文章は格段に読まれやすくなります。
