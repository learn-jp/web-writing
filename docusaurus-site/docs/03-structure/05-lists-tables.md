# 3-5　リスト・表・図版の使い分け

文章だけで伝えるのが難しい時、補助的な要素を使うと効果的です。

## リスト（箇条書き）

並列の情報や手順を伝える時に使います。

たとえば「在宅勤務に必要なもの」を文章で書くと、こうなります。

「在宅勤務には、机と椅子とネット回線が必要です。さらに、できればモニターと、Webカメラと、マイクもあった方がいいでしょう」

これをリストにすると：

- 机
- 椅子
- ネット回線
- モニター（あれば）
- Webカメラ（あれば）
- マイク（あれば）

一目で全体が把握できます。

---

〜もうちょっと深掘り〜

機械の目には、リストはこう見えています。

```html
<ul>
  <li>机</li>
  <li>椅子</li>
  <li>ネット回線</li>
  <li>モニター（あれば）</li>
</ul>
```

「ul」は「unordered list（順不同のリスト）」の略。  
順番が決まっている手順（1, 2, 3...）の場合は「ol（ordered list）」を使います。  
機械の目は、このタグを見て「これは並列の情報の列挙だ」と判断します。

---

## 表

複数の項目を比較する時に使います。

たとえば「ノートPCとデスクトップPCの違い」を伝えたい時、文章で書くより表にした方がわかりやすい。

| 項目 | ノートPC | デスクトップPC |
|---|---|---|
| 価格 | 中〜高 | 中 |
| 性能 | 普通 | 高い |
| 持ち運び | できる | できない |
| 拡張性 | 低い | 高い |

縦と横の関係が一目でわかります。

---

〜もうちょっと深掘り〜

機械の目には、表はこう見えています。

```html
<table>
  <tr>
    <th>項目</th>
    <th>ノートPC</th>
    <th>デスクトップPC</th>
  </tr>
  <tr>
    <td>価格</td>
    <td>中〜高</td>
    <td>中</td>
  </tr>
</table>
```

「th」は見出しセル、「td」はデータセル。  
機械の目は、この構造を見て「これは比較表だ」「縦と横にこういう関係がある」と理解します。  
だから、表は文章で同じ情報を書くより、機械にも明確に伝わるのです。

---

## 図版（画像・イラスト）

文章だけでは伝わらない「視覚的な情報」を補います。

商品の見た目、操作手順のスクリーンショット、概念図など。  
百聞は一見にしかず、という言葉通り、図版が文章を強力にサポートします。

---

ただし、リストも表も図版も、使いすぎは禁物です。

何でもリストにすると、文章が無味乾燥になります。  
何でも表にすると、読者の頭が表で疲れます。

「文章で伝わるなら文章で。文章で伝わりにくいなら、補助を使う」。  
このバランスが大切です。
