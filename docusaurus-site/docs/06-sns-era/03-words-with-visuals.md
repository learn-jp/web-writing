# 6-3　画像・動画につける言葉の力

SNSは、文字だけの世界ではありません。

画像、動画、サムネイル。  
こうしたビジュアル要素が、投稿の主役になることも多いです。

しかし、ここで誤解してはいけないことがあります。

ビジュアルが主役の投稿でも、言葉が要らないわけではありません。

むしろ、ビジュアルと言葉が組み合わさった時に、最大の力が生まれます。

---

たとえば、Instagram に料理の写真を投稿する場合を考えてみましょう。

A：写真だけ、キャプションなし。

B：写真＋「今日のランチ」

C：写真＋「在宅勤務3ヶ月目、ついに自分で作るようになったタイカレー。市販のペーストでこんなに本格的な味になるとは」

どれが、読者の心に残るでしょうか。

Aは、ただスクロールされて終わります。  
Bは、少しは目に止まりますが、すぐ忘れられます。  
Cは、写真を見た後、思わず読んでしまう。そして「自分も作ってみようかな」と思います。

ビジュアルと言葉、両方が必要なのです。  
そして、その言葉が「書ける人」と「書けない人」で、SNSでの存在感が変わります。

---

YouTubeも、同じことが言えます。

動画そのものが主役のメディアでも、文字が果たす役割は大きいです。

- 動画タイトル：検索結果やおすすめに表示される最初の接点
- サムネイルの文字：クリックを決定づける最大の要素
- 概要欄：視聴者がさらに深く知りたい時の窓口
- 字幕：聴覚に頼らず動画を理解できるようにする橋
- コメントへの返信：視聴者との関係を深める場所

これらの全てに、Webライティングの技術が活きます。

「YouTubeは動画だから、ライティングは関係ない」と思っている方は、もったいないです。  
ビジュアルの強さを、言葉でさらに引き上げることができるのに、それをやらないのは大きな損失です。

---

ビジュアルにつける言葉のコツを、3つお伝えします。

## 1. ビジュアルに説明をつけない

写真や動画で見れば分かることを、わざわざ文字で書く必要はありません。  
「青空の写真」を投稿して「青空です」と書いても、意味がありません。

## 2. ビジュアルの「向こう側」を語る

写真や動画には映っていない、書き手の感情や背景を言葉で補います。  
「ランチの写真」に「3ヶ月の試行錯誤の末にたどり着いた」と添える。  
そうすることで、ビジュアルが立体的になります。

## 3. 読者を引き込む「問い」を投げる

「あなたも試してみませんか？」  
「この味の決め手は何だと思いますか？」

問いかけは、読者を投稿の中に引き込みます。

---

〜SNSプラットフォームの目線に立ってみる〜

あなたが書いた記事を SNS でシェアした時、こんなコードが裏側で働いています。

```html
<meta property="og:title" content="在宅勤務3ヶ月で気づいた、集中力を変える朝のルーティン">
<meta property="og:description" content="コーヒーでも音楽でも変わらなかった集中力が、ある習慣で激変しました。">
<meta property="og:image" content="https://example.com/morning-routine.jpg">
```

これは「OGP（Open Graph Protocol）」と呼ばれる仕組みで、SNS でシェアされた時の見え方を決めています。

- og:title：SNSのカードに表示されるタイトル
- og:description：その下の説明文
- og:image：一緒に表示される画像

つまり、あなたが SNS でシェアした時にカードが綺麗に表示されるかどうかは、このコードが正しく書かれているかで決まります。

note やブログサービスでは、これらは自動で設定されることがほとんどです。  
ただし、og:image（画像）はサービスによって設定の手間が必要なこともあるので、シェアされた時に画像がちゃんと出るか、一度自分で確認してみてください。

SNS は短い文章で勝負する世界ですが、その短い文章を「正しく機械に伝える」コードもまた、Webライティングの一部なのです。
