# 第1章 Webライティングの基礎

> この章で学ぶこと
> - Webライティングは「文章術」であると同時に「コンピューターへの構造化」である
> - 紙とWebでは、読者の読み方と構造の責任が根本的に異なる（Webでは離脱＝タブを閉じた瞬間、記事が自分の頭から消える）
> - 現代の**Web最適化**は検索を入口に、SNS・AI（ChatGPT・Gemini等）を含む発見の設計である（第5章へ続く）
> - 自分が「開いてすぐ戻る」「読み続ける」を選ぶことは、問いとの適合／不適合として先に起き、その結果が検索エンジンやAIにも伝わりうる
> - 構造化は検索エンジン向けの小手先の技ではなく、「情報の正当性を証明するエンジニアリング」
> - 文章の目的（情報・共感・行動）が、構成と構造を決める

本章の核となるメッセージ

> Webの土台を作ることは、読者への敬意である。タブを閉じさせない設計は、その敬意の「最終目的」である。道具と段取りを整えるように構造を設計する。読者への設計が常に先にあり、その結果として検索エンジンやAIにも正しく届く。「人間味と技術の両方」が、ここから始まる。

本書第1章〜第7章は、ひとつの比喩の階段として設計されています。「手紙(1)」→「問い(2)」→「導管(3)」→「玄関(4)」→「物流(5)」→「精密検査(6)」→「証明書(7)」。第6章は、読者から返る「第2の返球」を診断する工程です。第7章で、「誠実な設計士としての生き方」まで貫きます。
