# 4-2 クリックされ、かつ誤解を生まない見出し

スクリーニングゲートは、通過率と誠実さの両立が求められます。派手なタイトルで外門だけ開け、中で自分がタブを閉じさせてはなりません。小売店の看板が派手でも中身が伴わなければ、二度と来ないのと同じです。釣りでも控えめすぎでもない、誠実な吸引力を設計することが、情報の設計士の入口設計です。

## ゲートは通過率と誠実さの両方を満たす

> この節の要点：ゲートは騙して通過させてはならない。通過後に約束と異なる内容が待つゲートは、信頼を失い、タブを閉じさせる。

第4-1節で、見出しは通過率を上げるゲートだと述べました。ここで、情報の設計士としてもう一つの制約を加えます。

> ゲートは、読者を騙して通過させてはならない。  
> 通過後に約束と異なる内容が待っているゲートは、信頼を一度で失い、タブを閉じさせる。

工場の入口看板に「安全な作業場」と書いて、中に整理されていないラインがあったら。作業者は二度とその入口を使いません。Webも同じです。

| 戦略 | 外門（H1） | 中身 | 結果 |
|---|---|---|---|
| 誠実なゲート | 約束と一致 | 約束を果たす | 信頼、出口到達 |
| 釣りゲート | 過大な約束 | 中身が伴わない | リード直後にタブを閉じる |
| 控えめすぎるゲート | 約束が弱い | 良い内容でも | 入らない（機会損失） |

あなたの仕事は、釣りでも控えめすぎでもない、誠実な吸引力を設計することです。寿司職人がネタの鮮度を誇るように、あなたは見出しで約束し、本文でその約束を果たします。

---

## クリックされる見出しには5つの要素がある

> この節の要点：具体性・対象の明示・問いとの接続・約束の範囲・新鮮さの5要素。審査②「答えがありそうか」に直結する。

外門（H1）および強い内門（H2）に共通する、技術的な要素です。あなたが書く見出しに、次の5つが含まれているか確認してください。

### 1. 具体性：抽象を数・対象・条件に

```
✗ 「副業の始め方」
✓ 「副業の始め方｜初心者が今週末に登録まで進む3ステップ」
```

具体性は、審査②「答えがありそうか」に直結します。

### 2. 対象の明示：誰のゲートか

```
✗ 「確定申告のやり方」
✓ 「副業が初めての人向け｜確定申告で押さえる3点」
```

第2章のペルソナ。ゲートに「あなた向け」と書く。

### 3. 問いとの接続：ボールの言葉を借りる

```
検索：「副業 始め方 初心者」
H1：「副業の始め方｜完全初心者が最初の1週間でやること」
```

キーワードの丸写しではなく、問いの言葉として自然に含める。

### 4. 約束の範囲：何が得られるか、何が得られないか

```
✓ 「在宅副業3選｜初期費用0円・週末2時間から」（範囲が明確）
✗ 「副業で人生が変わる」（範囲が不明・過大）
```

Must Not（第2章）に抵触する約束は、ゲート段階で排除。

### 5. 新鮮さまたは緊急性：今読む理由

```
「2026年最新」「今週末に」「始める前に」
```

嘘の緊急性（「今すぐ買わないと損」）は釣りゲート。本当のタイミングだけ。

## 公開前に誤解が生まれないか確認する

> この節の要点：H1と主要H2について、約束の果たせる性・ペルソナ適合・過大表現・競合への引きずられを公開前に確認する。

あなたが公開する前に、H1と主要H2について次を確認してください。

```
□ 見出しの約束は、記事全体で果たせるか（Must と一致）
□ ペルソナが「自分向け」と感じるか
□ 過大表現（「絶対」「100%」「誰でも」）を使っていないか
□ 中身を読まないとわからない曖昧語だけで終わっていないか
□ 競合の釣り見出しに引きずられ、約束を膨らませていないか
```

釣りゲートの典型

| 見出し | 問題 | 読者の体験 |
|---|---|---|
| 「知らないと損！副業の秘密」 | 中身は一般的な紹介 | リード後にタブを閉じる |
| 「医師も推奨！○○の効果」 | 根拠が薄い | 信頼崩壊 |
| 「【衝撃】○○の真実」 | 煽りのみ | スキップまたはタブを閉じる |

---

## 数字・括弧・記号はゲートの装備になる

> この節の要点：数字・縦棒・括弧・記号は具体性とスキャン性を高める装備。乱用は釣りに見える。

実務で使われる技法と、設計上の注意です。あなたが見出しに数字や記号を使うとき、次の表を参考にしてください。

| 技法 | 効果 | 注意 |
|---|---|---|
| 数字（3選、5ステップ） | 具体性、スキャンしやすさ | 本文で数字を必ず果たす |
| 縦棒（｜） | 副題で約束を追加 | 長くしすぎない（スマホで切れる） |
| 括弧（初心者向け） | 対象の明示 | 括弧だらけにしない |
| 【】・！ | 目立つ | 乱用は釣りに見える |

スマホの検索結果では、H1は28〜32文字前後で切れることが多い。前半に核心を置く。

---

## 外門（H1）と内門（H2）の吸引力のバランス

> この節の要点：H1だけ派手でH2が弱いと、外門通過後に中でタブを閉じる。第3章のアウトラインH2をすべてゲートとして言い換える。

あなたが設計するH1とH2は、役割が異なります。外門だけ派手にして、内門を弱くすると、中でタブを閉じやすくなります。

| 要素 | 外門 H1 | 内門 H2 |
|---|---|---|
| 役割 | 記事全体への入場 | セクションへの入場 |
| 吸引力 | やや強め（競争が激しい） | やや具体的（答えの予告） |
| 誠実さ | 記事全体の約束 | そのセクションの約束 |
| 失敗時 | クリックされない | スキップまたはタブを閉じる |

H1だけ派手で、H2が「背景」「詳細」。内門が弱いと、外門を通過したあと、中でタブを閉じます。第3章のアウトラインのH2を、すべて第4章のゲートとして言い換えてください。

---

## プラットフォームごとに外門の設計が変わる

> この節の要点：検索・SNS・AI引用で外門の場所と設計重点が異なる。SNSから来た読者にはリンク先H1・リードがSNSの約束の続きである必要がある。

あなたの物語が届く場所によって、外門の設計重点が変わります。

| プラットフォーム | 外門の場所 | 設計の重点 |
|---|---|---|
| 検索エンジン | タイトル（H1）＋メタ説明 | 問いとの一致、具体性（第5章） |
| SNS | 投稿文＋リンク先タイトル | 共感型ゲート、短いフック |
| AI引用 | 見出し＋リードの冒頭 | 独立した答えの予告 |

SNSから来た読者は、外門をSNS投稿で通過している場合があります。リンク先のH1・リードはSNSの約束の続きである必要があります（第2章）。

---

### ポイント

- ゲートは通過率と誠実さの両立。釣りは信頼を失い、タブを閉じさせる
- 5要素：具体性、対象、問いとの接続、約束の範囲、新鮮さ
- 公開前チェック：約束は Must と一致、過大表現なし
- H1だけ強く、H2が弱い。中でタブを閉じるパターンに注意
- スマホでは H1 の前半に核心

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 検索結果だけ選ばれるように最適化 | 釣りゲート化 | 開いてすぐ閉じたか、読み続けたかとセットで評価 |
| 競合見出しのコピー | 差別化できず、釣り競争 | ペルソナの問いから再設計 |
| メタ説明と H1 が矛盾 | 外門二重で混乱 | 同じ約束に揃える |
| 数字の約束を本文で果たさない | 信頼崩壊 | 3選なら3つ、5ステップなら5つ |
