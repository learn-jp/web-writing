# 8-7 章末まとめ・チェックリスト・演習

応用編の第1章を読み終えたあなたへ。本編第7章で完成した「正当性の証明書」は、正しい情報を世界に宣言する書類でした。第8章は、その証明書をどう手渡すか、すなわちブランドの声を一貫させる章でした。一度、地図を確認しましょう。

## 第8章のメッセージ（再確認）

> この節の要点：証明書は正しくても、渡し方が店ごとにバラバラなら読者は迷う。同じ工房、同じカウンター越しの作法が、ブランドの声である。

寿司屋で例えるなら、ネタの鮮度（第7章）と、カウンター越しの説明の仕方（第8章）はセットです。検索・SNS・生成AIが要約・引用する時代ほど、声の一貫性は信頼の一部になります。常連でも初来店でも、板の前の誠実さは変わりません。説明の長さと温度だけ、場面に合わせて調整します。

## 本編から応用編への接続

> この節の要点：第8章は、本編の設計思想を「声の一貫性」として現場の運用に広げる入口である。

| 本編（第1〜7章） | 第8章（応用編入口） |
|---|---|
| 手紙・問い・導管・玄関・物流 | 声の一貫性で「届け方」を統一 |
| 精密検査（第6章） | クエリから語彙表を更新（8-3節） |
| 証明書（第7章） | トーンを変えても証明書の欄は維持 |
| ペルソナ・メディア（第2章） | 文体・語彙・共感の設計根拠 |

応用編は、本編の設計思想を現場の運用に広げる章群です。第9章以降では、モバイル（第9章）、アクセシビリティ（第10章）、リライト（第11章）へと、媒体と工程を深めていきます。

## 第8章の章末まとめ

> この節の要点：ボイス・トーン・文体・語彙・ガイドライン・共感・多言語。第8章の7項目を統合する。

1. ボイス＝店の声（人格・価値観・距離感）。記事・メディアをまたいで不変
2. トーン＝その場の調子。問い・ジャーニー・メディアで可変（8-1節）
3. 敬体・常体は距離感の道具。冗長敬体と無秩序な混在を避ける（8-2節）
4. 語彙はペルソナの辞書から。表層・裏層・禁則の三層（8-3節）
5. ブランドガイドライン＝声の設計書。良い例・悪い例が再現性の核（8-4節）
6. 共感＝不安の言語化のあと、必ず返球へ。煽り・断定は禁則（8-5節）
7. 多言語はボイス維持・トーン再設計。YMYLは国別（8-6節）

## 第8章の執筆前・公開前チェックリスト

> この節の要点：執筆前に声の設計を確認し、公開前に一貫性と証明書の欄を点検する。

記事を書く前、および公開前に、次の項目を確認してください。

### 声の設計（執筆前）

- [ ] ペルソナ（第2章）とジャーニー段階（第2-6節）を確認した
- [ ] ボイス（不変）とトーン（可変）を1行ずつメモした
- [ ] 文体のデフォルト（敬体/常体）を決めた（8-2節）
- [ ] 推奨語彙・禁則語をガイドラインまたはメモで参照した（8-3・8-4節）
- [ ] 共感段落のあと、結論または手順につながる（8-5節・第4章）

### 一貫性と証明書（公開前）

- [ ] 同一メディア内で、ライター間の口調が大きくズレていない
- [ ] トーンを変えても、著者・出典・更新（第7-4節）を省略していない
- [ ] 見出し・リードのトーンが本文と矛盾していない（第4章）
- [ ] メディア別の深さは変えても、誠実さ（ボイス）は揃っている（第2-5節）
- [ ] 多言語版がある場合、YMYL・法令は現地版で監修済み（8-6節）

### 公開後（第6章との接続）

- [ ] クエリと語彙のズレを月次で確認し、言い換え表を更新した
- [ ] ガイドラインの良い例・悪い例を、効いたリライトで差し替えた

## 第8章の演習

> この節の要点：自社メディアのトーン＆マナーガイドを1ページで作成し、既存記事1本への適用メモを書く。

課題：自社（または担当メディア）の「トーン＆マナーガイド」ドラフトを1ページで作成してください。

### 提出物

1. 対象メディア名と主なペルソナ（第2章）
2. ボイスステートメント（3〜5文）
3. 文体ルール（敬体/常体、見出し、一人称）
4. 推奨語彙10語・禁則語10語
5. 良い例・悪い例（各1段落、同一テーマ）
6. 第7章の証明書欄への参照（著者・出典・更新の書き方）
7. 既存記事1本への適用メモ（どこをガイドに合わせて直すか）

ヒント：第7章の演習と同じ記事を使うと、証明書→声の一貫性まで一連で体験できます。

参考解答：[第8章 演習の参考解答](../../exercises/answer-keys/chapter-08.md)

## 次章への接続

> この節の要点：第9章では、声の設計をモバイルファーストの段組・ファーストビューとセットで機能させる。

第9章では、スマホで読まれることを前提に、短い画面で伝える構成（モバイルファースト）を扱います。声（第8章）が決まっても、画面が狭ければ、トーンの設計は第9章の段組・ファーストビューとセットで初めて機能します。第2-4節で触れたデバイス文脈を、執筆ルールとして深めていきましょう。
