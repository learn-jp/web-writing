# 応用編 第1章 トーン＆マナー

> 第7章からの接続：本編で、あなたは「正当性の証明書」を設計する方法を学びました。著者、根拠、更新。証明書の欄は埋まった。しかし、証明書をどう手渡すかは、まだ語っていません。第8章は、その届け方、すなわち「声」を一貫させる章です。

> この章で学ぶこと
> - トーン（その場の調子）とボイス（店の声）の違いを設計する
> - 敬体・常体、語彙、共感表現を、ペルソナとメディアに合わせて選ぶ
> - ブランドガイドラインを、再現可能な「カウンターの作法」として書く
> - 多言語展開時も、同じ工房の誠実さを保つ

本章の核となるメッセージ

> 証明書は正しくても、渡し方が店ごとにバラバラなら、読者は迷う。同じ工房、同じカウンター越しの作法。それが、ブランドの声である。
