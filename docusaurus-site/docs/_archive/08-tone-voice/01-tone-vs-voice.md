# 8-1 トーンとボイスの違い

第7章で、E-E-A-Tを「正当性の証明書」として完成させました。著者名、出典、更新日。証明書の欄が埋まっても、読者が受け取る印象は、まだ決まっていません。正しい情報を、毎回まったく違う口調で届けていたら、読者は「この店、誰が話しているのか」と迷います。応用編の第1章は、証明書を「どう手渡すか」を設計する章です。その核心が、トーンとボイスです。検索・SNS・生成AIが要約・引用する時代ほど、声の一貫性は信頼の一部になります。

## ボイスとは、店の声（変わらない軸）

> この節の要点：ボイスはブランドが一貫して保つ「話し方の人格」である。記事・メディアをまたいで不変の軸として設計する。

ボイス（Voice）とは、ブランドやメディアが一貫して保つ「話し方の人格」です。寿司屋に例えるなら、板の前に立つ職人の姿勢、カウンター越しの距離感、ネタの説明の仕方。常連でも初来店でも、同じ職人が同じ誠実さで迎える。それがボイスです。

Webライティングにおけるボイスの要素は、次のように整理できます。

| 要素 | 問い | 例（BtoB SaaS） | 例（健康メディア） |
|---|---|---|---|
| 人格 | 誰が話しているか | 現場に寄り添う同僚 | 経験豊富な先輩 |
| 価値観 | 何を大切にするか | 再現性、数字、手順 | 安全、根拠、限界の明示 |
| 語彙の傾向 | どんな言葉を選ぶか | 具体的、控えめ | やさしい、断定を避ける |
| 距離感 | 読者との関係 | 並走するパートナー | 伴走する案内人 |

第2章で設計したペルソナは、ボイスを決める羅針盤になります。健太さん（副業を考える会社員）向けの声と、経営者向けの声は、同じ事実でも届け方が変わります。ただし、どちらも第7章の証明書（正しさの宣言）から外れてはいけません。

## トーンとは、その場の調子（状況で変わる温度）

> この節の要点：トーンは同じボイスのなかで、状況に応じて調整する温度である。問い・ジャーニー・メディアで可変する。

トーン（Tone）とは、同じボイスのなかで、状況に応じて調整する「温度」です。寿司職人が、初来店の客には産地と食べ方を丁寧に説明し、常連には「今日は塩で」と短く伝える。声の人格は同じでも、場面ごとの調子は変わります。

| 状況 | トーンの調整 | Webでの例 |
|---|---|---|
| 初めての読者 | 丁寧、前提説明多め | ハウトゥ記事、用語の定義 |
| リピーター | 簡潔、リンクで戻れる | 更新記事、シリーズ後半 |
| 不安が強い問い | 寄り添い、断定を避ける | YMYL、健康・お金（第7-5節） |
| 比較・検討段階 | 俯瞰、選択肢を並べる | 比較記事（第2-6節） |
| エラー・障害 | 落ち着き、手順を短く | サポートページ |

ブログ記事とエラーページでまったく別人のように書いていたら、読者はブランドの一貫性を失います。ボイスは同じ、トーンだけ調整する。これが応用編の基本原則です。

## 整備工房の比喩、声は同じ、説明の深さは変える

> この節の要点：ボイス（正確・誠実・責任）は不変、トーン（説明の長さ・専門用語・共感）は可変である。

自動車整備士も、同じ工房の声を持ちます。国家資格を持つ整備士として、正確さと誠実さは変わりません（第7-2節）。しかし、初めて来店したオーナーには、症状と原因を順を追って説明します。同じ症状で3度目の来店のオーナーには、「前回と同じ箇所です。今回はここまで交換しましょう」と短く伝えます。

```
ボイス（不変）＝ 正確、誠実、責任ある説明
トーン（可変）＝ 説明の長さ、専門用語の量、共感の度合い
```

Web記事でも同じです。第3章の構成（導管）や第4章の玄関（見出し・リード）は、問いに合わせて設計します。トーンも、問いとジャーニーの段階（第2-6節）に合わせて調整します。しかし、第7章で誓った「空の返球を返さない」「正しいと宣言する」というボイスの根っこは、記事の種類を問わず共通です。

## メディアごとのトーン、深さは変えても声は揃える

> この節の要点：メディアごとに深さと長さは変えてよい。しかし、誠実さ（ボイス）は全チャネルで揃える。

第2-5節で、ブログ・コーポレート・EC・SNSでは「期待される返球の深さ」が異なると述べました。SNSは短く、コーポレートは敬体で公式に、ブログは著者の声を残す。深さと長さはメディアで変えてよい。しかし、ボイス（誠実さ、ペルソナへの敬意、証明書としての正確さ）は揃える必要があります。

| メディア | トーンの傾向 | ボイスで守るもの |
|---|---|---|
| ブログ | ややカジュアル、体験を織る | 出典、限界の明示 |
| コーポレート | 敬体、客観的 | ブランドガイドライン（8-4節） |
| EC商品ページ | 選び手の立場、簡潔 | デメリットの誠実な記載 |
| SNS | プラットフォーム文化に合わせる | 誇大表現を避ける。要約・引用に耐える構造 |
| 生成AI引用 | — | 出典・著者・更新日が本文から読み取れる |

寿司屋がテイクアウトの説明と、カウンターでの説明で長さを変えても、ネタの鮮度を隠さない誠実さは同じです。

## トーンとボイスを混同すると、ブランドが分裂する

> この節の要点：トーンを変えることは、別人格で書くことではない。口調は柔らかくても、証明書は維持する。

| 混同 | 実際 |
|---|---|
| 記事ごとに人格を変える | トーンだけ変え、ボイスは固定 |
| カジュアル＝正確さを捨てる | 口調は柔らかく、証明書は維持 |
| 敬体＝ボイス | 敬体・常体はトーンの道具（8-2節） |
| 検索エンジン向けに硬く | 読者向けの声を優先。結果として検索・AIにも伝わる（第1章・第5章） |

### この節の整理

- ボイス＝店の声。人格・価値観・距離感。記事をまたいで不変
- トーン＝その場の調子。問い・ジャーニー・メディアで可変
- 証明書（第7章）の正しさと、届け方（第8章）の一貫性はセット
- 同じ工房、同じカウンター越しの作法。それが読者の信頼を積む

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| ライターごとに口調がバラバラ | ブランドが分裂 | ボイス定義を8-4節で文書化 |
| カジュアル記事で出典を省略 | 証明書が空になる | トーンと正確さは別軸 |
| すべて敬体で統一 | ペルソナとズレる | 常体の余地を8-2節で設計 |
| SNSだけ煽り口調 | 他メディアとの信頼が崩れる | ボイスの価値観を全チャネルに |
