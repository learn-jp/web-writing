# 6-2 分析は故障診断・精密検査である

自分が検索結果を眺め、クリックする前に判断し、開いてすぐタブを閉じた経験はありませんか。データ分析は、その体験を振り返る精密検査です。点数付けではなく、整備士の故障診断のように、どこで問いと答えがズレたかを特定します。

---

## 分析は責めない。原因を特定する

> この節の要点：分析は記事の点数付けではなく、問いと答えがどこでズレたかを特定する精密検査。

自動車整備士がエンジンから異音を聞くとき、最初に言うのは「この車はダメだ」ではありません。どの部品の、どの工程で、何が起きているかを特定します。

Web記事の分析も同じです。

> 分析とは、第2の返球から「どこで、なぜ、問いと答えがズレたか」を特定する精密検査である。

| 整備士の検査 | Webライティングの分析 |
|---|---|
| 異音・振動（予兆） | 即去りの増加、読み続けの短さ |
| 診断機の読み取り | Search Console、Analytics |
| 原因の特定 | クエリ不一致、H2離脱、外門の弱さ |
| 修理の優先順位 | リライトの段取り（第6-5節） |
| 再試運転 | 改善後のデータ確認 |

---

## 予兆検知、整備士時代の視点を完全にマッピング

> この節の要点：選ばれにくくなる・即去り・H2で止まる・クエリズレ・表示減の5予兆パターンを整備士の視点で読む。

### 予兆1：表示は増えたが、検索結果で選ばれにくくなった

整備士の例え：部品は届いているが、梱包ラベルが読みにくく、開封率が下がっている。

疑う場所：title・meta（第5-3節）、H1（第4章）。外門の設計。

### 予兆2：クリックはあるが、自分が開いてすぐタブを閉じる

整備士の例え：箱は開けたが、中身が期待と違う。すぐ返品。

疑う場所：リード（第4章）、検索意図とのズレ（第2章）。防波堤と宛名。

### 予兆3：読み続けはあるが、特定H2で止まる

整備士の例え：ラインの途中工程で部品が止まる。

疑う場所：そのH2の見出し・本文（第3章）。関所の設計。

### 予兆4：Search Consoleのクエリが、想定キーワードと違う

整備士の例え：注文書の型番と、実際に届いた部品番号が違う。

疑う場所：問いの読み違え、キーワード配置（第5-4節）。型番と問いの対応。

### 予兆5：順位は横ばいだが、表示が減った

整備士の例え：物流ルートは生きているが、需要（問い）自体が変わった。

疑う場所：季節性、競合、鮮度（第11章）。物流と陳腐化。

寿司職人が握りの反応を見て、次のネタの順番を変えるように、予兆は「次の段取りを変える」ための信号です。

## 精密検査の3原則

> この節の要点：症状と原因を分離、比喩の階段に沿って疑う、1記事1診断。

### 原則1：症状と原因を分離する

自分が開いてすぐタブを閉じるのは症状。リードが問いに答えていないが原因の候補。症状だけ直そうとしない。

### 原則2：比喩の階段に沿って疑う

第1章から第5章の設計レイヤー（手紙、問い、導管、玄関、物流）のどこでズレが起きたか、順に当てはめる。

```
外門（選ばれにくい）→ 防波堤（即去り）→ 関所（H2で止まる）→ 物流（表示減）
```

### 原則3：1記事に1診断

サイト全体の平均値だけ見ても、どの返球を直すかは決まらない。記事単位、問い単位で精密検査する。

## 人間味と技術の融合、分析にも両方ある

> この節の要点：数値とペルソナをセットで読む。計器の向こうにある、自分が検索したときの体験を振り返る。

計器は、あなた自身が検索結果を見て、クリックする前に判断した経験を振り返るための道具です。しかし、その背後にあるのは、自分がタブを閉じた瞬間の感覚です。

- 計器の鏡：Search Console、Analytics、数値の推移
- 人間味：「自分が何に失望してタブを閉じたか？」を思い出す

自動車整備士が診断機の数値を見ながら、ドライバーの走行状況をヒアリングするように、数値とペルソナ（第2章）をセットで読む。これが、本書の分析のトーンです。

### ポイント

- 分析＝故障診断。責めず、原因を特定する
- 整備士の予兆検知を、5つの予兆パターンにマッピング
- 症状と原因を分離。比喩の階段に沿って疑う
- 数値＋ペルソナ＝人間味と技術の融合

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| KPIだけダッシュボード化 | 原因が見えない | 記事×問い単位で診断 |
| 平均値だけ見る | 個別の故障を見逃す | 外れ値記事を深掘り |
| すぐ全面書き直し | 段取りが崩れる | 症状から疑うレイヤーを特定 |
| データを見ない | 予兆を逃す | 月次精密検査を習慣化 |
