# 5-5 内部リンク・外部リンク。物流ルートの設計

内部リンクは「関連はこちら」程度にしか考えていませんか。第3章の導管をサイト全体の物流網として広げないと、読者もクローラーも行き止まりで消滅します。

---

## 第3章の導管を、物流網としてサイト全体に広げる

> この節の要点：第3章の導管分岐をサイト全体の物流網として広げ、通路途切れによる消滅を防ぐ。

第3章で、リンクは次の問いへの分岐だと述べました。第1章ではこちらだけのリンクが壊れた手紙を生むと警告しました。第5章では、検索エンジン（Web上の情報を収集・整理し、問いに対する答えを選び出す仕組み）への最適化の視点。クローラビリティ（第5-2節）。を加えます。

比喩の階段で言えば、導管（第3章）の枝分かれを、物流網（第5章）としてサイト全体に広げる作業です。通路が途切れれば、読者は行き止まりで消滅し、クローラーもページに辿り着けません。リンク設計は、テクニックではなく。読者の時間を預かった設計士が、次の返球までの経路を確保する責任です。

---

## リンクは物流ルートである。種類ごとの役割

> この節の要点：内部・外部・被リンクは工場比喩で整理。ライターが設計できるのは主に内部と出站。

工場の比喩で整理します。

| リンクの種類 | 工場比喩 | 役割 |
|---|---|---|
| 内部リンク | 工場内のコンベア・通路 | ページ間をつなぎ、クローラーを誘導 |
| 外部リンク（出站） | 他工場・公的規格への参照 | 信頼の根拠、引用 |
| 被リンク（入站） | 他社からの納入経路 | 権威性（直接制御は難しい） |

ライターが設計できるのは、主に内部リンクと出站リンクです。

---

## 内部リンクは、サイト内の通路設計である

> この節の要点：内部リンクはクローラーの通路と読者の次の問いへの導管。意味あるアンカーとハブ＆スポーク。

### 内部リンクがWeb最適化に効く理由

1. 読者が次の関所（H2・別記事）へジャンプし、問いへの対話を続ける
2. インデクサーがサイト構造を理解（どのページが重要か）
3. PageRank（リンクの投票）がサイト内で流通。重要ページに集約
4. クローラーがリンクを辿り、未発見ページを巡回

孤立ページ（どこからもリンクされない）は、地図にない倉庫です。

### 内部リンクのHTMLと、読者・クローラーへの見え方

```html
<p>
  就業規則の確認が終わったら、
  <a href="/articles/side-job-types/">在宅で週末だけ試せる副業3選</a>
  から種類を1つ選びましょう。
</p>
```

ブラウザでの表示結果（見た目）：

- アンカーテキスト「在宅で週末だけ試せる副業3選」がリンクとして表示される
- 読者は行き先がわかる状態で次の問いへ進める
- クローラーはリンクを辿り、関連ページを発見する

```html
<p>詳しくは<a href="/articles/side-job-types/">こちら</a>。</p>
```

ブラウザでの表示結果（見た目）：

- 「こちら」だけでは行き先が不明
- スクリーンリーダーでも文脈が失われる
- 第1章で警告した壊れた手紙の典型

### 内部リンクの設計原則

| 原則 | 内容 |
|---|---|
| 意味のあるアンカー | こちら禁止（第1章）。行き先がわかるテキスト |
| 関連性 | 読者の次の問い（第2章ジャーニー）につなぐ |
| 重要ページへ | ハブ記事、サービスページへ適度にリンク |
| 量より質 | 1記事に100本より、5本の的確なリンク |
| 新しいタブ | 外部は必要に応じて。内部は通常同一タブ |

### ハブ＆スポーク（Topic Cluster）

第12章で詳述しますが、検索エンジンへの最適化の基本パターンです。

```
        [ハブ記事：副業の始め方 総合]
           /    |    \
          /     |     \
    [就業規則] [種類] [登録手順]   ← スポーク記事
```

ハブからスポークへ、スポークからハブへ。双方向の通路。読者もクローラーも、迷子になりません。寿司職人が握りの流れを決めてからネタを出すように、ハブが全体の段取りを決めます。

### 実務。内部リンクを入れるタイミング

- 執筆時：ここで読者は次に何を知りたくなるか？（第2章ジャーニー）
- 公開前：関連記事へのリンク3〜5本を確認
- リライト時：新記事追加に合わせ、旧記事からリンク（第11章）

---

## 外部リンクは、信頼の根拠となる出站である

> この節の要点：権威ある外部リンクはE-E-A-Tの根拠。出站を恐れず、スパムだけ避ける。

### 出站リンクを恐れない

外部リンクはWeb最適化に悪い。誤解です。権威ある情報源（政府、研究、公式）への引用リンクは、読者の信頼を支える根拠となり、その結果としてE-E-A-T（信頼性）の評価にも効きます。

```
✓ 「国税庁の確定申告ガイド（リンク）によると…」
✓ 出典を明示した統計データ
```

工場から公的な規格書へ参照線を引く。品質の証明です。

### 外部リンクの注意

| 注意 | 理由 |
|---|---|
| スパムサイトへリンク | 信頼を損なう |
| 過剰な affiliate リンク | 読者の信頼を損なう |
| リンクなしの他人の主張 | 根拠不明（第7章） |

---

## 被リンク（バックリンク）は、入站物流である

> この節の要点：被リンクは品質から生まれる。購入・スパムはNG。誠実なあなたの物語が自然な入站を生む。

他サイトからのリンクは、他工場からの推薦です。ライターが直接増やすのは難しいですが。

- 問いに誠実に答えるあなたの物語が、自然な被リンクを生む
- 一次情報、調査、ツールはリンクされやすい
- 被リンク購入、スパムリンクはNG（第5-6節）

---

## リンク設計チェックリスト

> この節の要点：公開前にアンカー・次の問い・ハブ・孤立ページ・外部ソース・こちらリンクを点検する。

```
□ アンカーテキストは行き先がわかるか
□ 読者の次の問いに繋がっているか
□ 重要記事（ハブ）へ戻る／進むリンクがあるか
□ 孤立ページを作っていないか
□ 権威ある外部ソースへ適宜リンクしているか
□ 「こちら」だけのリンクが残っていないか
```

### ポイント

- 内部リンク＝読者の次の問いへの導管＋サイト内の物流通路。消滅する行き止まりを作らない
- 意味あるアンカー、関連性、ハブ＆スポーク（整備士の動線設計と同根）
- 外部リンク（権威ソース）＝信頼の根拠
- 被リンクは品質から生まれる。購入はNG
- 執筆・リライト時に通路を整備

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 内部リンクゼロ | 孤立、巡回不足 | 関連3〜5本 |
| 全記事からTOPのみ | 通路が単純すぎ | 文脈に沿った横リンク |
| 外部リンクを一切しない | 根拠不足 | 公式・研究へ |
| 被リンク操作 | ペナルティ | あなたの物語の品質 |
