# 10-4 色・コントラストに依存しない情報設計

色は装飾ではなく、情報のひとつ。しかし色だけで重要度や状態を伝える設計は、工房の看板が色盲の整備士には読めないのと同じ。形・言葉・位置でも同じ意味が届くように設計する。

## 色だけに頼ると何が起きるか

> この節の要点：赤文字＝警告、緑バッジ＝おすすめ、リンクだけ青：色だけの設計は、色覚多様性・低コントラスト・モノクロ環境で情報が失われる。

人の色の見え方は、個人差があります。赤と緑の区別が難しい方、コントラストが低いと文字が読めない方、目が疲れて彩度に頼れない方。いずれも、あなたの読者になり得ます。

| 色だけの設計 | 失われる情報 |
|---|---|
| 赤文字＝警告 | 警告と通常の区別 |
| 緑バッジ＝おすすめ | おすすめの識別 |
| リンクだけ青 | リンクと通常文の区別（下線なしの場合） |
| グラフが色分けのみ | 系列の対応 |

Webのコントラスト比（文字と背景の明度差）は、WCAGなどの指針で数値化されています。実装はデザイナー・開発者の領域ですが、ライターは「色以外の手がかり」を文章に書き込むことで、情報の冗長性（同じ意味を複数経路で届ける）を確保できます。

---

## 情報の冗長性：寿司職人の盛り付けから学ぶ

> この節の要点：ネタの種類を色だけで見せない。形、切り方、説明、位置（複数の手がかりで同じ意味を届ける冗長性を設計する。）

寿司職人は、ネタの種類を色だけで見せません。形、切り方、カウンターでの説明、皿の位置。複数の手がかりで「今日のおすすめ」を伝えます。

Web記事でも同じです。

```
✗ 「赤い部分が必須項目です」（色だけ）
✓ 「必須項目（※印付き）」（記号＋言葉）
✓ 表の見出し行に「必須」「任意」と文字で記載
```

自動車整備士の工場では、危険箇所に色のテープだけでなく「高温」「高電圧」の文字標識を併記します。色は補助。意味は言葉と形でも届けます。

---

## ライターが書ける「色に依存しない」表現

> この節の要点：言葉で状態を明示し、記号・番号を併用し、表では行見出しで意味を持たせ、グラフ・図の説明を本文に書く。

### 1. 言葉で状態を明示する

```
✗ 「下記の赤文字に注意」
✓ 「次の3点に注意してください（重要）」
```

### 2. 記号・番号を併用する

```
✓ 手順1 → 手順2 → 手順3（番号付きリスト、第3章）
✓ 必須※ / 任意（表記）
```

### 3. 表では行見出しで意味を持たせる

```html
<table>
  <caption>副業の届け出要否（会社規模別）</caption>
  <thead>
    <tr>
      <th scope="col">会社規模</th>
      <th scope="col">届け出</th>
      <th scope="col">確認方法</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="col">従業員300人以上</th>
      <td>原則必要</td>
      <td>就業規則を確認</td>
    </tr>
    <tr>
      <th scope="col">従業員300人未満</th>
      <td>規則による</td>
      <td>総務に問い合わせ</td>
    </tr>
  </tbody>
</table>
```

「ブラウザでの表示結果（見た目）」：

- 表が罫線付きで表示され、列見出しと行見出しが太字になる（スタイル次第）
- 「届け出」列の「原則必要」「規則による」は、色がなくても文字で状態がわかる
- スクリーンリーダーは caption → 列見出し → 行ごとのセル、と構造を読み上げる

### 4. グラフ・図の説明を本文に書く

```
✓ 「2024年は2023年比で副業開始者が15%増加（下図）。主因は在宅勤務の定着です。」
✓ alt：「棒グラフ。2023年100に対し2024年115。右肩上がり」
```

色の系列識別に頼るグラフは、本文か凡例テキストで系列名を繰り返します。

---

## リンクとCTA：色以外の手がかり

> この節の要点：下線のない青文字だけのリンクは識別が難しい。リンク文言で行動を明示し、「こちら」単独を避ける。

第3章・第5章 Web最適化（検索・SNS・AI引用）で、リンクは読者とクローラーの通路です。下線のない青文字だけのリンクは、色覚・モノクロ環境で識別が難しくなります。

ライターが指定できること：

| 項目 | 推奨 |
|---|---|
| リンク文言 | 「詳細はこちら」ではなく「就業規則の確認手順を見る」 |
| 文中の位置 | 関連する文の直後に置く |
| CTA | ボタン文言で行動を明示。「無料で登録する」 |

```html
<p>届け出の様式は、
   <a href="/forms/side-job.pdf">副業届出書（PDF）</a>
   からダウンロードできます。</p>
```

「ブラウザでの表示結果（見た目）」：

- リンク部分が下線付き・別色で表示される（サイトのCSS次第）
- リンク文言だけ読み上げても、PDFの届出書だとわかる
- 「こちら」だけのリンクより、音声ユーザーが先に進みやすい

---

## 強調の使い方：太字・斜体・大文字

> この節の要点：`<strong>` は意味上の強調。赤・大文字・太字・下線を全部付けると、どこも重要ではなくなる。

HTMLの `<strong>` は、意味上の強調です。見た目の太字だけの `<b>` より、スクリーンリーダーに「ここが重要」と伝わりやすい設計になります（実装はサイト方針に従う）。

```
✓ <strong>結論：まず就業規則を確認してください。</strong>
✗ 赤・大文字・太字・下線を全部付ける（情報過多）
```

強調を付けすぎると、どこも重要ではなくなります。工房の看板が全部「危険」なら、どれも標識として機能しません。

---

## 消滅との接続

> この節の要点：色だけの設計は、コントラスト不足での一瞬で去る、意味の取り逃し、「自分向けではない」判断につながる。テキストで意味を完結させることは、あなたの物語の堅牢性でもある。

色だけの設計は、次の引き返しを生みます。

- コントラスト不足で、スマホの屋外では文字が読めず一瞬で戻る（第1章）
- 「重要」と書かれたが色しか目印がなく、意味を取り逃す
- グラフだけ見て、数値の比較ができず「自分向けではない」と判断

色に頼らずテキストで意味を完結させることは、音声読者・AI要約・検索インデックスのいずれにも同じ情報が届く、あなたの物語の堅牢性でもあります（第5章 Web最適化・第7章）。

---

### ポイント

- 色は補助。状態・重要度は言葉・記号・表構造でも伝える
- 表は caption と th scope で見出しを明確に（第3章）
- リンク文言は目的地がわかる文に。色と下線だけに頼らない
- グラフ・図は本文・altで数値・傾向をテキスト化

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 「赤い部分を見て」 | 色だけの指示 | 「次の※印を確認」 |
| グラフが色分けのみ | 系列が区別不能 | 凡例を文字で、本文に数値 |
| リンクが「こちら」 | 音声で意味不明 | リンク先の内容を文言に |
| 強調の乱用 | 重要箇所がわからない | 1段落1強調までを目安 |
