# 10-6 章末まとめ・チェックリスト・演習

第10章では、アクセシビリティを「誰にでも読みやすい文章」として、工房のスロープと標識に例えた。本編第1章の消滅、第3章の導管、第7章の平易なExpertiseと接続し、応用編の設計責務として定着させる。

## 第10章のメッセージ（再確認）

> この節の要点：アクセシビリティは入口の横に置いたおまけのスロープではない。工房全体にスロープと明確な標識を組み込む、設計の責任である。

自動車整備士が安全基準で工房を整えるように、寿司職人が客に届く言葉でネタを説明するように、あなたも言葉・見出し・alt・色に頼らない表現で、あなたの物語を届けます。音声読者・スクリーンリーダー・生成AIの要約：いずれも、第3章の構造を正しく読み取れる設計が前提です。

## 本編との接続

> この節の要点：第1章の消滅、第3章の導管、第7章の平易語、第9章のモバイル（第10章はこれらを「全員に返球する」設計責務として統合する。）

## 第10章の章末まとめ

> この節の要点：アクセシビリティの六つの学び：設計責務、プレーンランゲージ、alt、色に頼らない表現、スクリーンリーダー向け構造、全員が結論に辿り着ける導管。

1. アクセシビリティ＝工房のスロープと標識。設計士の責務
2. プレーンランゲージ＝問いに届くExpertise。短い文・能動態・具体性
3. alt＝画像の意味を言葉で再現。装飾は空、意味ある図は具体的に
4. 色だけに頼らず、言葉・記号・表構造で情報を冗長化
5. スクリーンリーダーは第3章の構造を読む。リンク・略語・読み上げテスト
6. 音声・視覚・認知のどれかが制約されても、結論に辿り着ける導管

## 第10章の執筆前・公開前チェックリスト

> この節の要点：言葉・画像・色・構造の四ブロックで、公開前にアクセシビリティを点検する。

### 言葉（10-2）

- [ ] 1文が長すぎない（目安：60字前後）
- [ ] 専門語の初出に説明または平易語
- [ ] 見出しだけで骨格がわかる（第3章）
- [ ] 核心キーワード（問いの言葉）を削りすぎていない

### 画像（10-3）

- [ ] 意味ある画像に、具体的なalt
- [ ] 装飾画像は alt=""
- [ ] 複雑な図は本文・表でも同情報

### 色・視覚（10-4）

- [ ] 「赤い部分」など色だけの指示がない
- [ ] 表・リストで状態を文字でも示す
- [ ] リンク文言が目的地を表す（「こちら」だけにしない）

### 構造・音声（10-5）

- [ ] H1→H2→H3の階層を飛ばしていない（第3章）
- [ ] 見出しは装飾divではなくh1〜h4
- [ ] 手順は番号付きリストで
- [ ] 公開前に読み上げまたはVoiceOverで1回確認

## 第10章の演習

> この節の要点：記事1本についてアクセシビリティ監査を行い、平易語・alt・色依存・構造・読み上げの五領域で改善アクションを1つ決める。

課題：自分（または他者）の記事1本について、アクセシビリティ監査を行ってください。

### 提出物

1. 対象記事URL（またはタイトル）
2. 平易語チェック：改善すべき文を1つ（Before/After）
3. alt監査：意味ある画像のalt評価（○/△/×）と改善案1つ
4. 色依存チェック：色だけに頼っている箇所があれば指摘
5. 構造チェック：見出し階層・リンク文言の問題点
6. 読み上げテスト：音声で迷った箇所（または想定される問題）
7. 改善アクション1つ（工房のどの「標識」を直すか）

ヒント：第3章・第7章の演習と同じ記事を使うと、導管→証明書→アクセシビリティの一連の流れが体験できます。
