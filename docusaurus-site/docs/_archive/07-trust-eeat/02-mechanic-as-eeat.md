# 7-2 整備士の国家資格、経験と信頼の最大の証

第1章のコラムで触れた自動車整備士は、国家資格を取得し、何千台もの車と向き合い、何万時間も工具を手にしてきました。その経験は、履歴書の一行ではありません。本章では、その歩みが、いかにして証明書の中身を埋めるかを見ていきます。

## 資格は、証明書の発行元

> この節の要点：資格は証明書の発行元に相当する。肩書きの一行ではなく、現場で刻まれた具体的事実が、ExperienceとExpertiseの欄を埋める。

整備記録簿に載る資格情報は、証明書の「発行元」に相当します。しかし、欄に名前だけ書いても、証明書は完成しません。

```
✗ 「整備士2級を保有しています」
```

これだけでは、証明書は空です。しかし、

```
✓ 「10年間、同一工場で走行距離20万km超の車両を担当し、
    エンジン異音の診断で社内トップ3の精度を維持してきた」
```

これは、ExperienceとExpertiseが、具体的な事実として刻まれた証明書です。

自動車整備士として国家資格を取得し、技術を磨いてきた。その歩みそのものが、本書が信じる最大のE-E-A-Tです。なぜなら、それは嘘のつけない現場で培われたからです。

> 現場で身体を使い、結果に責任を持った経験。それが、いかなる肩書きよりも強い信頼の根拠になる。

---

## なぜ「現場」がE-E-A-Tの核か

> この節の要点：現場の特徴（結果が即返る、嘘が通用しない、段取りが命）は、Webライティングの設計と同型である。

Webライティングの教科書には、小手先のテクニックや構成のフレームが並びます。しかし本書は、第1章から自動車整備士の視点を軸にしてきました。それには理由があります。

| 現場の特徴 | Webライティングへの対応 |
|---|---|
| 結果が即座に返る | タブを閉じる・消滅という第2の返球 |
| 嘘は通用しない | 釣りタイトル・薄いあなたの物語は消滅 |
| 道具と段取りが命 | 構造化・PREP・物流 |
| 資格は最低条件、実力が評価 | E-E-A-Tの4要素すべて |
| 次の作業者への敬意 | 読者の時間を預かる責任 |

自動車整備士は、資格試験に合格した日で完成しません。翌日から来店する車の前で、問い（異音、不具合、不安）に答え続けます。情報の設計士も同じです。寿司職人が毎日板を磨き、ネタの鮮度を確かめるように、設計士も現場で問いに応え続けることで、証明書の中身を更新し続けます。

---

## 国家資格とWebの「資格」

> この節の要点：Webには国家資格のような単一基準はない。分散した信頼信号を、整備士の世界と対応づけて設計する。

Webの世界には、国家資格のような単一の基準はありません。代わりに、分散した信頼信号があります。

| 整備士の世界 | Webの世界 |
|---|---|
| 国家資格 | 著者の経歴・資格・実績 |
| 整備記録簿 | 記事の出典・更新履歴 |
| 工場の評判 | 被リンク、メディア引用 |
| 部品メーカーの保証 | 公式情報へのリンク |
| 定期点検 | リライト・第6章の精密検査 |

国家資格は、信頼の入口です。それだけでは足りません。しかし、入口すらない状態。著者不明、経験の記載なし、出典なし。では、証明書は発行されません。

---

## あなたの「国家資格」は何か

> この節の要点：国家資格がなくても、検証可能な具体的事実を記事に刻むことが、ExperienceとExpertiseの欄を埋める行為である。

読者、未来の設計士に問いかけます。

「あなたの書くテーマにおいて、国家資格に相当するものは何ですか？」

- 10年間、その業界で働いてきた経験
- 資格、学位、認定
- 100件以上のクライアント案件
- 自分自身が乗り越えた失敗と学び
- 一次調査、インタビュー、実験

リストアップし、記事の中で具体的な事実として示す。それが、ExperienceとExpertiseの欄を埋める行為です。

```
✗ 「Webマーケティングの専門家として」
✓ 「Search Consoleを5年間運用し、月200本の記事の
    精密検査を担当してきた経験から」
```

抽象は、証明書には載りません。事実だけが載ります。

---

## 嘘は、第2の返球で露呈する

> この節の要点：著者ページと記事の整合性は、自分が検索してタブを閉じた体験と第6章の第2の返球で検証される。嘘は長くは持たない。

著者の経歴ページ、Aboutページ、他記事との一貫性、外部からの言及。証明書の欄が互いに矛盾していないかは、あなた自身が検索結果を眺め、クリックする前に感じ取ります。その結果として、検索エンジンと生成AIも整合性を読み取ります（第5章）。

自動車整備士が記録簿に虚偽の記載をすれば、次の点検で矛盾が露呈するように、Webでも嘘は長くは持ちません。第6章で学んだ第2の返球である即去り、選ばれにくさ、クレームが、自分が期待外れでタブを閉じた体験として、証明書の偽りを暴きます。

> 最大のE-E-A-Tは、飾りではない。現場で積み上げ、記事に具体的な事実として刻んだ経験である。

---

### ポイント

- 国家資格＋現場経験＝最大のE-E-A-Tのモデル
- 資格は入口。本文中の具体的事実が証明書を完成させる
- 整備士の現場＝タブを閉じる体験・結果責任・段取り。Web設計と同型
- あなたの国家資格相当を特定し、記事に刻む

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| 肩書きだけ掲載 | 空の証明書 | 具体的事実・数字・期間 |
| 経験を誇張 | 信頼崩壊 | 検証可能な範囲で書く |
| 資格がないから書けない | 誤解 | 学びの過程・失敗もExperience |
| 著者ページを後付け | 整合性が弱い | 執筆時から設計 |
