# 7-7 章末まとめ・チェックリスト・演習

第7章を読み終えたあなたへ。ここまでで、手紙から証明書まで、本書の比喩の階段を登り切りました。一度、本章の地図を確認しましょう。

## 第7章のメッセージ（再確認）

> この節の要点：E-E-A-Tは検索・AIへのお世辞ではない。読者に対して「正しい」と宣言するための証明書である。

> E-E-A-Tは、検索・AIへのお世辞ではない。読者に対して「この情報は正しい」と宣言するための証明書である。

自動車整備士として国家資格を取得し、現場で技術を磨いてきた経験。それが、最大のE-E-A-Tのモデルでした。専門性は用語の羅列ではなく、問いへの具体的・責任ある応答。YMYLでは、その責任は一段厳しくなる。

そして最後に。テクニックを超えた、3つの誓いと、技術者の矜持。

---

## 本書第1章〜第7章、比喩と誓い

> この節の要点：第1章から第7章までの比喩と誓いは、人間への配慮と技術への誠実さが一本になった設計の完成形である。

| 章 | 比喩 | 誓い |
|---|---|---|
| 第1章 | 手紙 | 届け方は、礼儀である |
| 第2章 | 問い | 宛名を、間違えるな |
| 第3章 | 導管 | 段取りを、整えよ |
| 第4章 | 玄関 | 入口で、去らせない |
| 第5章 | 物流 | 届け方を、設計せよ |
| 第6章 | 精密検査 | 答え合わせを、続けよ |
| 第7章 | 証明書 | 正しいと、宣言せよ |

人間への配慮（道具・段取り・おもてなし）と技術への誠実さ（印付け・通信規格・証明書）。対立ではなく、一本の設計。これが、本書第1章〜第7章の完成形です。

---

## 第7章の章末まとめ

> この節の要点：証明書・現場経験・問いへの応答・記載事項・YMYL・3つの誓い・設計士の生き方。第7章の7項目を統合する。

1. E-E-A-T＝正当性の証明書。4要素は整備記録簿の欄
2. 国家資格＋現場経験＝最大のE-E-A-Tのモデル
3. Expertise ≠ 専門用語。問いへの具体的・責任ある応答が真の権威性
4. 出典・著者・更新・利益開示＝記載事項
5. YMYL＝人生への責任声明。すべての記事に預かる責任あり
6. 3つの誓い：空の返球を返さない／消滅を切り捨てない／宣言し、更新し続ける
7. 誠実な設計士としての生き方。第6章の改善の継続を受けた、技術者の矜持

## 第7章の執筆前・公開前チェックリスト

> この節の要点：公開前に証明書の欄を確認し、公開後は第6章の精密検査を継続する。

記事を公開する前、および公開後の継続点検で、次の項目を確認してください。

### 証明書（公開前）

- [ ] 著者・プロフィールに具体的事実（Experience / Expertise）
- [ ] 数値・事実に出典または一次体験の明示
- [ ] 更新日（初版日含む）
- [ ] 利益相反の開示（該当時）
- [ ] 監修者（YMYL・専門領域で該当時）
- [ ] 専門用語より、ペルソナの問いへの直結
- [ ] 限界・例外・わからないを適宜記載

### 設計士として（公開後）

- [ ] 第6章の月次精密検査を継続
- [ ] 誤り発見時は訂正と記録
- [ ] 次に書く記事のために、今日ひとつだけ整える

## 第7章の演習

> この節の要点：記事1本をE-E-A-T＝証明書の観点で監査し、改善アクションを1つ決める。

課題：自分（または他者）の記事1本を、E-E-A-T＝証明書の観点で監査してください。

### 提出物

1. 対象記事URL（またはタイトル）
2. 4要素の評価（Experience / Expertise / Authoritativeness / Trustworthiness。各○/△/×と理由）
3. 記載事項チェック（著者・出典・更新・利益開示。7-4節）
4. 専門用語 vs 問いへの応答。改善すべき段落を1つ指摘
5. YMYL該当性（該当する/しない、理由）
6. 改善アクション1つ（証明書のどの欄を、どう埋めるか）
7. 自分の国家資格相当。今後の記事に刻む具体的事実を1文

ヒント：第5章・第6章の演習と同じ記事を使うと、物流→精密検査→証明書の一連の流れが体験できます。

参考解答：[第7章 演習の参考解答](../../exercises/answer-keys/chapter-07.md)

第1章の手紙から、ここまで。長い階段を登り切りました。

テクニックは、手の中に残っているはずです。しかし本書が最後に渡したかったのは、型のリストではありませんでした。
