# 1-3　紙とWebの違い

ここで一度、紙の本とWebの文章の違いを整理しておきましょう。

紙の本は、読者が「お金を払って買った」ものです。  
だから、最後まで読んでもらえる可能性が高い。

しかしWebの文章は違います。

読者は、検索結果やSNSのタイムラインから、ふらっと訪れます。  
そして、つまらないと感じた瞬間、タブを閉じる。

タブを閉じた瞬間、あなたの記事は、その読者の頭から消えます。

これは、紙の本では起こりにくいことです。

紙の本なら、つまらない章があっても「ここまで読んだから、もう少し続けよう」と思ってもらえる。  
しかしWebでは、「ここまで読んだから」という積み重ねが、ほとんど効きません。

つまり、Webの文章は「常に最初の一文で勝負している」のです。

そして、もう1つ大きな違いがあります。

紙の本は「目次のあるページ」を読者がめくります。  
Webの記事は、検索エンジンやAIが「構造」を読み取って、読者に届けます。

つまりWebでは、読者の前に「機械の目」が立っているのです。

機械の目にきちんと理解されない文章は、そもそも読者の元に届きません。

ここが、紙とWebの決定的な違いです。

読者は逃げる。  
そして、その前に機械の目が立っている。

この2つを理解することが、Webライティングの第一歩です。
