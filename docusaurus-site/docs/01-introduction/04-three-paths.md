# 1-4　あなたの物語が届く3つの道

では、あなたの物語は、どんな道を通って読者に届くのでしょうか。

現代において、それは大きく3つあります。

**1つ目は、検索エンジン経由。**

「在宅勤務 始め方」「東京 美味しいラーメン」など、人が何かを知りたいと思って検索する。  
そして、検索結果に表示されたあなたの記事を読む。

これは昔から変わらない、王道のルートです。

**2つ目は、SNS経由。**

X（旧Twitter）、Instagram、Threads、TikTok。  
SNSのタイムラインで、誰かがシェアしたあなたの言葉が、思いがけず別の誰かに届く。

これは10年前にはあまりなかった、現代的なルートです。

そして、おもしろいことに、最近は「SNS内の検索」も増えています。  
若い世代は、おいしいレストランを探すときにInstagramで「カフェ 渋谷」と検索する。

つまり、SNSもまた、ある種の検索エンジンになっているのです。

**3つ目は、AI経由。**

ChatGPTやPerplexity、Geminiなどに「在宅勤務を始めるにはどうしたらいい？」と質問する。  
AIは、Web上のあなたの記事を読み込んで、その内容を要約して答える。

このルートは、ほんのここ数年で生まれました。  
しかし、すでに多くの人がこの方法で情報を得ています。

ここで大切なことがあります。

検索エンジンも、SNSも、AIも、結局は「あなたが書いた文章」を読み取っているということです。

つまり、これら3つの道に共通する「正しく書く」技術が、現代のWebライティングの核心なのです。

本書では、この3つの道それぞれに対応する書き方を、後の章で詳しくお伝えしていきます。
