# 1-1　Webライティングは死んでいない

「Webライティングって、もう古いんじゃない？」

最近、こんな声をよく耳にします。

AIに頼めば、文章は数秒で出来上がる。  
SNSでは、長い文章よりショート動画のほうがバズる。  
若い世代は、Google検索ではなくInstagramでお店を探す。

確かに、私たちが「ライティング」と呼んでいたものの形は、大きく変わりました。

しかし、です。

文章を書く「技術そのもの」は、決して死んでいません。

むしろ、誰もが発信者になれる今だからこそ、その重要性は以前にも増して高まっています。

考えてみてください。

AIが書いた文章を、そのまま使う人。  
AIが書いた文章を、自分の言葉に磨き直す人。

どちらが、読者の心に届くでしょうか。

SNSで毎日100投稿する人。  
SNSで週に1投稿だけど、必ず誰かの心を動かす人。

どちらが、長くファンに愛されるでしょうか。

答えは、考えるまでもないですよね。

本書が伝える「Webライティング」とは、過去のSEOテクニック集ではありません。

AI・SNS・検索という大きな変化の中で、あなたの物語を最高の形で世界に届けるための、現代の技術です。

私はこれを「文章のWeb最適化」と呼びたいと思います。
