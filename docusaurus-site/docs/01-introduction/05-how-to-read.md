# 1-5　本書の歩き方

本書は、全13章で構成されています。

最初に伝えたいのは、本書は「順番に読まなくてもいい」ということです。

もちろん、第1章から順に読んでいただければ、本書の流れがよく伝わると思います。

しかし、あなたが今困っていることがあるなら、その章から読み始めても構いません。

たとえば、SNSでの発信に悩んでいるなら、第6章から。  
AIとの付き合い方に迷っているなら、第7章から。  
書いた記事のリライトに困っているなら、第11章から。

Webの読書には、Webの読み方があります。  
本書もまた、その流儀に従ってください。

ただし、1つだけお願いがあります。

本書を読みながら、ぜひ「自分の文章」を1つでも書き直してみてください。

過去に書いたブログ記事でもいい。  
SNSの投稿でもいい。  
これから書こうとしている文章でもいい。

実際に手を動かしてみると、本書に書かれていることが「知識」から「技術」に変わります。

そして、ある日ふと気づくはずです。

「あれ、自分の文章、前より読まれるようになったな」と。

その瞬間、あなたはもう「文章のWeb最適化」を身につけているのです。

さあ、新時代のWebライティングの旅を、ここから一緒に始めましょう。
