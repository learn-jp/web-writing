# 1-2　なぜ今、Webライティングが必要なのか

「AIに書かせれば、それで十分じゃないか」

そう思う方もいるかもしれません。

確かに、AIは便利です。  
私自身も、毎日のように使っています。

しかし、AIが書く文章には、決定的に足りないものがあります。

それは「あなた自身の物語」です。

あなたが見てきた景色。  
あなたが感じた喜びや悔しさ。  
あなたが、なぜそれを伝えたいと思ったのか。

これは、AIには書けません。

なぜなら、それは「あなたという人間が生きてきた証」だからです。

今、Web上には毎日とんでもない量の情報が生まれています。

その中で「あなたの言葉」が誰かに見つけられるためには、2つのことが必要です。

1つは、検索エンジンやAIに「正しく理解されること」。  
もう1つは、読者に「心を動かされること」。

この2つを両立させる技術こそが、本書の伝える「文章のWeb最適化」です。

技術と言うと冷たく聞こえるかもしれません。

しかし実際には、これは「あなたの想いを、誰かに届けるための作法」です。

手紙を書くときに、宛名を書き、季節の挨拶を入れ、相手のことを思い浮かべながら言葉を選ぶ。  
それと同じです。

Webに書く文章にも、ちゃんとした「届け方」があるのです。
