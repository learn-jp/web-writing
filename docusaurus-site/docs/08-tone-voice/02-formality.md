# 8-2 敬体・常体の使い分け

8-1節で、ボイスは不変、トーンは可変と述べました。日本語のWeb文章で、トーンを最も直接的に変える道具が、敬体（です・ます調）と常体（だ・である調）です。「Webは敬体一択」と決め打ちせず、距離感の設計として使い分けを見直してください。検索・SNS・生成AIが要約・引用する時代ほど、文体のルールを固定しておくほど、チャネルをまたいでも「同じ店の声」として届きます。

## 敬体と常体、それぞれが生む距離感

> この節の要点：敬体は礼儀と距離、常体は近さとテンポ。正しさの問題ではなく、読者との距離感の設計である。

敬体は、読者との間に一段の礼儀を置きます。コーポレートサイト、公式ヘルプ、初めての読者向けハウトゥ、お問い合わせへの返信。第1章で述べた「手紙としての礼儀」とも通じます。

常体は、距離を少し縮けます。ブログの体験談、開発者向けドキュメント、社内ナレッジ、読者との関係が前提化されたシリーズ後半。断定のテンポが上がり、スキャンしやすくなる面もあります（第2-3節）。

| 文体 | 読者への印象 | 向く場面 | 注意 |
|---|---|---|---|
| 敬体 | 丁寧、公式、安心 | コーポレート、YMYL入門、初訪 | 冗長になりやすい（第3-3節） |
| 常体 | 近い、率直、テンポ良 | ブログ、上級者向け、開発者向け | 軽く見えるリスク |
| 混在 | 場面転換が明示的 | リードは敬体、引用は常体など | ルールなき混在は禁物 |

寿司職人が「本日のおすすめは、中トロです」と敬い、板の裏のメモに「塩弱め」と常体で書く。表と裏で文体が分かれても、同じ職人の判断です。Webでも、表向きの記事と内部用のメモで文体が分かれるのは自然です。問題は、同じ記事のなかで理由なく混在することです。

## メディアとペルソナによる使い分けの地図

> この節の要点：メディア別期待とペルソナを組み合わせ、文体の初期設定を決める。

第2-5節のメディア別期待と、第2-2節のペルソナを組み合わせて、文体の初期設定を決めます。

健太さん（副業を考える会社員）向けブログを書いているなら、敬体ベースで「一緒に確認していきましょう」と伴走するトーンが合いやすい。一方、エンジニア向け技術ブログなら、常体で手順を短く並べる方が、問い（ボール）に素早く返球できます（第3章）。

| ペルソナの段階 | 文体の目安 | 理由 |
|---|---|---|
| 認知・不安が強い | 敬体、共感多め | 信頼の土台（8-5節） |
| 比較・検討 | 敬体または常体、並列表 | 俯瞰を優先（第2-6節） |
| 実践・上級 | 常体可、手順中心 | テンポと再現性 |
| 既存顧客 | 短い敬体または常体 | 前提共有済み |

自動車整備士が、初来店のオーナーには「ブレーキパッドが薄くなっています」と敬い、同じ工房のベテラン整備士同士の引き継ぎメモには「左前パッド2mm、交換推奨」と常体で書く。読者が誰かで、文体の初期値が変わります。

## 敬体が長文化する問題と、第3章との接続

> この節の要点：敬体＝冗長ではない。敬体のまま短く書く技術が、トーン設計の実務である。

敬体は礼儀ですが、過剰になると第3-3節で述べた「1文1メッセージ」の原則を壊します。

```
✗ 「ご確認いただきたいのですが、副業を始める際には、
    就業規則をご確認いただくことが重要でございますので、
    お手数ですが、まずはそちらをご覧ください。」

✓ 「副業を始める前に、就業規則を確認してください。
    多くの会社では届け出が必要です。」
```

1文目は敬体の重なりで、スマホ画面（第2-4節）では息が続かない。2文目は敬体を保ちつつ、第4章の結論ファーストに近い返球です。敬体＝冗長、ではありません。敬体のまま短く書く技術が、トーン設計の実務です。

## 常体を選ぶときの、証明書との両立

> この節の要点：常体でも、第7章の証明書（出典、限界、著者）を省略してはいけない。

常体はテンポが良い反面、「軽い」「煽り」と誤解されやすい表現と相性が悪い。第7章の証明書（出典、限界、著者）を常体記事から省略してはいけません。

```
✗ 「副業ならブログ一択。すぐ稼げる。」（常体＋根拠なし）

✓ 「副業でブログを始める場合、就業規則の確認が先である。
    収益化まで平均6〜12か月かかる事例が多い（出典：〇〇調査2024）。」
```

常体でも、整備士の整備記録のように、事実と根拠は短く明記する。トーンは近く、ボイス（誠実さ）は変えない。

## チーム執筆での文体ルール

> この節の要点：複数ライターが書くと敬体の「温度」までバラつく。ガイドラインでデフォルトと禁止表現を固定する。

複数ライターが書くと、敬体の「温度」までバラつきます。「〜と思います」が多い人、「〜してください」が多い人。8-4節のブランドガイドラインに、文体の初期値と禁止表現を書いておく。

| ルール例 | 内容 |
|---|---|
| デフォルト | コーポレートは敬体、ブログは敬体ベース |
| 見出し | H2は体言止めまたは敬体で統一（第3-2節） |
| 禁止 | 記事途中の常体への無理由な切り替え |
| 例外 | 引用、コード、ユーザー声は文体を明示 |

---

## 文体はトーンの道具、正しさの代替ではない

> この節の要点：文体だけ変えて、ペルソナの問いに答えていないなら、第2章に戻り宛名を確認する。

### この節の整理

- 敬体＝礼儀と距離、常体＝近さとテンポ
- メディア・ペルソナ・ジャーニー段階で初期値を決める
- 敬体でも短く、常体でも証明書の欄は埋める
- 混在はルール付きのみ。無秩序な混在はブランドを壊す

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| すべて敬体で冗長 | スキャンで消滅 | 文長を第3-3節で圧縮 |
| 常体＝カジュアル＝煽り | 信頼低下 | 根拠・限界を常体でも明記 |
| ライターごとに文体 | 同一メディアで分裂 | 8-4節でデフォルトを固定 |
| 見出しだけ常体 | 本文との違和感 | 見出しルールを第3-2節と連動 |
