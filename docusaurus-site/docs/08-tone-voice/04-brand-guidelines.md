# 8-4 ブランドガイドラインの作り方

8-1節から8-3節で、ボイス、文体、語彙の考え方を押さえました。一人で書くうちは頭の中のルールで回ります。チームが増え、外注ライターが入り、メディアが増えると、声が分裂します。「うちのサイト、なんとなく優しい感じ」とだけ口頭で伝えていたなら、ブランドガイドライン（トーン＆マナーガイド）を文書化する段階です。第2-5節で、コーポレートはブランドガイドラインに沿うと述べました。本章では、その中身を、Webライターが使える形で設計します。

## ガイドラインが答える4つの問い

> この節の要点：優れたトーン＆マナーガイドは、誰か・距離・語彙・禁則の4問に答える。ライター向けに文章単独で完結させる。

優れたトーン＆マナーガイドは、次の4問に答えます。デザインガイドのロゴ使用規定と並べてもよいですが、ライター向けには文章単独で完結させることを推奨します。

| 問い | ガイドラインの記載例 |
|---|---|
| 私たちは誰か（ボイス） | 「伴走する設計士。上から教えない」 |
| 読者との距離は（トーン） | 敬体デフォルト、不安が強い問いは共感を増やす |
| どんな言葉を使うか（語彙） | 推奨語彙表、禁則語、言い換え表（8-3節） |
| どんな言葉を使わないか | 誇大、断定的収益、他社贬め、差別表現 |

寿司屋が「塩は弱め」「シャリは握りたて」と板の裏に書くように、Webチームも「です・ます調」「数字には出典」と声のレシピを残します。

## 最小構成、1ページから始める

> この節の要点：最初から100ページは不要。ボイス・ペルソナ・文体・語彙・良悪例・証明書参照の最小セットから始める。

最初から100ページのガイドは不要です。次の最小セットで、8章の演習にもそのまま使えます。

```
1. ボイスステートメント（3〜5文）
2. 読者像（ペルソナへのリンクまたは要約）
3. 文体ルール（敬体/常体、見出し、一人称）
4. 推奨語彙・禁則語（各10語程度）
5. 良い例・悪い例（各2段落）
6. 証明書の欄（著者、出典、更新。第7-4節への参照）
```

自動車整備工房の「作業手順書」に近い発想です。国家資格者でなくても、手順書があれば品質の下限が揃う。ガイドラインは、声の下限と上限を定義します。

## ボイスステートメントの書き方

> この節の要点：形容詞だけでは再現できない。「やること／やらないこと」を対で書く。

ボイスステートメントは、形容詞3〜5個と、短い段落で書きます。抽象的なだけでは再現できないので、必ず「やること／やらないこと」を対で書きます。

| 形容詞 | やること | やらないこと |
|---|---|---|
| 誠実 | 限界・例外を書く | 収益を保証する |
| 具体的 | 手順と数字 | 抽象語だけで終わる |
| 伴走 | 「一緒に確認」 | 上から目線の断定 |
| 簡潔 | 結論ファースト（第4章） | 冗長な敬語の連打 |

例（架空の副業メディア）：

> 私たちは、副業を考える会社員の不安に寄り添い、就業規則と届け出から説明する。収益の話には必ず期間と条件を添える。専門用語より、読者が検索する言葉を選ぶ。著者の経験と出典を、記事の末尾で明示する（第7章）。

## 良い例・悪い例、比喩で固定する

> この節の要点：同じテーマの良い段落と悪い段落の対比が、再現性の核である。

ガイドラインで最も効くのは、同じテーマの良い段落と悪い段落の対比です。ルールを読むより、体感で覚えられます。

```
【悪い例】
「副業ならブログ一択！誰でも月10万円！」

【良い例】
「副業でブログを始める場合、まず就業規則を確認してください。
 収益化まで6〜12か月かかる事例が多いです（出典：〇〇調査2024）。
 著者は副業歴3年、関連記事100本を執筆しています。」
```

悪い例には、禁則（誇大、根拠なし）が含まれます。良い例には、8-3節の語彙、8-2節の敬体、第7章の証明書の欄が含まれます。

## 運用、更新と第6章との接続

> この節の要点：ガイドラインは作って終わりではない。第6章の返球と第11章のリライトで、四半期ごとに見直す。

ガイドラインは作って終わりではありません。第6章の第2の返球（クエリ、去り方、自分が検索したときの体験）を振り返り、語彙表やトーンの例外を更新します。四半期に1回、次の項目を見直すとよいでしょう。

| 見直し項目 | トリガー |
|---|---|
| 言い換え表 | クエリと本文のズレ（6-4節） |
| 良い例・悪い例 | リライトで効いた修正（第11章） |
| 禁則語 | クレーム、法務フィードバック |
| ペルソナ要約 | 新規メディア・新商品 |

寿司職人が季節のネタでレシピを更新するように、声の設計書も鮮度を保ちます。第7章の「更新し続ける宣言」と同じ姿勢です。

## 外注・AI執筆への渡し方

> この節の要点：外注や生成AI（ChatGPT、Gemini等）には、アウトライン・ペルソナ・ガイドライン・良い例を必須資料として渡す。

外注ライターや生成AIに記事を書かせる場合、ガイドラインは「入力の必須資料」にします。アウトライン（第3-5節）、ペルソナ、ガイドライン、良い例1本。これが揃って初めて、ボイスが再現可能になります。AIに渡すときは、禁則語・証明書の欄（著者・出典・更新）をプロンプトに明示し、出力後に人間が事実確認を行います。

ガイドラインなしで外注だけ増やすと、記事ごとに別の店が出店している状態です。読者は混乱し、第7章の証明書も記事ごとに形が変わります。

## ガイドラインは、声の整備記録簿

> この節の要点：1ページのドラフトと良い例1組から始め、第6章のデータで自分が検索したときに選びたくなる記事を基準に更新する。

### この節の整理

- ガイドライン＝声の設計書。配色集だけでは不十分
- 最小構成：ボイス、ペルソナ、文体、語彙、良悪例、証明書参照
- 良い例・悪い例の対比が、再現性の核
- 第6章の返球と第11章のリライトで更新する

### よくある間違い

| 間違い | 問題 | 改善の方向 |
|---|---|---|
| デザインガイドのみ | ライターが参照できない | 文章単独の1ページ版を作る |
| 抽象語だけ | 執筆時に判断できない | 良悪例の段落を追加 |
| 作ったきり放置 | 声が時代遅れ | 四半期見直し |
| ガイドと証明書が分離 | トーンだけ統一、中身が空 | 第7-4節をガイドに組み込む |
