# 4-5　見出し・リードの改善方法

最後に、書いた後の見直しの話をします。

見出しとリード文は、書き終えた後の見直しが特に大切です。

なぜなら、書き手は自分の文章に慣れすぎて、客観的に判断できなくなるからです。

見直しのコツを3つお伝えします。

## 1. 一晩寝かせる

書き上げた直後の文章は、書き手の中で「最高の出来」に見えます。  
しかし、一晩寝てから読み返すと、意外な粗が見えてきます。

特に見出しとリードは、頭の冷えた状態で読み返してください。

## 2. 他人の目で読む

書き手が自分で「これで完璧」と思っても、他人が読むと違和感を感じることがあります。

身近な人に読んでもらうのが理想です。  
それが難しければ、自分の中で「全く別の人」になりきって読んでみてください。

「この見出しを初めて見た人は、何を期待するだろう」  
「このリードを読んだ人は、本文を読みたくなるだろうか」

## 3. 数字で改善する

公開してからも、改善は続きます。

検索コンソールやアクセス解析を見れば、見出しがどれくらいクリックされているかが分かります。  
クリック率が低ければ、見出しを変えてみる。

改善の話は、第12章で詳しくお伝えします。

---

見出しとリード文は、本文より時間をかけて書く価値があります。

なぜなら、ここで読者の99%が判断するからです。

本文を100%の力で書いても、見出しとリードが弱ければ、本文は読まれません。  
逆に、見出しとリードが強ければ、本文は最後まで読んでもらえます。

時間配分で言うと、見出しとリードに、全体の3割を使ってもいい。  
それくらい、ここは大切な場所です。
