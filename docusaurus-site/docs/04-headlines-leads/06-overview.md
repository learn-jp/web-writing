# 4-6 章末まとめ・チェックリスト・演習

第3章で導管を設計したあなたへ。第4章では、その導管に「玄関」を設計しました。論理が正しくても、自分が入口でタブを閉じれば、導管は空回りします。本章の要点を整理し、第5章への橋渡しを確認しましょう。

## 第4章のメッセージを再確認する

> この節の要点：見出し＝一瞬のスクリーニングゲート、リード＝最大の防波堤。H1＝外門、リード＝玄関ホール、H2＝内門。

第3章で、情報の通り道（導管）を設計しました。しかし、導管が完璧でも、入口が閉じていれば、自分はタブを閉じ、記事を忘れます。

あなたが第4章で学んだことを、ここで一度整理しましょう。

> 見出しは、自分が「この関所を通る価値があるか？」を一瞬で判断する、最初のスクリーニングゲートである。  
> リード文は、離脱（タブを閉じる）を防ぐ、最初にして最大の防波堤である。

H1＝外門、リード＝玄関ホール、H2＝内門。結論ファーストは、3層すべてで出口の予告を見せる設計。釣りゲートは信頼を失い、タブを閉じさせる。誠実な吸引力が、情報の設計士の入口設計です。

---

## 第4章から第5章へ、玄関から物流へ

> この節の要点：第5章では比喩が物流に移る。問いに届くルート（検索を入口に）と配送ラベル（title・meta）を設計し、第4章の約束を発見の入口に伝える。

第1章の手紙、第2章の問い、第3章の導管、第4章の玄関。ここまでで、読者が記事の中に入り、答えへ進む道筋は整いました。

しかし、SNS・検索・AI経由で来る読者の多くは、あなたの玄関の前にすら立ちません。第5章では、比喩が物流に移ります。問いに届くルート（クロール・インデックス）と、荷物に貼る配送ラベル（title・meta）。第4章の外門・防波堤と同じ約束を、検索を入口としたWeb最適化の通信規格として設計します。

手紙を書き、段取りを整え、玄関を磨いた設計士が、最後に届け方のインフラと向き合う。それが第5章です。人間味と技術は、ここで初めて対立せず、一本の設計として収束します。

---

## 第4章の章末まとめ

> この節の要点：第3章の関所＋第4章のゲート、防波堤、3層の結論ファースト、意図の型ごとの設計、ABテストと継続改善の7要点。

1. 第3章の関所に、第4章のゲート（看板）を載せる。論理と表現の分担
2. 見出し＝スクリーニングゲート。審査は一瞬、通過率と誠実さの両立
3. リード＝最大の防波堤。ボールを引き取り、約束を果たし、本文へ誘導
4. 結論ファーストはH1・リード・H2冒頭の3層。タブを閉じる前に出口を予告
5. 意図の型（Know/Do/Go/Buy/共感）ごとに、ゲートと防波堤の型を変える
6. ABテストと自分の体験の確認で、入口を継続改善。タブを閉じた瞬間の手がかりは、発見の入口（検索を含む）にもその結果が伝わりうる
7. title・meta は正当性を証明する配送ラベル。H1・リードと同じ約束を機械の知性に伝える

## 公開前チェックリスト

> この節の要点：H1（外門）・リード（防波堤）・H2（内門）の3段階で、問いとの接続・約束の一致・結論ファーストを確認する。

### H1（外門）

- [ ] ペルソナの問いと接続している
- [ ] 具体性（数字・対象・条件）がある
- [ ] 約束は Must と一致し、釣りになっていない
- [ ] スマホ検索結果で前半に核心が見える
- [ ] メタ説明（あれば）と同じ約束

### リード（防波堤）

- [ ] 150〜300字、3〜5文
- [ ] 結論（P）が1〜2文目にある
- [ ] ペルソナの問いの言葉でボールを引き取っている
- [ ] H1の約束を果たす内容
- [ ] 最初のH2への橋がある

### H2（内門）

- [ ] 第3章の論理名をゲート文言に言い換えた
- [ ] 見出しだけ読んで答えの予告がわかる
- [ ] 各H2冒頭に結論（P）がある

### 公開後（任意）

- [ ] 検索結果での選ばれ方、開いてすぐ閉じたかを確認し、入口改善候補をメモ
- [ ] 開いてすぐ閉じる場合、H1・リード・最初のH2から疑う

## 演習：見出し10案とリード文3案

> この節の要点：固定するP（結論）からH1を10案・リードを3案。第3章の論理名をゲート文言に言い換え、手を動かして入口設計を確認する。

第2〜3章で使ったテーマ（または新規）について、見出し10案とリード文3案を作成してください。

### 前提

- 問い・出口・ペルソナは第2章演習から引用可
- H2構成は第3章アウトラインから引用可

### 提出物

1. 固定するP（結論）1文
2. H1見出し10案（バリエーション：具体性、対象、数字、問いの言葉、型を変える）
3. 採用H1 1つと、その理由（2〜3文）
4. リード文3案（結論ファースト / 共感→結論 / 問いかけ など型を変える）
5. 採用リード 1つと、その理由
6. H2見出し（3〜5個）。第3章の論理名→ゲート文言への言い換え

ヒント：10案は良い1案を探すための量産です。釣り案も1つ含め、なぜ採用しないかを言語化すると学びが深まります。リードは本文より先に書いてください。
