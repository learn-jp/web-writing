# 10-5　プレーンランゲージ

「プレーンランゲージ」とは、平易で分かりやすい言葉のことです。

専門用語、難しい漢字、長い文章。  
こうした表現を避けて、誰にでも理解できる言葉で書く。  
これが、プレーンランゲージの基本です。

---

具体的な工夫を、いくつかお伝えします。

## 1. 漢字を多用しすぎない

「漢字で書ける言葉は、漢字で書く」が必ずしも正しいとは限りません。

たとえば、「致します」より「いたします」の方が読みやすい場合があります。  
「於いて」より「において」の方が、目に優しい。

漢字の使いすぎは、文章を硬くします。  
ひらがなとのバランスを意識してください。

## 2. 専門用語にはルビや言い換えを

避けられない専門用語を使う時は、その意味を併記しましょう。

「アジャイル（短い周期で開発を繰り返す手法）」  
「PDCAサイクル(計画・実行・確認・改善の繰り返し)」

カッコで補足するだけで、初めての読者にも伝わるようになります。

## 3. 一文を短くする

第3章でもお伝えしましたが、長い文は読みにくいです。  
特に、認知に困難がある読者や、日本語を学んでいる読者にとっては、大きな壁になります。

一文60文字以内を目安にしてください。

---

プレーンランゲージは、特別な層のためだけのものではありません。

実は、すべての読者にとって、プレーンランゲージは読みやすいのです。  
急いでいる時、疲れている時、誰だって難しい文章は読みたくありません。

「誰にでも読める文章」は、結果として「誰にとっても読みやすい文章」になります。
