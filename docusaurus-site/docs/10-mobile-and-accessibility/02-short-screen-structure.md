# 10-2　短い画面で伝える構成

スマホ画面で読まれることを前提にすると、文章の構成も変わってきます。

スマホ画面に一度に表示できる文字数は、限られています。  
だから、その狭い画面の中で「読み進めたい」と思わせる工夫が必要です。

---

スマホ向けの構成で意識したいことを、3つお伝えします。

## 1. 最初の画面で「読む価値」を伝える

スマホで記事を開いた時、最初に表示されるのは、ほんの数行です。  
その数行で「この記事は自分にとって価値がある」と思わせなければ、読者はすぐに戻るボタンを押します。

第4章でお伝えしたリード文の話が、ここでも効いてきます。  
最初の3行で、読者の心を掴む。  
これが、スマホ時代の鉄則です。

## 2. 段落をこまめに区切る

パソコンで読みやすい段落の長さと、スマホで読みやすい段落の長さは、違います。

パソコンでは5〜7行が適切な段落でも、スマホでは長すぎます。  
スマホ画面では、3〜4行で段落を区切るくらいがちょうどいいです。

「短すぎるかな」と感じるくらいで、ちょうど読みやすくなります。

## 3. 見出しを多めに入れる

スキャンしながら読む読者にとって、見出しは「現在地を示す看板」です。  
スマホで縦に長くスクロールしていく中で、見出しがあると「あ、ここからこの話か」と理解できます。

長い記事ほど、見出しの数を増やしてください。  
目安として、2〜3スクロールに1つの見出しがあると、読みやすくなります。
