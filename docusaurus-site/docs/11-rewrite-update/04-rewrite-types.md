# 11-4　全面・部分・統合・分割の使い分け

リライトといっても、その方法はいくつかあります。  
状況に応じて、最適な方法を選びましょう。

---

代表的なリライトの方法を、4つご紹介します。

## 1. 全面リライト

記事をほぼゼロから書き直す方法です。

「もう一度、最初から書くなら、こう書く」と感じた時に使います。  
過去の構成を捨てて、新しい視点で書き直す。  
労力は大きいですが、効果も大きい方法です。

## 2. 部分リライト

記事の一部だけを書き直す方法です。

「リード文だけ直す」「特定の節だけ追加する」「結論だけ書き直す」など。  
時間がない時に、優先度の高い部分だけを修正する方法です。

## 3. 統合リライト

複数の記事を1つにまとめる方法です。

似たテーマで複数の記事を書いていると、それぞれが薄くなりがちです。  
これらを統合して、1つの濃い記事にする。  
そうすることで、機械の目にも読者の目にも、価値が伝わりやすくなります。

## 4. 分割リライト

1つの長い記事を、複数に分ける方法です。

「あれもこれも詰め込んだ記事」は、結果として何も伝わらないことがあります。  
テーマごとに分割して、それぞれを掘り下げた記事にする。  
そうすることで、各記事の専門性が高まります。

---

どの方法を選ぶかは、その記事の状態によります。

「情報が古いだけ」なら、部分リライトで十分。  
「構成が悪い」なら、全面リライトが必要。  
「内容が薄い」なら、統合や分割を検討する。

リライトは、闇雲にやるものではありません。  
何を直したいのか、明確にしてから取りかかりましょう。
