# 8-5　信頼性（Trustworthiness）

最後は、Trustworthiness（信頼性）です。

これが、E-E-A-T の中で最も重要だと言われています。

信頼性とは、この情報源は信頼できるかという、最終的な判断基準です。

経験、専門性、権威性。  
これら3つを総合して、「信頼できるかどうか」が決まります。

---

信頼性を高めるために、書き手ができることがいくつかあります。

## 1. 根拠を示す

データや事実を書く時には、必ず出典を示しましょう。  
「ある調査によると」ではなく「◯◯による2024年の調査によると」と書く。

## 2. 著者情報を明確にする

誰が書いたのか、その人はどんな経歴を持つのか。  
これが分かるだけで、記事の信頼性は格段に上がります。

## 3. 更新日を明確にする

情報には鮮度があります。  
いつ書かれた記事なのか、最後にいつ更新されたのか。  
これを明示することで、読者は安心します。

## 4. 間違いを認める

書いた内容に間違いがあった時、潔く修正し、訂正したことを明示する。  
これは、信頼性を高める最も誠実な行為です。

---

信頼性は、一度失うと、取り戻すのに長い時間がかかります。

煽った見出し、根拠のない主張、間違いを隠す姿勢。  
こうした行為が積み重なると、信頼は崩れていきます。

逆に、地道に誠実な発信を続ければ、信頼は静かに、しかし確実に積み上がっていきます。
