# 第12章 あなたの物語戦略

> 比喩の階段における位置：応用編（第8章〜）。本編で1台分の修理を学んだあと、車両全体の整備計画と、おまかせコースの献立設計を担う章です。

> 第11章からの接続：既存の記事を修理し、資産として磨き続ける方法を学んだ。しかし、修理は「既にあるものを直す」作業に限られる。第12章は、その前段階。何を、どの順番で、どう組み合わせて書くか。あなたの物語を体系で設計する章です。

> この章で学ぶこと
> - 単発の記事ではなく、あなたの物語を体系で設計する考え方
> - トピッククラスターとハブ記事（第5-5節・第2-6節の拡張）
> - コンテンツカレンダーの設計と運用
> - インパクト×労力による優先順位づけ（第6-5節・第3-6節の拡張）
> - ステークホルダーとの合意形成と計画の継続

本章の核となるメッセージ

> 1台の故障修理から、車両全体の整備計画へ。1貫の握りから、おまかせコースの献立へ。あなたの物語は、記事の集合ではなく、読者のジャーニーに沿った体系である。
