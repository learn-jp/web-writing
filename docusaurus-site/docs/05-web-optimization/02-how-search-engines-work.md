# 5-2　検索エンジンの基本動作

Web最適化を理解するために、まず「機械の目」がどう動いているかを知っておきましょう。

代表的な「機械の目」である、検索エンジンの仕組みから見ていきます。

検索エンジンは、大きく3つのステップで動いています。

## 1. クロール

検索エンジンは、世界中のWebページを巡回するロボット（クローラー）を持っています。  
このロボットが、新しいページや更新されたページを見つけて、内容を読み取ります。

あなたが書いた記事も、公開してしばらくすると、このロボットに発見されます。

## 2. インデックス

クローラーが読み取った内容は、検索エンジンの巨大なデータベースに登録されます。  
これを「インデックス」と呼びます。

インデックスされて初めて、あなたの記事は「検索結果に出る候補」になります。

## 3. ランキング

ユーザーが何かを検索すると、検索エンジンはインデックスされたページの中から、最適なものを選び出して並べます。

ここで「どの順番で並べるか」を決めるのが、ランキングのアルゴリズムです。

---

このランキングを決める要素は、何百もあると言われています。  
その全てを把握することは、現実的ではありません。

しかし、書き手として意識しておきたい大きな要素は、いくつかに絞られます。

「この記事は、ユーザーの問いに答えているか」  
「この記事は、信頼できる情報源か」  
「この記事は、読みやすく構造化されているか」

これらは、検索エンジンが昔から重視してきた基本です。  
そして、これらは全て、本書がこれまで伝えてきた内容と重なります。

つまり、奇をてらわず、読者の問いに誠実に応える文章を書けば、検索エンジンも自然にあなたの記事を評価してくれるのです。
