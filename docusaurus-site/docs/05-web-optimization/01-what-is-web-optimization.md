# 5-1　Web最適化とは何か

ここからは、いよいよ本書の核となる概念に入ります。

本書では「文章のWeb最適化」という言葉を、何度か使ってきました。  
ここで、その意味をきちんと定義しておきましょう。

文章のWeb最適化とは、こう定義します。

「機械の目」と「読者の心」、その両方に届く文章を書くこと。

これが、本書が伝える Web最適化の本質です。

---

ここで、よく聞かれる質問にお答えします。

「Web最適化って、SEOのことですよね？」

答えは、半分イエスで、半分ノーです。

SEO（サーチエンジン最適化）は、Web最適化の中に含まれます。  
しかし、Web最適化は、SEOよりずっと広い概念です。

なぜか。

かつての SEOは、主に「Google検索で上位に表示されること」を目的としていました。

しかし、現代では「機械の目」は検索エンジンだけではありません。

SNSのアルゴリズム、AIチャット、動画プラットフォームのレコメンドエンジン。  
これら全てが、文章を読み取る「目」になっています。

つまり、現代の文章は、複数の「機械の目」に同時に晒されています。

そのどれかに最適化するのではなく、すべてに自然に届く文章を書く。  
これが、本書の言う「Web最適化」です。

---

ただし、誤解しないでください。

「Web最適化」は、機械に媚びることではありません。

機械に最適化された結果、人間にとって不自然な文章になってしまったら、本末転倒です。  
キーワードを無理やり詰め込んだ見出し。  
SEO対策のために水増しされた本文。

こういう文章は、機械にも見抜かれます。  
そして、何より読者の心に届きません。

本書が伝える Web最適化は、「読者の心に届く文章を書く」ことが大前提です。  
その上で、機械の目にも自然に理解されるように設計する。

順番が大切です。

読者の心が先、機械の目が次。  
この順番を、絶対に間違えないでください。
