# 5-6　やってはいけないこと

最後に、Web最適化の「やってはいけないこと」をお伝えします。

ここは、私自身が過去に通ってきた道でもあります。  
正直に話します。

かつて、「上位表示こそが正義」と思っていた時期が、私にもありました。

色々な手法を試しました。  
キーワードを詰め込んだ文章を書く。  
他のサイトから不自然にリンクを集める。  
中古ドメインを使って、すでに評価のあるドメインから始める。

確かに、一時的には効果が出ます。  
検索順位が上がる。  
アクセスが増える。

しかし、それは長くは続きませんでした。

検索エンジンは、必ずその先を見抜きます。  
ある日、検索エンジンのアルゴリズムが更新されて、順位がガクッと落ちる。  
そんなことを、何度も経験しました。

---

その経験を通って、ようやく気づきました。

小手先のテクニックで上位を取っても、それは「借りた席」でしかありません。  
本当に大切なのは、読者の心に届く文章を書くこと。  
それが、結果として検索エンジンにも評価される。  
この順番でしか、長く愛される記事は作れないのです。

これは、私の黒歴史でもあり、本書を書くきっかけにもなった気づきです。

---

具体的に「やってはいけないこと」を、いくつか挙げておきます。

## 1. キーワードの不自然な詰め込み

すでに何度も書きましたが、最も多い失敗です。

## 2. 他サイトの文章のコピー

著作権の問題はもちろん、検索エンジンも重複コンテンツを評価しません。

## 3. 自動生成された薄い記事を量産

AIで大量に記事を生成して、サイトに並べる手法があります。  
しかし、内容の薄い記事を増やしても、サイト全体の評価が下がるだけです。

## 4. 不自然なリンク購入

他のサイトに依頼して、自分のサイトへのリンクを大量に貼ってもらう手法です。  
検索エンジンは、これも見抜きます。

---

これらの手法には、共通点があります。

それは、「読者のためではなく、機械を騙すための行為」であることです。

機械を騙そうとした瞬間、あなたは読者の信頼を失います。  
そして、機械の目も、必ずいつかその嘘を見抜きます。

正攻法で行きましょう。

読者の問いに、誠実に応える文章を書く。  
情報を正しく構造化する。  
信頼できる情報源を示す。

これだけで、十分です。

そして、これこそが、本書が伝える「文章のWeb最適化」の全てです。
