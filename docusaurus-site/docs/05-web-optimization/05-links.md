# 5-5　内部リンクと外部リンク

文章単体だけでなく、文章と文章のつながりも、Web最適化では大切です。

そのつながりを作るのが、「リンク」です。

リンクには、2種類あります。

## 内部リンク

同じサイト内の、別の記事へのリンクです。

たとえば、あなたが「在宅勤務の始め方」という記事を書いた時。  
記事の中で「椅子の選び方は別記事で詳しく書きました」と、自分の別記事にリンクを貼る。  
これが内部リンクです。

内部リンクには、3つの効果があります。

- 読者がより深く情報を得られる
- サイト全体の滞在時間が伸びる
- 検索エンジンに「サイトの構造」が伝わる

3つ目が特に重要です。  
内部リンクが適切に張られているサイトは、検索エンジンに「整理されたサイト」として認識されます。

## 外部リンク

自分のサイトから、他の人のサイトへのリンクです。

たとえば、政府の統計データを引用する時に、その元のページにリンクを貼る。  
これが外部リンクです。

外部リンクには、2つの役割があります。

- 情報の信頼性を高める
- 読者にさらに深い情報源を提供する

「外部にリンクを貼ると、読者が逃げてしまうのでは？」と心配する人がいます。  
しかし、信頼できる情報源を示すことは、読者にとってもプラスです。  
そして、それは結局、書き手への信頼にもつながります。

---

リンクを貼る時のコツを、いくつか。

## 1. リンクテキストは具体的に

❌ こちらをご覧ください  
⭕ 在宅勤務に最適な椅子の選び方

何のリンクか、テキストだけで分かるようにします。

## 2. 関連性のあるリンクだけを貼る

無関係なリンクを大量に貼ると、機械の目から不自然と見なされます。  
本当に読者の役に立つリンクだけを選んでください。

## 3. リンク切れに注意

外部リンクは、相手のサイトが変わると切れることがあります。  
時々チェックして、切れていたら修正しましょう。
