# 5-4　キーワードを自然に配置する

「キーワード」という言葉を、何度か使ってきました。

ここでは、キーワードとの正しい付き合い方を、もう少し掘り下げます。

まず、キーワードとは何か。

キーワードとは、読者が検索窓に打ち込む「言葉」のことです。

たとえば、在宅勤務の始め方を知りたい人は、こんな言葉を検索します。

「在宅勤務 始め方」  
「テレワーク 初心者」  
「リモートワーク 必要なもの」

これらが、その記事の「キーワード」です。

書き手は、こうしたキーワードを意識して、文章の中に自然に含めます。  
そうすることで、検索エンジンが「この記事は何について書かれているか」を理解しやすくなります。

---

ここで重要なのは、「自然に」という部分です。

かつての SEO対策では、キーワードを文章中に大量に詰め込む手法がありました。

「在宅勤務には在宅勤務専用の机が必要です。在宅勤務を始めるなら在宅勤務用の椅子も用意してください。在宅勤務初心者の方は…」

こんな文章、読みづらいですよね。  
そして実は、検索エンジンもこれを「不自然」と判断します。

現代の検索エンジンは、文章の意味を理解する能力を持っています。  
だから、キーワードを連呼するより、関連する言葉を自然に散りばめる方が、評価されやすいのです。

「在宅勤務」というキーワードを意識しつつ、「テレワーク」「リモートワーク」「家での仕事」「リモート業務」といった関連語も、自然に使う。  
これが、現代の正しいキーワード配置です。

---

キーワード配置の基本原則を、3つにまとめます。

## 1. 読者の言葉で書く

書き手が使い慣れた専門用語ではなく、読者が検索しそうな言葉を使います。

## 2. 不自然な繰り返しを避ける

同じキーワードを何度も連呼するのではなく、関連語を使い分けます。

## 3. 大事な場所に置く

タイトル、見出し、リード文、まとめ。  
これらの「読者と機械の目が必ず見る場所」にキーワードを配置します。

これだけ守れば、十分です。

複雑なテクニックは、必要ありません。
