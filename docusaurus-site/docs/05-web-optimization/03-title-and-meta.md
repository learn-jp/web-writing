# 5-3　タイトルとメタディスクリプション

検索エンジンの仕組みを踏まえた上で、具体的な技術に入りましょう。

まずは、検索結果に直接表示される2つの要素です。

## タイトル

検索結果に大きく表示される、青い文字の部分です。

タイトルは、第4章で扱った「見出し」と同じ役割を持ちます。  
ユーザーが検索結果を見て「この記事を読むかどうか」を判断する、最大の要素です。

良いタイトルの条件は、第4章の見出しと同じです。

具体的であること。  
読者の問いに対応していること。  
中身を裏切らないこと。

ここに、検索エンジン向けの工夫を加えます。

それは、検索されるキーワードを、自然に含めることです。

たとえば、在宅勤務についての記事なら、「在宅勤務」「始め方」「初心者」といった、読者が検索しそうな言葉を、タイトルに自然に組み込みます。

ただし、第4章でもお伝えした通り、キーワードを詰め込むのは逆効果です。  
「読みやすい文として、キーワードが入っている」状態を目指してください。

## メタディスクリプション

検索結果で、タイトルの下に表示される説明文のことです。

メタディスクリプションは、第4章のリード文と同じ役割を持ちます。  
タイトルで興味を持った読者に、「この記事を本当に読むべきか」を判断させる場所です。

良いメタディスクリプションには、以下の要素を含めます。

- この記事で扱うテーマ
- 読者が得られる具体的なメリット
- 続きを読みたくなる「引き」

長さの目安は、120〜150字程度。  
スマホの検索結果では、これより長いと途中で切れてしまいます。

---

タイトルとメタディスクリプションは、検索結果での「広告コピー」のようなものです。
